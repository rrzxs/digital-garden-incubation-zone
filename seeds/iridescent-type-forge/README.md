# Iridescent Type Forge · 虹彩字形锻造炉

沉浸式虹彩字形锻造实验室。输入文字即刻锻造成具有金属光泽的活体字形——弹簧-阻尼物理驱动每个字符对光标力场产生排斥 / 吸引 / 涡旋响应，点击画布发射冲击波涟漪，全场脉冲共振。

## 特性

- **4 种虹彩着色模式**: HOLO 全息 / PRISM 色散棱镜 / CHROME 镀铬 / OIL 油膜干涉
- **3 种力场**: 排斥 · 吸引 · 涡旋，光标实时扰动字形晶格
- **冲击波系统**: 点击画布发射径向冲击波，字形被推开并以弹簧曲线归位
- **粒子流场**: 值噪声流场驱动的环境粒子随氛围配色呼吸
- **乱码揭示**: 锻造 / 标题入场均为乱码解密动画
- **4 种氛围配色**: AURORA · EMBER · ABYSS · ORCHID
- **实时遥测 HUD**: GLYPHS / FPS / WAVES / 光标速度

## 技术

- 免构建: Vanilla JS + CSS3 + Canvas 2D
- 字体: Inter / Outfit / Share Tech Mono
- 动效曲线: `cubic-bezier(0.16, 1, 0.3, 1)`
- 流体渐变背景 + 微晶玻璃态容器 (`backdrop-filter`)

## 使用

直接打开 `index.html`，输入文字、移动光标、点击画布即可。
