# Glass Xylophone — 微晶玻璃木琴

沉浸式微晶玻璃木琴交互体验。每一根琴键都是一片微晶玻璃态发光体，击键时弹簧-阻尼物理驱动非线性形变，涟漪与粒子从琴键顶部迸发。

## 特性

- **Web Audio 合成引擎** — 四种音色（Glass 玻璃 / Crystal 水晶 / Bell 钟铃 / Marimba 马林巴），多泛音叠加 + 程序化卷积混响
- **弹簧-阻尼物理琴键** — 击键瞬间触发半隐式欧拉积分的弹簧物理，琴键产生压缩、拉伸与微倾斜形变
- **Canvas 涟漪 + 粒子迸射** — 击键位置迸发多层谐振环、上抛粒子受重力与 Simplex 噪声流场扰动
- **键盘演奏** — A S D F G H J K 对应 C D E F G A B C，Z / X 切换八度，空格切换持续模式
- **氛围流场粒子** — 背景持续流动的环境粒子，受 Simplex 噪声驱动
- **4 种氛围配色** — 棱镜 / 暮霭 / 余烬 / 苔藓
- **自动演奏** — 内置 4 段旋律随机演奏，带节奏微抖动
- **实时参数调节** — 延音时长、微光（高频泛音强度）、击键力度

## 技术实现

- Vanilla JS + Canvas 2D + Web Audio API，零构建
- Simplex 噪声流场驱动粒子运动
- 微晶玻璃态容器（`backdrop-filter: blur(48px) saturate(140%)`）+ 流体渐变背景（4 层 blob + 颗粒噪点叠加）
- 非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Inter（正文）/ Outfit（展示）/ Share Tech Mono（等宽）
- 响应式布局，支持触屏与 `prefers-reduced-motion`

## 使用

直接在浏览器中打开 `index.html`。

- 鼠标点击琴键，或键盘 `A S D F G H J K` 演奏
- `Z` / `X` 降低 / 升高八度
- `空格` 切换持续模式
- 切换音色、配色，调节滑块改变音色质感
- 点击「自动」按钮启动随机演奏
