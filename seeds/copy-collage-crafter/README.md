# Copy Collage Crafter · 文案拼贴工坊

把一句文案撕成碎片，在流体渐变舞台上诉诸弹簧物理，重组为一张拼贴海报。

## 玩法

1. **投喂文案** — 粘贴句子（`Ctrl/⌘ + Enter` 快速撕裂），或点击灵感样本
2. **✂ 撕碎成拼贴** — 句子裂解为碎片，乱码揭示 + 模糊入场级联飞入舞台
3. **拖拽** — 每片碎片带惯性：拖动时随速度倾斜，松手抛飞后弹簧回弹归位
4. **双击碎片** — 随机换装（字体 / 字号 / 字重 / 颜色 / 斜体）
5. **⟲ 打乱布局** — 全体碎片弹簧 FLIP 重组
6. **描边幽灵字模式** — 切换为空心描边海报风
7. **⤓ 导出 PNG** — Canvas 重绘渐变背景 + 碎片，输出 1200×900 海报

## 微交互清单

- 流体网格渐变背景（多层 blob 漂移 + `mix-blend-mode: screen`）
- 微晶玻璃态容器（`backdrop-filter: blur` + 发光描边）
- 弹簧-阻尼物理拖拽（速度倾斜 / 惯性抛飞 / 回弹）
- 乱码揭示（scramble reveal）入场
- 正弦流场粒子背景
- 全部过渡曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 4 种氛围配色（极光 / 暮霞 / 深海 / 墨色）

## 技术

Zero-build Vanilla JS + CSS3 + HTML5，无任何依赖。字体：Inter / Outfit / Share Tech Mono。
