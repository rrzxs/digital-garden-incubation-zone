# Brand World Builder · 品牌世界铸造器

> 沉浸式品牌世界铸造器。五维 DNA 实时铸炼一整个宇宙的呼吸。

拖拽 DNA 元素至中央坩埚（或点击直接铸入），色彩 / 字体 / 几何 / 氛围 / 音律五个维度会协同改写整个世界——背景流体、粒子流场、坩埚核心、字体排版、形态几何、呼吸节律全部实时重组。

## 维度

| 维度 | 含义 | 影响范围 |
|------|------|----------|
| COLOR  | 色彩 | 世界色相、坩埚核心光晕、粒子配色、背景 blob 重染 |
| TYPE   | 字体 | 显示字族、字重、字距（标题、Logo 样本） |
| SHAPE  | 几何 | 坩埚核心形态、圆角、旋转、徽记 |
| MOOD   | 氛围 | 流体速度、粒子密度、品牌标语 |
| RHYTHM | 音律 | 粒子运动模式（脉冲/波/混沌/低鸣）、呼吸周期 |

## 交互

- **点击 DNA orb** — 直接将该元素铸入对应维度
- **拖拽 DNA orb 至坩埚** — 物理感更强的铸造手势（支持触摸）
- **数字键 1–5** — 快速切换维度
- **S** — 随机铸炼（五个维度同时随机）
- **R** — 清空坩埚重置
- **WORLD TONE 配色** — 切换基础氛围（余烬 / 星云 / 深渊 / 霜降）

## 技术栈

- Vanilla JS + CSS3 + HTML5（零构建）
- Inter / Outfit / Share Tech Mono（Google Fonts）
- `cubic-bezier(0.16, 1, 0.3, 1)` 非线性缓动贯穿所有微交互
- Canvas 粒子流场 + 鼠标力场吸附
- CSS 自定义属性驱动实时世界状态
- 流体网格渐变背景 + `backdrop-filter` 微晶玻璃态容器
