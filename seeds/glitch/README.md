# Glitch - 故障艺术文字效果

一个赛博朋克风格的故障艺术文字效果生成器，支持多种故障模式与高阶微交互。

## 功能特性

### 核心交互
- **实时文字输入**: 输入任意文字，实时预览故障效果
- **5种故障模式**: RGB_SPLIT、SLICE、NOISE、WAVE、CORRUPT
- **强度/速度调节**: 精确控制故障效果的强度和速度
- **一键随机化**: 随机生成文字、模式和参数

### 微交互
- **悬停扰动**: 鼠标悬停在显示区域时产生微故障
- **鼠标跟随**: 光标位置影响文字扭曲程度
- **点击触发**: 点击显示区域触发爆发式故障效果
- **文字揭示动画**: 随机化时文字以打字机+乱码方式揭示

## 技术实现

- 纯 Vanilla JS + CSS3，无构建依赖
- CSS `clip-path` 实现切片故障效果
- CSS `filter` 和 `transform` 实现色彩偏移和扭曲
- `requestAnimationFrame` 驱动 FPS 计数器
- 流体渐变背景 + 微晶玻璃态容器

## 设计规范

- 字体: Inter, Outfit, Share Tech Mono
- 动效曲线: `cubic-bezier(0.16, 1, 0.3, 1)`
- 色彩: 青色 (#00ffff)、品红 (#ff00ff)、黄色 (#ffff00)

## 使用方式

1. 打开 `index.html`
2. 输入想要显示的文字
3. 选择故障模式
4. 调节强度和速度参数
5. 点击 TRIGGER 触发爆发效果，或点击 RANDOMIZE 随机生成
