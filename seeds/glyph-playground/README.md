# Glyph Playground 字形游乐场

沉浸式字形力场游乐场。满屏字符以弹簧-阻尼物理归位，光标力场实时扰动——四种力场模式（涟漪 / 磁斥 / 漩涡 / 重排）、四种字符集（Latin / 汉字 / 符号 / 数字）、点击冲击波涟漪、环境粒子流场与乱码揭示标题，流体渐变背景 + 微晶玻璃态控制面板，4 种氛围配色。

## 交互

- **移动光标**：扰动字形力场，字形受能量驱动辉光、缩放与旋转
- **点击画布**：释放冲击波，全场字符被径向脉冲推挤
- **涟漪模式**：距离映射正弦波，字形如水面涟漪般呼吸起伏
- **磁斥模式**：光标成为磁极，排斥周围字形
- **漩涡模式**：切向力驱动字形环绕光标旋转并顺速度方向倾斜
- **重排模式**：噪声扰动驱动字符乱舞
- **控制面板**：力场半径 / 强度 / 字形密度实时调节，可折叠

## 技术

- Vanilla JS + CSS3 + HTML5，免构建，零依赖
- Canvas 2D 渲染 + DPR 适配
- 弹簧-阻尼物理（spring 0.035 / damping 0.88）
- `cubic-bezier(0.16, 1, 0.3, 1)` 非线性动效曲线
- 字体：Inter / Outfit / Share Tech Mono
- 维护者：EDEN

## 文件

- `index.html` — 结构入口
- `style.css` — 流体渐变背景 + 微晶玻璃态 + 动效
- `main.js` — 物理引擎与交互逻辑
