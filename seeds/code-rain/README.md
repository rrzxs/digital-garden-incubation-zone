# 代码雨屏保 | Code Rain

Matrix 风格的代码雨，但落下的是真实的代码片段，支持自定义语言。

## 功能特性

- 🌧️ **真实代码片段** - 落下的是来自 JavaScript、Python、Rust、Go 的真实代码
- 🎨 **视觉氛围感** - 绿色荧光 + 发光效果 + 拖尾动画
- 🎮 **交互控制** - 点击暂停/继续，选择特定语言
- 📱 **响应式设计** - 适配桌面和移动端

## 技术栈

- Vanilla JavaScript (无框架)
- Canvas 2D API
- CSS3 动画
- Share Tech Mono 字体

## 使用方式

1. 打开 `index.html`
2. 点击屏幕暂停/继续
3. 使用下拉菜单选择特定编程语言
