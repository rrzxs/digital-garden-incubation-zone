# VHS Filter Lab · 磁带滤镜实验室

把任何画面塞进 1985 年的录像机里。基于 Canvas 逐帧像素运算的实时 VHS 滤镜实验场。

## 功能

- **实时 VHS 信号管线**：磁迹失真带（tracking band）滚动、行抖动、随机行撕裂、RGB 色度分离、色彩渗溢、噪点颗粒、扫描线、暗角
- **传输控制**：PLAY / PAUSE / REW / FF — 倒带与快进注入高速失真并双向驱动时间码
- **磁带装入**：点击 `⏏` 或直接拖拽图片到屏幕，即刻成为磁带画面；默认为程序化生成的合成波演示场景
- **交互微动效**：光标掠过屏幕激起信号波纹，点击触发磁迹撕裂，`⚡` 按钮注入全场故障
- **6 种磁带工况预设**：SP 标准 / 旧磁带 / 广播级 / 故障暴走 / 褪色记忆 / 单色监视（预设切换带非线性数值插值过渡）
- **7 维信号调校滑杆**：噪点 / 色度 / 磁迹 / 抖动 / 扫描线 / 饱和 / 渗溢
- **快照导出**：一键导出带 OSD 时间码烧录的 PNG
- **4 种氛围配色**：磁带洋红 / 酸性绿 / 落日橙 / 北极蓝（流体渐变背景实时迁移）

## 技术

- 纯 Vanilla JS + CSS3 + HTML5，零依赖、免构建
- 720×405 内部分辨率像素运算，CSS 无损拉伸（VHS 柔焦加成）
- 动效曲线统一 `cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Outfit / Inter / Share Tech Mono

## 使用

直接用浏览器打开 `index.html`，或通过数字花园主页种子卡进入。
