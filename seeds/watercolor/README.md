# Watercolor 水彩秘境

> Where watercolor breathes with your touch.

**Susurrus (WEIGHT 0.93)** — Kuwahara 水彩 NPR + 鼠标交互 + 环境音效

## 交互逻辑

场景以实时的 Kuwahara 水彩 NPR 风格渲染，并响应光标移动——当你滑过画布时，笔触绽放，颜料晕染开来，每一丝手势都伴随着柔和的 ASMR 式喃喃低语音效，其音色随速度和压力而变化，让整个页面如同一幅鲜活的、会呼吸的水彩画。

## 技术实现

### 水彩渲染 (Canvas 2D + 噪声算法)

- **Simplex Noise**: 驱动笔触形状的不规则性，实现水彩颜料的自然晕染
- **Kuwahara 风格**: 通过多层径向渐变和椭圆变形模拟水彩的颗粒感和流动感
- **FBM (分形布朗运动)**: 多倍频叠加创造细腻的纹理层次

### 笔触系统

- **速度自适应宽度**: 移动越快笔触越细，越慢颜料越浓密
- **插值渲染**: 鼠标快速移动时自动在路径点之间插值，保证笔触连贯
- **双层晕染**: 主笔触 + 边缘晕染层，模拟真实水彩的渗透效果

### Web Audio API 音效

- **噪声发生器**: 滤波后的白噪声模拟水声/纸声
- **正弦振荡器组**: 3 个频率错开的振荡器产生柔和的底音
- **动态参数调制**: 根据速度调节音量、滤波器频率和音高

## 视觉特性

| 特性 | 实现 |
|------|------|
| 深色流体背景 | 四层动态 Blob + 超大模糊 + 流体动画 |
| 水彩效果 | Canvas 2D + Simplex Noise + 径向渐变 |
| 玻璃拟态 | `backdrop-filter: blur` + 微透明 + 微发光描边 |
| 动画缓动 | `cubic-bezier(0.16, 1, 0.3, 1)` |
| 自定义光标 | 跟随鼠标 + 颜色适配 + 速度响应 |

## 使用方式

1. **移动光标**: 在画布上移动即可看到水彩笔触绽放
2. **选择颜色**: 点击底部调色板切换颜料颜色
3. **清空画布**: 点击垃圾桶图标重置
4. **音效开关**: 点击音符图标切换环境音
