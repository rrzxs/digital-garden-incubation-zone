# Comfort Space Builder - 舒适空间构建器

沉浸式舒适空间构建体验。拖拽或点击元素面板中的道具，在你的私人空间中自由排列，创造属于自己的安宁角落。

## 功能

- **8种舒适元素**: 靠枕、蜡烛、植物、书本、茶杯、音乐、猫咪、窗户
- **拖拽布置**: 从面板拖入或点击添加，工作区内自由拖拽调整位置
- **双击移除**: 不想要的元素双击即可移除，附带优雅消失动效
- **4种氛围基调**: 温暖、清凉、梦幻、禅意 — 切换即时改变全局氛围
- **环境声场**: 雨声、炉火、微风、夜虫 — Web Audio API 合成白噪音
- **呼吸引导**: 4-4-4 呼吸法引导，配合脉动光环
- **能量语句**: 随机揭示温暖语句，逐字打字机动效
- **粒子流场**: Canvas 粒子系统随光标互动，连线网络
- **流体渐变背景**: 5层 mesh gradient 随氛围变色
- **微晶玻璃态容器**: backdrop-filter blur + 半透明边框

## 技术栈

- Vanilla JS + CSS3 + HTML5
- Web Audio API (环境音合成)
- Canvas 2D (粒子流场)
- CSS Animations + Transitions (cubic-bezier 非线性动效)
- 无构建依赖，即开即用
