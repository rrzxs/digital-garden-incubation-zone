# Pixel Chess Desk 像素棋桌

沉浸式像素国际象棋桌面。8×8 棋盘悬浮于流体渐变光雾中，棋子为手绘 8×8 像素精灵，落子以 `cubic-bezier(0.16, 1, 0.3, 1)` 弹簧曲线滑行，捕获迸裂为像素星尘。

## 交互

- **点选行棋**：点选己方棋子，圆点 = 行进、圆环 = 捕获
- **完整规则**：合法着法校验、将军 / 将杀 / 逼和判定、王车易位、吃过路兵、兵升变
- **人机模式**：切换后与贪心 + 随机混合的桌面 AI 对弈（AI 执黑）
- **悔棋 / 重开**：快照式历史回溯（人机模式自动回退两手）
- **战利品托盘**：实时陈列双方捕获的棋子
- **棋谱**：右侧滚动记录每手着法（含 `+` 将军 / `#` 将杀标记）
- **4 种氛围配色**：暮穴 / 苔原 / 余烬 / 潮汐，一键切换全局光雾与棋子配色

## 技术

- Vanilla JS + CSS3 + HTML5，免构建
- 完整国际象棋引擎（着法生成 → 王安全过滤 → 终局判定）
- FLIP 位移动画驱动棋子滑行；Web Animations API 驱动捕获粒子
- 微晶玻璃态容器（`backdrop-filter`）+ 多层模糊流体渐变背景 + 环境尘埃粒子
- 字体：Inter / Outfit / Share Tech Mono
