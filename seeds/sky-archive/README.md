# Sky Archive · 天空档案

沉浸式天空档案体验。拖拽时间刻度，让黎明、正午、黄昏与午夜在你的指尖缓慢呼吸；点击天空，把一颗流星、一群候鸟、一片积雨云收入只属于此刻的档案。流体渐变背景 + 微晶玻璃态容器 + 非线性动效。

## 核心交互

1. **时间擦除 (Time Scrub)** — 拖拽底部刻度，天空在 24 小时间连续呼吸：渐变色、地平线、太阳/月亮位置、星群与云朵密度全部联动
2. **AUTO 模式** — 点击 AUTO 让时间自动流转（约 200 秒一个昼夜循环），天空自主呼吸
3. **点击观察 (Click to Observe)** — 在天空任意位置点击，把"当前现象"记录为一条档案条目，伴随流星划过 / 候鸟掠过 / 积雨云堆积 / 气球升空 / 不明光体悬停的视觉特效
4. **5 种现象 (Phenomena)** — 流星 ☄ / 候鸟群 ⌒ / 积雨云 ▢ / 气球 ○ / 不明光体 ◬
5. **档案台账 (Ledger)** — 所有观测按时间倒序排列，点击任意条目弹出详情卡（含诗意观测笔记与坐标）
6. **相位年鉴 (Almanac)** — 4 个相位卡片（黎明/正午/黄昏/午夜），点击直接平滑跳转
7. **重放观测 (Replay)** — 一键重放所有已记录现象的视觉效果
8. **4 种氛围配色 (Themes)** — Dawn 黎明 / Ember 炽光 / Abyss 深渊 / Mono 单色

## 交互方式

- **拖拽底部刻度**：天空随时间流动
- **AUTO 按钮**：开启/关闭自动昼夜循环
- **点击天空**：把"当前现象"记录为档案条目（先在现象选择器里选好要观察什么）
- **现象选择器**：流星 / 候鸟群 / 积雨云 / 气球 / 不明光体
- **档案台账**：点击条目查看详情；hover 显示删除按钮
- **相位卡片**：点击平滑跳转到对应时刻
- **右下角配色**：4 种氛围配色

## 审美系统

- **流体渐变天空**：24 小时关键帧插值（hexLerp 平滑过渡），渐变层 + 地平线层 + 天体辉光层分离呼吸
- **天体轨迹**：太阳/月亮沿抛物线弧从地平线升起到天顶再落下
- **星群 / 云朵**：星群仅在夜间可见并闪烁带十字耀斑；云朵随时间相位调整可见度与色温
- **粒子流场**：Simplex 噪声驱动的飘浮微粒，鼠标附近被吸引
- **微晶玻璃态容器**：`backdrop-filter: blur(26px)` + 发光描边 + 光标跟随辉光
- **非线性动效**：统一 `cubic-bezier(0.16, 1, 0.3, 1)` 曲线
- **字体**：Outfit (展示) / Inter (正文) / Fraunces 斜体 (档案标题) / Share Tech Mono (数据)

## 技术栈

- Vanilla JS + CSS3 + HTML5 (零构建)
- Simplex Noise (内联实现) 驱动粒子流场
- Canvas 2D：星群闪烁、云朵漂移、流星拖尾、候鸟编队、点击涟漪
- CSS 变量主题系统 + `backdrop-filter` 玻璃态
- IntersectionObserver 章节揭示（墨迹浮现）
- 自定义光标（glow + ring，observe-mode 切换）
- 指针事件拖拽时间刻度（pointer capture）
