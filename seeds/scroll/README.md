# Scroll · 滚动之境

沉浸式滚动微交互体验场。

## 功能

- **视差深度层** — 多层元素以不同速率响应滚动，创造空间纵深
- **弹性物理卡片** — 弹簧-阻尼模型驱动卡片过冲与回弹
- **滚动驱动形变** — 滚动速度实时驱动元素拉伸、旋转、缩放
- **揭示与消隐** — 4种揭示动画（裁切/滑入/缩放/模糊）由滚动触发
- **粒子流场** — 鼠标力场驱动的背景粒子系统
- **滚动速度可视化** — 实时显示滚动速度与进度

## 技术栈

- Vanilla JS + CSS3 + HTML5
- 无构建依赖
- 字体: Inter, Outfit, Share Tech Mono
- 动效曲线: cubic-bezier(0.16, 1, 0.3, 1)

## 4种氛围配色

- Aurora (极光)
- Ember (余烬)
- Ocean (深海)
- Void (虚空)
