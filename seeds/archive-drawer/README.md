# Archive Drawer - 记忆档案抽屉

> 沉浸式记忆档案抽屉柜：磁吸拉手、非线性开合、微晶玻璃态档案卡与指针光泽追踪。

## ✨ 特性

- **五层抽屉柜**: 2026 / 2025 / 2024 / SIGNAL / SKETCH 五个归档层，共 22 份档案
- **非线性开合动效**: 抽屉以 `grid-template-rows: 0fr → 1fr` + `cubic-bezier(0.16, 1, 0.3, 1)` 曲线展开，开合瞬间发射冲击波光环
- **磁吸拉手**: 拉手跟随光标在抽屉面板内横向偏移，悬停时呼吸发光
- **档案卡级联入场**: 卡片依次以 `延迟 × 55ms` 从模糊与位移中浮现
- **3D 倾斜跟随**: 档案卡随指针位置做 `perspective` 倾斜，底色光带同步延展
- **指针光泽追踪**: 玻璃容器表面随光标移动的高光层 (`--mx / --my`)
- **全文检索**: 实时过滤档案卡，无命中抽屉自动降饱和弱化
- **随机调档**: 一键抽取随机档案，自动开屉、滚动定位并高亮闪烁
- **详情透视层**: 点击卡片进入全屏玻璃模态，内容级联入场
- **三套氛围配色**: NEBULA / EMBER / MINT 一键切换
- **键盘可达**: `↑↓` 切换抽屉、`ENTER` 开合 / 打开详情、`ESC` 逐层收起
- **环境浮尘 + 流体渐变背景**: 四团超大模糊渐变球以混合模式缓慢漂移

## 🎨 设计亮点

- **微晶玻璃态 UI**: `backdrop-filter: blur(26px) saturate(150%)` + 微弱发光描边与内高光
- **流体网格渐变背景**: 多层渐变球体 + `mix-blend-mode: screen` + SVG 噪点颗粒
- **非线性微交互**: 全站统一 `cubic-bezier(0.16, 1, 0.3, 1)` 缓动
- **等宽档案语言**: Share Tech Mono 承担编号 / 时间 / 元信息，Outfit 与 Inter 负责展示与正文

## 🚀 使用方式

直接在浏览器中打开 `index.html` 即可体验。

### 操作说明

1. **开合抽屉**: 点击任意抽屉面板（或聚焦后按 `ENTER`）
2. **查看详情**: 点击展开后的档案卡
3. **检索**: 顶部检索框输入关键词（按 `ESC` 清空）
4. **随机调档**: 点击打散图标按钮
5. **切换配色**: 点击太阳图标按钮

## 🛠️ 技术实现

- **核心框架**: Vanilla JavaScript (零依赖，免构建)
- **展开动画**: CSS Grid `0fr → 1fr` 高度过渡
- **倾斜跟随**: 指针事件驱动 CSS 自定义属性 (`--rx / --ry`)
- **可访问性**: `aria-expanded` / `aria-controls` / `role="dialog"` / 焦点管理 / `prefers-reduced-motion`
