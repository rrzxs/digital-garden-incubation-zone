# Archive Score Index · 档案评分索引

沉浸式档案评分索引工具。在评级台上为卷宗打分（5 维度 × 可调权重），加权综合分引擎实时驱动活体索引榜 —— FLIP 物理重排、乱码揭示、数字滚动、冲击波涟漪与粒子流场。

## 特性
- **加权综合分引擎**：史料价值 / 稀有程度 / 完整度 / 时效活性 / 复用潜力，五维滑块 + 右侧行进器实时调权，全榜即刻重算
- **FLIP 活体重排**：分数变化触发非线性位移动画（cubic-bezier(0.16, 1, 0.3, 1)），升降位 Δ 徽章提示
- **评级分层**：S / A / B / C / D 五级 tier，色彩徽章 + 微条形图（透明度映射权重）
- **高阶微交互**：乱码揭示入场、点击条目升分激化冲击波、重新校准 ±3 漂移、随机抽卷
- **审美**：流体渐变背景（多团 blur + mix-blend-mode screen）+ 微晶玻璃态容器 + 噪点颗粒层
- **4 种氛围配色**：曜石 / 极光 / 熔金 / 幽紫（localStorage 持久化）

## 技术
Vanilla JS + CSS3 + HTML5，免构建。字体：Inter / Outfit / Share Tech Mono。
