# Morph Ink Cursor · 墨变光标

沉浸式墨变光标微交互体验场。光标化身为一滴带弹簧-阻尼物理的活体墨滴：移动时沿运动方向延展、垂直方向收缩，速度越快形变越剧烈；墨迹拖尾以 metaball 柔光渲染留下余晖。

## 特性

- **3 种墨迹模式**：拖尾（速度驱动密度）/ 迸溅（快速移动或点击迸发墨滴）/ 环绕（墨滴绕光标轨道环绕）
- **弹簧-阻尼墨滴形变**：18 顶点独立弹簧物理，实时非线性形变
- **墨脉冲冲击波**：多层涟漪扩散
- **可调参数**：粘滞强度、墨滴密度、扩散半径
- **4 种氛围配色**：墨玄 / 烬火 / 青瓷 / 幽兰
- 流体渐变背景 + 微晶玻璃态控制面板 + 遥测 HUD

## 技术

Vanilla JS + Canvas 2D + CSS3，免构建。动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`。字体：Inter / Outfit / Share Tech Mono。
