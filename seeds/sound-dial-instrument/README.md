# Sound Dial Instrument — 声波刻度盘

沉浸式声音刻度盘乐器。中央主刻度盘选择音高（离散音阶档位 + 弹拨发声），四枚环绕子刻度盘实时塑形音色——TONE 滤波、ECHO 回声、DRIVE 驱动饱和、SPACE 空间延展。

## 交互
- **拖拽刻度盘**：沿圆周旋转调节，弹簧-阻尼物理回弹
- **主盘**：跨过音阶档位即弹拨发声；键盘 `1-9` 演奏，`空格` 重弹当前音
- **弹拨 / 持续音 / 琶音 / 随机**：四种演奏模式
- **四种音阶**：五声 / 多利亚 / 利底亚 / 和风
- **主题按钮**：星云紫 / 极光绿 / 熔岩橙 / 霜蓝 四种氛围配色

## 技术
- Vanilla JS + CSS3 + HTML5，免构建
- Web Audio 实时合成（振荡器 + 低通滤波 + WaveShaper 驱动 + 延迟回声）
- 弹簧-阻尼刻度物理、粒子流场背景、乱码揭示标题、涟漪冲击波
- 动效曲线：`cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Inter / Outfit / Share Tech Mono
