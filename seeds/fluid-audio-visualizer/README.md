# Fluid Audio Visualizer

沉浸式流体音频可视化器。通过麦克风实时捕获音频，以流体渐变背景 + 微晶玻璃态容器呈现频谱之美。

## 特性

- **4种可视化模式**: 频谱柱、波形线、径向谱、粒子场
- **4种氛围配色**: 极光 / 余烬 / 深海 / 霓虹
- **实时音频分析**: 基于 Web Audio API 的频谱与波形数据
- **演示音源**: 内置锯齿波振荡器演示，无需麦克风
- **鼠标/触摸交互**: 粒子场模式支持光标力场交互
- **流体网格渐变背景**: 5层动态流体 blob 营造氛围感
- **微晶玻璃态容器**: 毛玻璃 + 发光描边 + 非线性过渡

## 技术栈

- Vanilla JS + CSS3 + HTML5 (零构建)
- Web Audio API (AnalyserNode)
- Canvas 2D 渲染
- CSS cubic-bezier(0.16, 1, 0.3, 1) 动效曲线

## 使用

打开 `index.html`，点击画面启动麦克风，或在控制栏点击音符图标启动演示音源。
