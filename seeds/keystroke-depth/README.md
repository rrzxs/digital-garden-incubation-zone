# Keystroke Depth 按键深度

沉浸式按键力场体验。每一次击键都在画布中心绽放涟漪，字符以非线性动效飞散，粒子被力场推动偏转，营造击键即创造的沉浸感。

## 核心交互

- **涟漪力场**: 按键触发多层同心涟漪，带有微变形噪声
- **粒子迸射**: 字符驱动的方向性粒子爆发，带尾迹与发光
- **浮动字符**: 击键字符以非线性动效浮升消散
- **力场偏转**: 涟漪推动流场粒子偏移轨迹
- **节奏感知**: 检测打字节奏，快速连击时涟漪更加强烈
- **涟漪连接线**: 相邻涟漪间自动绘制拓扑连接线

## 参数控制

- **涟漪力**: 控制涟漪扩散范围与速度
- **衰减**: 控制涟漪与粒子的生命周期
- **粒子**: 每次击键的粒子迸射数量

## 配色方案

黑曜石 / 极光 / 余烬 / 霜降 四种氛围配色

## 技术栈

- Vanilla JS + Canvas 2D
- CSS3 流体渐变背景 + 微晶玻璃态容器
- 非线性缓动 cubic-bezier(0.16, 1, 0.3, 1)
- 零依赖，免构建
