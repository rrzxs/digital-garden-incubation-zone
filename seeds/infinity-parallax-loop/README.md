# Infinity Parallax Loop 无限视差循环

沉浸式无限视差循环视觉体验。7层视差深度层响应鼠标位移，配合粒子流场、轨道运动、脉冲冲击波与流体渐变背景，营造无限纵深的宇宙级视觉空间。

## 交互方式

- **鼠标移动** — 扰动所有视差层的位移偏移，近层响应剧烈、远层微弱
- **鼠标点击** — 产生脉冲冲击波，震散附近粒子
- **滚轮** — 调节视差深度系数（0.2 ~ 3.0）
- **暂停/播放** — 冻结或恢复全部动效

## 视差层结构

| 层 | 深度系数 | 内容 |
|---|---|---|
| Stars | 0.05 | 200颗闪烁星点 |
| Grid | 0.10 | 无限滚动透视网格 |
| Rings | 0.20 | 6层脉冲同心环 |
| Floaters | 0.35 | 12个漂浮光斑 |
| Orbiters | 0.50 | 8个轨道运动光点 |
| Center | 0.00 | 无限符号中心件 |
| Particles | 0.60 | 60个漂浮粒子 + 120个Canvas粒子 |

## 配色方案

宇宙 / 深海 / 余烬 / 极光

## 技术栈
