# MotionPath Gallery Fold 折叠画廊

## 简介
沉浸式折叠画廊交互体验。8 种数学运动路径（轨道 / 无限 / 螺旋 / 波浪 / 利萨如 / 玫瑰线 / 内旋轮线 / 噪声场）以 3D 透视折叠卡片呈现，弹簧-阻尼物理驱动的折叠/展开动效，3 种折叠模式（扇形 / 级联 / 螺旋）× 4 种氛围配色，粒子流场与脉冲冲击波。

## 技术栈
- Vanilla JS + CSS3 + HTML5（免构建）
- CSS 3D Transform + perspective
- Canvas 2D 运动轨迹绘制
- Simplex Noise 流场
- 弹簧-阻尼物理模型

## 交互
- **点击卡片**：展开/折叠，触发弹簧物理动效
- **悬停卡片**：轻微上浮反馈
- **折叠模式**：扇形 / 级联 / 螺旋 三种布局切换
- **全部折叠/展开**：批量控制
- **洗牌**：随机重排路径类型，弹性过渡
- **脉冲冲击**：冲击波扰动所有卡片
- **速度调节**：控制轨迹动画速度
- **配色切换**：黑曜石 / 极光 / 余烬 / 虚空

## 字体

- `cubic-bezier(0.16, 1, 0.3, 1)`
