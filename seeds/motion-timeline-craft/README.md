# Motion Timeline Craft 动效时间线

> 沉浸式关键帧编排工具。在微晶玻璃态时间线上拖拽关键帧、切换非线性缓动曲线、实时预览复合动效，并一键导出 CSS。

## 核心特性

- **关键帧编辑器**：添加、拖拽、删除关键帧，实时调整时间位置与数值
- **非线性缓动库**：8 种缓动曲线（线性 / 指数缓出 / 回弹 / 弹性 / 弹跳 / 正弦等），附带可视化曲线预览
- **7 种动画属性**：位移 X/Y、缩放、旋转、不透明度、模糊、色相旋转
- **实时预览舞台**：动效球体即时响应关键帧与缓动变化
- **可拖拽播放头**：时间线轨道支持点击擦洗与播放头拖拽
- **预设编排库**：8 套精心设计的动效预设（脉冲呼吸 / 弹簧入场 / 漂浮悬浮 / 色相轮转 等）
- **CSS 一键导出**：自动生成 `@keyframes` 与 `animation` 规则，复制即用
- **播放控制**：播放 / 暂停、4 档速度（0.25× ~ 2×）、循环开关
- **遥测面板**：FPS、关键帧数、进度百分比、播放状态实时监控

## 交互指南

| 操作 | 效果 |
|------|------|
| 拖拽时间线关键帧圆点 | 调整关键帧时间位置 |
| 点击时间线空白处 | 擦洗播放头至该位置 |
| 右键关键帧 | 删除该关键帧 |
| `Space` | 播放 / 暂停 |
| `Delete` / `Backspace` | 删除选中关键帧 |
| `Esc` | 取消选择 / 关闭预设浮层 |

## 审美风格

- **流体网格渐变背景**：4 层超大模糊色块以 `mix-blend-mode: screen` 呼吸流动
- **微晶玻璃态容器**：`backdrop-filter: blur(40px) saturate(1.6)` + 发光描边
- **非线性动效**：全局采用 `cubic-bezier(0.16, 1, 0.3, 1)` 缓动曲线
- **4 种氛围配色**：深海 / 极光 / 余烬 / 虚空

## 技术栈

- Vanilla JS + CSS3 + HTML5（零构建）
- Canvas 2D（时间线曲线绘制 + 环境粒子流场）
- 字体：Inter / Outfit / Share Tech Mono
