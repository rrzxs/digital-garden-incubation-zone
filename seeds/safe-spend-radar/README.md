# Safe Spend Radar · 安全消费雷达

沉浸式个人消费安全雷达。六维预算健康实时扫描，SVG 雷达拓扑可视化，预算溢出预警与智能建议。

## 特性

- **六维消费雷达** — 餐饮 / 交通 / 购物 / 娱乐 / 居家 / 健康六大消费维度，SVG 雷达图实时扫描
- **旋转扫描动画** — 雷达扫描线持续旋转，模拟真实雷达探测效果
- **预算管理** — 拖动滑块设定每品类预算上限，实时进度条反馈
- **智能建议引擎** — 根据超支情况、预算使用率与消费占比自动生成个性化建议
- **健康状态徽章** — 安全 / 警告 / 危险三级状态，雷达色实时切换
- **4 种快捷场景** — 学生 / 自由职业 / 家庭 / 极简预设，一键载入
- **周期切换** — 周 / 月 / 年三种预算周期

## 设计

- **流体网格渐变背景** — 4 层 blob 模糊球 + 噪声颗粒纹理
- **微晶玻璃态容器** — `backdrop-filter: blur(26px)` + 发光描边
- **粒子流场** — Simplex 噪声驱动的 60 粒子鼠标排斥交互
- **非线性动效** — `cubic-bezier(0.16, 1, 0.3, 1)` 物理曲线
- **字体** — Inter / Outfit / Share Tech Mono
- **4 种氛围配色** — Aurora 极光 / Ember 余烬 / Abyss 深渊 / Orchid 兰若

## 技术栈

Vanilla JS + CSS3 + HTML5，零构建依赖。
