# Spend Card Mosaic · 消费卡片马赛克

沉浸式消费总览微交互体验。将月度支出可视化为微晶玻璃态卡片马赛克，流体渐变背景之上，每一次悬停、点击与切换都是非线性动效的呼吸。

## 交互特性

- **卡片马赛克** — 9 个消费类别以差异化尺寸拼贴于 6 列弹性网格
- **3D 倾斜 + 眩光** — 悬停时卡片跟随光标透视倾斜，径向眩光实时追踪
- **FLIP 详情展开** — 点击卡片从原位弹性飞至中心，展开 12 周趋势线与构成拆解
- **数字递增** — 总支出、预算环、日均均以 easeOutExpo 曲线滚动呈现
- **涟漪 + 粒子迸射** — 点击即刻激发色彩涟漪与 14 颗迸射粒子
- **月份切换** — 三期数据错峰重入场动画
- **4 种氛围配色** — Aurora / Ember / Midnight / Bloom
- **环境粒子流场** — Canvas 漂浮粒子随主题变色

## 技术

Vanilla JS + CSS3 + HTML5，零构建。字体：Inter / Outfit / Share Tech Mono。全局动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`。
