# Type Forge — 字形锻造

沉浸式字形锻造实验室。输入文字，每个字符对光标产生弹簧物理响应。五种锻造模式实时形变字符，配合脉冲冲击波、Simplex 噪声粒子流场与微晶玻璃态容器。

## 核心交互

- **五种锻造模式**: Magnetic (磁力吸引) / Repel (排斥推开) / Wave (噪声波浪) / Glitch (故障乱码) / Gravity (重力坠落)
- **弹簧-阻尼物理**: 每个字符独立维护位移、速度、缩放与旋转，非线性缓动归位
- **脉冲冲击波**: 点击画布或按空格触发径向冲击波，涟漪环传播影响所有字符
- **力场半径**: 光标周围的字符感知磁场范围实时可调
- **Simplex 噪声粒子流场**: 80 个环境粒子沿噪声场流动，响应光标力场
- **可变排版**: 实时调节字号、字重、字距，逐字符延迟揭示入场动画
- **四种氛围配色**: Aurora (极光) / Ember (烬火) / Forest (森林) / Void (虚空)

## 快捷键

| 按键 | 功能 |
|------|------|
| `1`–`5` | 切换锻造模式 |
| `Space` | 触发脉冲冲击波 |
| `R` | 重置所有参数 |

## 技术栈

- Vanilla JS + CSS3 + HTML5 (零构建)
- Inter / Outfit / Share Tech Mono 字体
- 弹簧-阻尼物理模型
- Simplex 2D 噪声 (内嵌实现)
- Canvas 2D 粒子系统
- CSS Custom Properties 动态配色
- `cubic-bezier(0.16, 1, 0.3, 1)` 非线性动效曲线
