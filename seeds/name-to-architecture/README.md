# Name to Architecture · 名字建筑学

每一个名字，都是一座待建成的建筑。

输入任意名字（支持中英文），算法通过 FNV-1a 哈希将其映射为确定性随机种子（mulberry32），同一名字永远生成同一座建筑——层数、收分塔身、裙楼配翼、尖顶信标与亮灯窗格全部由名字本身决定。

## 特性

- **确定性生成**：名字 → 哈希种子 → 蓝图（STYLE / FLOORS / HEIGHT / SEED 实时显示）
- **非线性建造动画**：楼层以 expo-out 曲线错峰坠落生长，尖顶弹性伸展，信标呼吸脉动
- **可交互视口**：拖拽旋转（弹簧阻尼相机）、滚轮缩放、双击重置视角
- **微交互细节**：HUD 名字乱码揭示、输入拒绝抖动、建造尘埃粒子、窗光闪烁
- **4 种氛围配色**：晨雾 / 暮色 / 深海 / 霓虹
- **审美材质**：流体渐变背景（多 blob 漂移 + 混合模式）+ 微晶玻璃态容器 + 颗粒噪点

## 技术栈

- 纯 Vanilla JS + CSS3 + HTML5，零依赖免构建
- Canvas 2D 等距投影 + 画家算法深度排序
- 动效统一采用 `cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Inter / Outfit / Share Tech Mono

## 使用

直接用浏览器打开 `index.html`，或通过数字花园主页的种子卡片进入。
