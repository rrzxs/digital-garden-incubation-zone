# Nocturne — Waitlist Launch Page

> 为深度思考者打造的候补名单发布页。流体渐变背景 + 微晶玻璃态容器 + 非线性动效。

## 概述

一个完整的 Waitlist 候补名单落地页 Web App，模拟虚构产品 "Nocturne"（专注创作空间）的发布预热。包含完整的用户旅程：从首屏视觉冲击 → 特性展示 → 用户证言 → 路线图 → 多步候补注册 → 成功庆祝。

## 技术栈

- **Vanilla JS + CSS3 + HTML5** — 免构建，零依赖
- **字体**: Inter (正文) · Outfit (展示) · Share Tech Mono (数据/标签)
- **动效曲线**: `cubic-bezier(0.16, 1, 0.3, 1)` (Expo Out) 为核心缓动

## 核心交互

| 模块 | 描述 |
|------|------|
| **流体粒子场** | Simplex 噪声驱动的粒子流场，光标产生排斥力，邻近粒子连线 |
| **光标光晕** | 跟随鼠标的柔光球，`mix-blend-mode: screen` 叠加 |
| **磁性按钮** | 鼠标靠近时按钮被磁力吸引偏移 |
| **标题逐字揭示** | Hero 标题字符按非线性延迟从下方浮现 |
| **倒计时翻牌** | 距离发布的实时倒计时，数字翻转动画 |
| **数字递增** | 统计数字进入视口时从 0 缓动递增 |
| **3D 倾斜卡片** | 特性卡片跟随鼠标做透视倾斜 |
| **证言无限滚动** | 客户证言横向无限轮播，悬停暂停 |
| **多步注册表单** | 邮箱 → 角色选择 → 成功，步骤指示器同步 |
| **成功庆祝** | 粒子彩纸爆发动画 + 候补编号递增揭示 |
| **Toast 分享** | Web Share API / 剪贴板回退 + Toast 提示 |

## 审美设计

- **配色**: Aurora Nocturne — 青蓝 `#6ee7ff` × 紫 `#a78bfa` × 粉 `#f472b6`
- **背景**: 5 个 `blur(120px)` 渐变球体以不同周期漂移 + 噪点叠加层
- **容器**: `backdrop-filter: blur(30px)` 微晶玻璃态 + 发光描边
- **排版**: 大字号 Outfit 800 标题 + 渐变文字裁切
