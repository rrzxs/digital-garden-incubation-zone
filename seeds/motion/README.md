# Motion 韵动

高阶微交互体验场。鼠标在舞台中移动时，卡片和粒子会产生基于弹簧-阻尼模型的非线性动力学响应。

## 核心交互

- **弹簧物理**: 每张卡片拥有独立的弹簧刚度与阻尼系数，靠近鼠标时产生弹性偏移
- **粒子场**: 80 个粒子跟随鼠标方向流动，带有拖尾轨迹与连线效果
- **双模式**: 编排模式（吸引）/ 游乐场模式（排斥），鼠标对元素产生相反方向的力
- **4 种配色**: 黑曜石 / 极光 / 余烬 / 霜降

## 技术实现

- 纯 Vanilla JS + Canvas 2D 渲染
- 弹簧-阻尼物理模型 (`spring-damper`)
- `requestAnimationFrame` 驱动的 60fps 动画循环
- CSS `backdrop-filter` 微晶玻璃态容器
- `cubic-bezier(0.16, 1, 0.3, 1)` 非线性缓动曲线
- 全响应式布局，支持移动端触控
