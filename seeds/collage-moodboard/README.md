# Collage Moodboard 拼贴情绪板

沉浸式拼贴情绪板。在流体渐变背景上自由拼贴便签、色卡与程序化图像碎片——弹簧-阻尼物理驱动的拖拽与抛掷、边界弹性碰撞、速度姿态倾斜、点击脉冲冲击波推开邻近碎片、光标光泽追踪与乱码揭示标题。

## 交互

- **拖拽 / 抛掷**：抓取碎片甩出，带惯性、摩擦与边界弹性反弹，飞行中随速度倾斜
- **点击空白处**：发射脉冲冲击波，推开周围碎片（钉住的碎片免疫）
- **双击碎片**：置顶 + 小脉冲惊喜
- **便签**：可直接编辑文字；**色卡**：点击 COPY 复制 HEX；**碎片**：程序化渐变艺术
- **📌 钉住**：固定碎片位置（便签钉住后可整体拖拽）
- **洗牌**：碎片以弹簧物理级联重组为网格
- **4 种氛围配色**：Aurora / Dusk / Mono / Tropic，实时切换流体背景与粒子色彩

## 技术

Vanilla JS + CSS3 + HTML5，免构建。Inter / Outfit / Share Tech Mono 字体，`cubic-bezier(0.16, 1, 0.3, 1)` 非线性动效曲线，微晶玻璃态容器（`backdrop-filter` + 发光描边）。
