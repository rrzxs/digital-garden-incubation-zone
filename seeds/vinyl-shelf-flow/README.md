# Vinyl Shelf Flow · 黑胶流动货架

沉浸式黑胶唱片微交互体验。从微晶玻璃态货架中抽出一张唱片，飞行动画将它送上唱盘：唱臂落下、频闪呼吸、流场粒子随节拍脉动。

## 核心交互

- **抽盘上盘**：点击任意封面，唱片以非线性轨迹飞向唱机，落盘即刻播放
- **刮擦物理**：拖动黑胶即可打碟，松手后弹簧-阻尼模型驱动惯性回归目标转速
- **转速 / 音调**：33⅓ ↔ 45 RPM 切换，±8% Pitch 滑杆实时变调计时
- **底噪合成**：Web Audio 白噪声带通滤波模拟黑胶炒豆声（Crackle）
- **氛围配色**：暮紫 / 琥珀 / 墨翠 / 银盐 四种流体渐变氛围
- **微交互细节**：标题乱码揭示、封面 3D 倾角悬浮、标签错峰入场、上盘冲击波粒子

## 技术

Vanilla JS + CSS3 + HTML5，免构建。字体：Inter / Outfit / Share Tech Mono。
动效曲线统一采用 `cubic-bezier(0.16, 1, 0.3, 1)`。

## 文件

- `index.html` — 结构
- `style.css` — 流体渐变背景 + 微晶玻璃态容器 + 非线性动效
- `main.js` — 转动物理、粒子流场、Web Audio、交互逻辑
