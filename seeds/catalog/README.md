# Catalog · 策展陈列室

> 沉浸式策展产品陈列室。十二件器物被安放在微晶玻璃架上，磁吸标签筛选、3D 倾斜卡片物理、展开式详情覆盖层。

## 特性

- **流体网格渐变背景** — 5 层 blob 动画 + 颗粒噪点叠加
- **微晶玻璃态容器** — `backdrop-filter` + 发光描边 + 内高光
- **非线性动效** — 全局 `cubic-bezier(0.16, 1, 0.3, 1)` 缓动曲线
- **3D 倾斜卡片** — 鼠标驱动透视旋转 + 光泽跟随 + 弹性字形浮出
- **磁吸标签筛选** — 滑动指示器 + 错峰入场/退场动画
- **展开式详情覆盖层** — 底部抽屉弹出 + 背景模糊 + ESC/点击关闭
- **粒子流场** — 60 粒子带连接线 + 鼠标力场吸引
- **4 种氛围配色** — Aurora 极光 / Ember 余烬 / Abyss 深渊 / Orchid 兰若

## 技术栈

- Vanilla JS + CSS3 + HTML5（零构建）
- Google Fonts: Inter / Outfit / Share Tech Mono
