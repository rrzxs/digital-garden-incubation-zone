# World Ticker — 全球脉搏

沉浸式世界事件实时脉冲可视化。基于公开统计数据的模拟估算，将全球互联网每秒发生的数百万次事件以流体粒子场、微晶玻璃态容器与非线性动效呈现。

## 核心交互

- 实时模拟 Google 搜索、邮件发送、推文发布、YouTube 观看、电商订单、GitHub Stars、Instagram 照片、CO₂ 排放等 8 类世界事件
- 双侧滚动 Ticker 流：左右两列随机生成带有国家标签的事件卡片，配合滑入动效
- 中央英雄卡片：总事件计数器 + 运行时间 + 进度条 + 呼吸脉冲环
- 底部统计轨道：8 个微晶玻璃态卡片实时更新各自计数与进度条
- 粒子流场背景：60 个粒子在画布上流动，鼠标产生吸引力场，近距粒子间绘制连接线
- 鼠标跟随光晕
- 4 种氛围配色：深海 / 极光 / 余烬 / 霓虹
- 速度调节：0.5x / 1x / 3x / 10x
- 暂停 / 全屏控制

## 技术栈

- Vanilla JS + CSS3 + HTML5
- Canvas 粒子系统
- CSS Fluid Mesh Gradient 背景
- Glassmorphism 容器
- cubic-bezier(0.16, 1, 0.3, 1) 非线性缓动
- 字体：Inter, Outfit, Share Tech Mono
