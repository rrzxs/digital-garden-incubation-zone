# Cognitive Load Scoring · 认知负荷计分仪

> 沉浸式六维认知负荷评估工具。拖动维度滑块,实时重算加权综合分,呼吸态负荷核心、雷达拓扑与针对性优化建议同步响应。

## 体验

- **六维评分模型** — 信息密度 / 上下文切换 / 决策复杂度 / 工作记忆 / 视觉杂乱 / 时间压力,每维 0–10,带差异化权重。
- **加权综合分** — 按权重归一化为 0–100,映射 A→F 五级判定(极轻 / 轻量 / 中度 / 较高 / 严重)。
- **呼吸态负荷核心** — 进度环 + 脉动同心环,高分时进入"紧绷"呼吸态。
- **实时雷达拓扑** — Canvas 绘制六边形雷达,顶点高亮、网格、发光描边随配色切换。
- **维度排名条** — 按加权得分排序,首要瓶颈维度自动给出优化建议。
- **预设场景** — 阅读 / 仪表盘 / 结账流 / 极简 / 混乱 一键载入典型负荷画像。
- **4 种氛围配色** — Aurora 极光 / Ember 余烬 / Abyss 深渊 / Orchid 兰若。

## 审美与交互

- 流体网格渐变背景(5 颗高斯模糊 blob + screen 混合 + SVG 噪点颗粒层)
- 微晶玻璃态容器(`backdrop-filter: blur` + 发光描边)
- 全局非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 粒子流场 + 鼠标引力 + 近邻连线
- 点击涟漪层、滑块脉冲、卡片错峰入场

## 技术栈

Vanilla JS + CSS3 + HTML5,零构建、零依赖。字体:Inter / Outfit / Share Tech Mono。

## 文件结构

```
cognitive-load-scoring/
├── index.html   # 结构:三栏布局 (评分 / 核心 / 雷达)
├── style.css    # 流体背景 + 玻璃态 + 非线性动效 + 4 主题

```

## 使用

直接用浏览器打开 `index.html`。拖动左侧滑块、点击预设或切换右上角色板即可。
