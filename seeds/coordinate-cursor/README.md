# Coordinate Cursor — 坐标光标

沉浸式非线性坐标空间体验。光标化作坐标探测器，实时扭曲、扰动网格空间，配合轨迹流、速度向量与点击涟漪。

## 核心交互

- **扭曲模式**：光标推挤周围网格点，产生空间弯曲效果
- **涟漪模式**：光标产生同心波纹，网格节点随波振荡
- **磁力模式**：光标产生旋转磁场，网格节点环绕运动
- **点击涟漪**：点击任意位置产生扩散波纹
- **实时数据**：坐标、速度、角度等参数实时显示

## 技术栈

- Vanilla JS + Canvas 2D
- CSS3 流体渐变 + 微晶玻璃态
- 非线性缓动 `cubic-bezier(0.16, 1, 0.3, 1)`

## 配色
