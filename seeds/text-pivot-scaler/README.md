# Text Pivot Scaler — 文字枢纽缩放

沉浸式文字枢纽缩放交互体验。输入文字，光标作为枢纽驱动字符围绕缩放旋转。

## 核心交互

- **光标力场**: 鼠标位置作为枢纽点，影响范围内字符产生缩放、旋转、位移响应
- **4种力场模式**: 缩放 / 轨道 / 波浪 / 爆炸
- **乱码揭示**: 字符从随机乱码逐个揭示为真实文字
- **脉冲冲击波**: 点击画布或按钮触发扩散冲击波
- **实时统计**: 距离、角度、缩放值实时显示

## 技术栈

- Vanilla JS + CSS3 + HTML5
- Simplex Noise 2D (内联实现)
- 弹簧-阻尼物理模型
- 零构建依赖

## 力场模式

| 模式 | 效果 |
|---|---|
| 缩放 | 光标附近字符放大旋转，近大远小 |
| 轨道 | 字符围绕光标旋转偏转 |
| 波浪 | 正弦波浪沿字符序列传播 |
| 爆炸 | 光标排斥周围字符弹射散开 |

## 配色

极光 / 灼烬 / 森林 / 虚空
