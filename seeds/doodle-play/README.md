# Doodle Play 涂鸦游乐场

沉浸式即兴涂鸦体验场。流体渐变背景 + 微晶玻璃态容器 + 非线性动效。

## 功能

- **5 种画笔**：墨韵（呼吸线宽）/ 霓虹（双层辉光）/ 流彩（速度调制线宽 + 主题流动色）/ 星屑（粒子迸射）/ 缎带（法线填充带）
- **弹簧光标**：欠阻尼弹簧-阻尼物理驱动的活体光标，笔迹沿弹簧轨迹采样，落笔丝滑
- **回放**：以逐段节奏回放全部笔迹，段落终点粒子迸射
- **撤销 / 清空 / PNG 导出**（深色渐变成品底）
- **自动流彩**：色彩随 4 种氛围配色（极光 / 暮霞 / 深海 / 墨色）在笔迹上连续流动
- **快捷键**：`Z` 撤销 · `R` 回放 · `C` 清空 · `S` 导出

## 技术

Vanilla JS + CSS3 + HTML5，免构建。双 Canvas 架构：主画布承载笔迹，fx 层承载粒子。所有过渡使用 `cubic-bezier(0.16, 1, 0.3, 1)` 非线性缓动。
