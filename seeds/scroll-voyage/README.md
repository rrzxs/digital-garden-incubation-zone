# Scroll Voyage · 滚动远航

沉浸式滚动远航体验——**滚动即下潜**。页面以一次完整的深潜远航为叙事：海面出发 → 雾光带 → 暮光带 → 午夜深渊 → 热泉喷口 → 归途上浮。

## 交互亮点

- **深度仪表 HUD**：左侧微晶玻璃态仪表实时显示深度（米）、生物带名称、舱压与下潜速率，液柱随进度填充
- **SVG 航线绘制**：正弦下潜曲线随滚动逐笔绘制，弹簧-阻尼平滑的潜艇光球沿航线巡航
- **流体渐变背景**：四个超大模糊 blob 呼吸漂移 + 颗粒噪点，配色随主题即时流转
- **逐字揭示**：标题逐字符非线性入场，延迟 32ms 级联
- **视差 + 3D 倾斜**：玻璃卡片按 `data-depth` 多层视差，暮光带双卡随光标 3D 倾斜
- **海洋雪粒子场**：Canvas 粒子下沉，滚动速度越快气泡迸射越多（下潜加速的物理隐喻）
- **深渊之眼**：瞳孔凝视光标，呼吸律动
- **热泉遥测**：实时微扰动的烟温 / 舱压 / hull 完整度数据与烟柱粒子
- **归途上浮**：`easeOutQuart` 2.2s 出水缓动 + 气泡礼花
- **4 种氛围配色**：深渊蓝 / 极光绿 / 熔岩橙 / 暗夜紫

## 技术

- 零构建：Vanilla JS + CSS3 + HTML5，无任何依赖
- 字体：Outfit（展示）/ Inter（正文）/ Share Tech Mono（HUD）
- 统一缓动：`cubic-bezier(0.16, 1, 0.3, 1)`
- 支持 `prefers-reduced-motion`
