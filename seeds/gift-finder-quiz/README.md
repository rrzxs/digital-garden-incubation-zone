# Gift Finder Quiz - 礼物寻觅器

沉浸式礼物推荐问答 Web App。通过六个温柔的问题，为收礼者寻觅一份刚刚好的心意。

## 功能

- **六步问答流程** - 收礼者 / 年纪 / 气质 / 场合 / 预算 / 心意，每个选项携带情感标签
- **智能礼物匹配引擎** - 16 件候选礼物库，依据标签重叠度加权评分，输出 Top 推荐
- **分析序列动画** - 模拟「聆听心意」的终端式日志逐行输出，营造仪式感
- **结果卡片** - 推荐名称、描述、契合度、预算区间、心意指数、惊喜度与推荐理由
- **再来一次 / 换一个推荐** - 支持重置流程或在候选池中切换备选推荐
- **氛围配色动态迁移** - 6 段进度对应 6 组渐变强调色，随问答推进实时流转
- **键盘快捷键** - 问题阶段可用数字键 1-4 快速选择
- **粒子流场** - Canvas 粒子系统，鼠标吸引力场 + 邻近连接线 + 呼吸透明度
- **点击涟漪** - 全局点击涟漪扩散动效
- **流体网格渐变背景 + 微晶玻璃态容器** - 贯穿全场景的视觉语言

## 技术栈

- Vanilla JS + CSS3 + HTML5
- Canvas 2D 粒子系统
- CSS Fluid Mesh Gradient 动画
- Glassmorphism 容器
- 非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 字体: Inter, Outfit, Share Tech Mono
