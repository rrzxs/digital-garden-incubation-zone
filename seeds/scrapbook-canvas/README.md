# Scrapbook Canvas 拼贴画布

沉浸式数字剪贴簿体验。将贴纸、便签拖入微晶玻璃画布，用弹簧-阻尼物理甩动它们，贴上胶带，导出属于你的记忆拼贴。

## 交互

| 操作 | 效果 |
| --- | --- |
| 点击货架贴纸 | 随机位置弹入画布 |
| 拖拽货架 → 画布 | 精确放置 |
| 拖拽贴纸 | 弹簧物理跟随，倾斜响应速度 |
| 快速甩动释放 | 惯性滑行 + 边界弹性碰撞 + 粒子迸射 |
| 双击 | 置顶 + 弹跳动画 |
| `R` | 随机旋转选中贴纸 |
| `T` | 贴上/取下胶带 |
| `Delete` | 移除选中贴纸 |
| 洗牌 | 网格化重新拼贴布局 |
| 导出 | Canvas 合成 PNG 下载 |

## 特性

- 弹簧-阻尼物理：拖拽跟随、缩放弹性、甩动惯性、碰撞回弹
- 流体渐变背景（4 色球体漂移 + 超模糊 + screen 混合）
- 微晶玻璃态容器（backdrop-filter + 发光描边）
- 4 种氛围配色：牛皮纸 / 宝丽来 / 午夜 / 植物志
- 粒子迸射 + 环境漂浮粒子场、光标辉光、乱码揭示标题
- 实时遥测面板（条目数 / 坐标 / 速度 / 主题）
- 全部动效统一使用 `cubic-bezier(0.16, 1, 0.3, 1)` 非线性曲线

## 技术
