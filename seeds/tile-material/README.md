# Tile Material 瓷质

沉浸式瓦片材质微交互体验场。

## 概述

Tile Material 是一个交互式瓦片网格，展示了高阶微交互设计：弹簧-阻尼物理模型驱动瓦片对鼠标的实时响应，4 种交互模式，涟漪脉冲扩散，动态光影与材质变化。

## 交互模式

- **排斥 (Repel)** — 瓦片被光标推开，产生排斥力场效果
- **吸引 (Attract)** — 瓦片被光标吸引聚拢
- **波浪 (Wave)** — 正弦波驱动的环绕旋转力场
- **形变 (Morph)** — 瓦片产生非线性弹性形变与缩放

## 特性

- 弹簧-阻尼物理驱动的 3D 透视旋转与位移
- 点击 / 触摸产生涟漪冲击波级联传播
- 光标轨迹流与粒子连接线
- 4 种氛围配色（瓷白 / 黑曜 / 翡翠 / 余烬）
- 可调节磁场半径、弹性系数、阻尼参数
- 流体渐变背景 + 微晶玻璃态容器
- 全屏模式支持

## 技术栈

- Vanilla JS + CSS3 + HTML5（零构建）
- CSS Custom Properties 实现主题切换
- Canvas 2D 绘制轨迹与涟漪环
- requestAnimationFrame 驱动的物理模拟循环
