# Scroll Parallax Flip 视差翻转

沉浸式滚动视差翻转微交互体验。滚动驱动多层深度视差，弹簧-阻尼物理驱动的非线性 3D 卡片翻转，逐字逐词揭示动画与堆叠覆盖卡片，流体渐变背景 + 微晶玻璃态容器 + 非线性动效。

## 核心交互

- **滚动** — 驱动五幕章节（Hero / Depth / Flip / Reveal / Stack / Finale），视差层与堆叠卡片随滚动折叠
- **鼠标移动** — 扰动所有视差深度层（星点/网格/光环/光斑）、3D 倾斜翻转卡片与粒子力场
- **点击翻转卡片** — 弹簧-阻尼物理驱动的非线性翻转，迸发粒子脉冲冲击波
- **点击空白** — 触发涟漪粒子迸射
- **全部翻转 / 归位** — 级联触发所有卡片的翻转或复位
- **回到起点** — 平滑滚回顶部并重置状态

## 五幕章节

| 章 | 内容 | 微交互 |
|---|---|---|
| 00 Hero | 标题与引语 | 逐字揭示、视差元信息 |
| 01 Depth | 深度视差展示 | 三层深度卡片、鼠标位移 |
| 02 Flip | 翻转画廊 | 六张弹簧物理 3D 翻转卡片 |
| 03 Reveal | 叙事揭示 | 逐词揭示、微晶玻璃容器 |
| 04 Stack | 堆叠卡片 | 滚动驱动四层覆盖堆叠 |
| 05 Finale | 终幕统计 | 滚动百分比/翻转次数/层数 |

## 视差层结构

| 层 | 深度系数 | 内容 |
|---|---|---|
| Stars | 0.04 | 10 颗闪烁星点 |
| Grid | 0.10 | 透视网格 |
| Rings | 0.18 | 3 层脉冲同心环 |
| Floaters | 0.32 | 4 个模糊光斑 |
| Particles | — | 80 个 Canvas 漂浮粒子 + 鼠标力场 |

## 物理模型

翻转卡片采用独立弹簧-阻尼积分器：

```
F = −k·(θ − θ_target)
v' = (v + F) · c        (c 为阻尼系数)
```

每张卡片拥有独立的 `spring` 刚度与 `damping` 阻尼，产生差异化的过冲与回弹。

## 配色方案

黑曜石 / 极光 / 余烬 / 霜降

## 技术栈

Vanilla JS + CSS3 + HTML5，零构建依赖。`cubic-bezier(0.16, 1, 0.3, 1)` 贯穿所有非线性动效。
