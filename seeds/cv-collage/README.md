# CV Collage · 履历拼贴

把一份履历拆成碎片 —— 7 张微晶玻璃态碎片（身份 / 信条 / 履历 / 技能 / 作品 / 教育 / 联络）在流体渐变背景上自由拼贴。

## 交互

- **拖拽抛掷**：弹簧-阻尼物理 + 边界弹性碰撞 + 速度姿态倾斜，抛出碎片会随速度旋转
- **点击空白**：释放冲击波涟漪，把附近碎片炸开
- **双击碎片**：置顶 + 点亮技能条 + 局部冲击波
- **TRACE 轨迹**：拖拽时留下流光轨迹
- **TILT 倾斜**：碎片随光标 3D 透视倾斜
- **FLOW 流场**：三角函数叠层流场粒子，光标扰动
- **MOOD 氛围**：极光 / 墨韵 / 余烬 / 潮汐 4 种配色实时切换
- **洗牌拼贴 / 齐射散落 / 复位**：三种编排动作，标题乱码揭示

## 技术

免构建 · Vanilla JS + CSS3 + HTML5 · 无依赖。
动效曲线统一 `cubic-bezier(0.16, 1, 0.3, 1)`，字体 Inter / Outfit / Share Tech Mono。
