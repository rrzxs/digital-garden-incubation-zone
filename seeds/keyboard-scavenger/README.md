# Keyboard Scavenger 键盘拾荒者

散落的字母漂浮在空间中，用键盘快速捕获它们，拼出目标单词。连击越快，分数越高。

## 玩法

1. 观察顶部目标单词，找到高亮的首字母
2. 在画布中寻找并按下对应的漂浮字母
3. 按顺序拼出完整单词获得额外奖励
4. 连续命中触发 Combo 连击加分

## 特性

- 5 关递进难度（单词长度递增、字母速度加快）
- Combo 连击系统与分数倍率
- 漂浮字母粒子场 + 连接线拓扑
- 击键涟漪扩散 + 粒子迸射
- 键盘高亮提示当前目标字母
- 流体渐变背景 + 微晶玻璃态容器
- 空格键暂停/继续

## 技术栈

- Vanilla JS + CSS3 + HTML5
- Canvas 2D 渲染引擎
- 零构建、零依赖
