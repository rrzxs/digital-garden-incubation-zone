# Habit Terrarium - 习惯生态瓶

沉浸式习惯追踪器。将日常习惯可视化为玻璃生态瓶中生长的植物，每日打卡如同浇灌呵护。

## 功能

- **习惯 CRUD**：添加 / 完成打卡 / 删除习惯
- **4 种植物类型**：多肉、蕨类、花卉、仙人掌，各有独特 SVG 生成逻辑
- **生长等级**：每次打卡植物升级（Lv.0 ~ Lv.10），形态随之演变
- **连续天数**：追踪每个习惯的连续完成记录
- **微晶玻璃容器**：backdrop-filter + 发光边缘的生态瓶视觉
- **流体渐变背景**：多 blob 超级模糊 + screen 混合模式
- **粒子流场**：Canvas 绘制的漂浮光点
- **水雾凝结**：CSS 驱动的瓶内水珠与雾气效果
- **完成粒子**：打卡时绽放的 sparkle 粒子
- **LocalStorage 持久化**：刷新不丢数据，每日自动重置打卡状态

## 技术栈

- Vanilla JS + CSS3 + HTML5
- 无构建流、无依赖
- 字体：Outfit, Inter, Share Tech Mono
- 动效曲线：cubic-bezier(0.16, 1, 0.3, 1)

## 使用

直接用浏览器打开 `index.html` 即可体验。
