# Gradient Mesh - 渐变网格生成器

一个交互式的 Mesh 渐变生成工具，通过拖拽节点实时创造美丽的渐变效果。

## 功能特性

- **拖拽交互**：直接拖拽彩色节点调整渐变位置
- **预设配色**：5 种精心设计的配色方案（极光、日落、深海、霓虹、森林）
- **节点控制**：支持 3-8 个渐变节点
- **模糊调节**：实时调整渐变模糊强度
- **CSS 导出**：一键复制生成的 CSS 代码
- **PNG 导出**：导出高质量渐变图片
- **全屏模式**：沉浸式创作体验

## 使用方法

1. 在画布上拖拽彩色圆点调整渐变节点位置
2. 使用预设按钮快速切换配色方案
3. 调节节点数量和模糊强度
4. 点击随机按钮生成新的布局
5. 复制 CSS 代码或导出 PNG 图片

## 技术栈

- Vanilla JavaScript (无框架)
- Canvas 2D API
- CSS3 (Glassmorphism 设计)
- 非线性动效曲线
