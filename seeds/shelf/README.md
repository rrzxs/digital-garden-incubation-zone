# Shelf · 灵感书架

沉浸式 3D 灵感书架。每根书脊承载一个半成形的念头，悬停让它探出，拖拽让整排在透视中流动，点击抽出一本在微晶玻璃面板中翻开。

## 交互

- **悬停书脊** — 微微探出、邻近书脊退让、HUD 更新
- **拖拽平移** — 鼠标/触摸横向拖拽整排书，释放带惯性
- **滚轮滚动** — 纵向滚轮映射为横向位移
- **键盘导航** — `←/→` 平移，`Esc` 合上书本
- **点击展开** — 书本抽出至前景，右侧微晶玻璃详情面板滑入
- **视差倾斜** — 鼠标位置驱动书架 3D 透视偏转
- **配色切换** — 极光 / 余烬 / 深渊 / 兰若 四种氛围

## 技术

- Vanilla JS + CSS3 + HTML5，零构建
- 流体网格渐变（5 层 blob + screen 混合）
- 微晶玻璃态容器（backdrop-filter + 发光描边）
- 非线性动效（`cubic-bezier(0.16, 1, 0.3, 1)`）
- Canvas 粒子流场（Simplex-like 噪声驱动）
- 16 本预设书籍内容
