# Fluid Loader - 流体加载动画

> 流体模拟驱动的加载动画，可以用鼠标交互扰动流体

## ✨ 特性

- **流体粒子模拟**: 基于 Canvas 的实时粒子系统，模拟流体动力学效果
- **交互式扰动**: 鼠标移动可产生扰动场，实时影响流体行为
- **动态加载动画**: 加载过程中流体逐渐活跃，加载完成后进入自由流动模式
- **双模式切换**: 
  - 流体模式 (Fluid): 粒子间的连接线展示流体网络
  - 漩涡模式 (Vortex): 粒子围绕中心点旋转
- **响应式设计**: 完美适配桌面端和移动端
- **实时统计**: 显示粒子数量和 FPS 性能监控

## 🎨 设计亮点

- **微晶玻璃态 UI**: 采用现代 Glassmorphism 设计风格
- **流体网格渐变背景**: 多层渐变球体配合超大模糊和混合模式
- **非线性微交互**: 所有动效使用 `cubic-bezier(0.16, 1, 0.3, 1)` 缓动曲线
- **氛围感配色**: 使用紫、粉、蓝等现代色调营造沉浸式体验

## 🚀 使用方式

直接在浏览器中打开 `index.html` 即可体验。

### 操作说明

1. **加载阶段**: 观察粒子随加载进度逐渐活跃
2. **交互扰动**: 在 Canvas 区域移动鼠标或触摸，扰动流体
3. **重新开始**: 点击"重新开始"按钮重置加载动画
4. **切换模式**: 点击"切换模式"按钮在流体和漩涡模式间切换

## 🛠️ 技术实现

- **核心框架**: Vanilla JavaScript (零依赖)
- **渲染引擎**: HTML5 Canvas API
- **物理模拟**: 
  - 布朗运动模拟
  - 阻力和速度限制
  - 鼠标交互力场
- **动画系统**: `requestAnimationFrame` 实现流畅动画
- **响应式**: 媒体查询适配移动端，Canvas 自适应缩放

## 🎯 核心算法

### 粒子系统

每个粒子包含以下属性：
- 位置 (x, y)
- 速度 (vx, vy)
- 基础位置 (baseX, baseY) - 用于漩涡模式
- 大小、颜色、透明度

### 流体模拟

1. **噪声扰动**: 使用正弦和余弦函数模拟自然流体运动
2. **交互力场**: 鼠标位置计算距离，产生排斥或吸引力
3. **阻尼系统**: 速度衰减模拟能量损失
4. **边界处理**: 粒子碰撞边界时反弹

### 连接网络

当粒子距离小于阈值时，绘制连接线，透明度随距离渐变，形成流体网络效果。

## 💡 性能优化

- 使用 `requestAnimationFrame` 保证动画流畅性
- Canvas 渲染使用 `devicePixelRatio` 适配高清屏
- 粒子数量可配置，默认 800 个粒子平衡性能与视觉效果
- FPS 监控实时反馈性能状态
