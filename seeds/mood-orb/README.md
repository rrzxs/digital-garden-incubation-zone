# Mood Orb · 情绪光球

沉浸式情绪光球交互体验。一颗会呼吸的情绪生命体 —— 选择情绪，观察它在 Simplex 噪声场中流变形变、以不同的节律呼吸，并通过粒子光环与脉冲冲击波回应你的触碰。

## 交互

- **选择情绪**：底部 6 种情绪卡片（宁静 / 欢愉 / 忧郁 / 专注 / 焦躁 / 惊叹），光球色彩、噪声形变频率与呼吸节律 (BPM) 平滑混合过渡
- **拖拽**：牵引光球离开中心，松手后弹簧-阻尼物理回弹，运动速度驱动球体挤压拉伸
- **点击光球**：释放脉冲冲击波环 + 粒子迸射
- **双击任意处**：切换当前情绪的低语短句（乱码揭示动画）
- **主题切换**：右上角 4 种氛围配色（星云 / 深渊 / 熔岩 / 翠林）

## 技术

- 免构建：Vanilla JS + CSS3 + Canvas 2D，零依赖
- 内置紧凑 Simplex Noise 实现，驱动光球轮廓形变、内层流纹与环境粒子流场
- 弹簧-阻尼物理、呼吸余弦节律、非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 流体渐变背景（超大模糊 + mix-blend-mode: screen）+ 微晶玻璃态容器
