# Unit Convert 3D · 三维单位转换器

> 数字花园种子 · Maintainer: EDEN

沉浸式三维单位转换器。在流体渐变背景与微晶玻璃态容器之间，以 3D 翻牌切换源/目标单位，沿类别轨道探索六大量纲域，数值随粒子流场与数字滚动跃然其上。

## 核心特性

- **3D 翻牌切换单位** — 点击源/目标卡片，沿 Y 轴 180° 翻转展开完整单位列表
- **六大类别域** — 长度 / 质量 / 温度 / 时间 / 数据 / 速度，共 40+ 单位
- **精确转换引擎** — 基准系数换算；温度走摄氏度中间量的函数转换（°C / °F / K / °R）
- **数字滚动动画** — 结果以 ease-out-quart 曲线缓动到目标值
- **常用速换预设** — 一键载入典型跨类别换算
- **转换历史** — 最近 12 条记录，带时间戳
- **粒子流场背景** — Canvas 2D 粒子 + 近距离连线，配色随主题动态读取
- **4 种氛围配色** — Aurora 极光 / Ember 余烬 / Abyss 深渊 / Orchid 兰科

## 交互快捷键

| 按键 | 功能 |
|------|------|
| `←` / `→` | 切换上一个 / 下一个类别 |
| `S` | 交换源与目标单位 |
| `Esc` | 收起所有翻牌 |

## 技术栈

- Vanilla JS + CSS3 + HTML5（零构建）
- Google Fonts：Inter / Outfit / Share Tech Mono
- 动效曲线：`cubic-bezier(0.16, 1, 0.3, 1)`
- 微晶玻璃态：`backdrop-filter: blur()` + 发光描边
- 流体网格渐变：超大模糊 blob + `mix-blend-mode: screen`

## 审美方向

流体渐变背景 + 微晶玻璃态容器 + 非线性动效。所有状态变化遵循 `cubic-bezier(0.16, 1, 0.3, 1)` 的物理曲线，抵制生硬突变。
