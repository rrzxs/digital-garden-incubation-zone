# AI Guardian Stage 守护者舞台

沉浸式 AI 守护者微交互体验场。一位悬浮于微晶玻璃舞台的 AI 哨兵守护者，注视着你的光标，拦截从暗区逼近的威胁信号。

## 体验亮点

- **活体守护者**：光标追踪瞳孔、弹簧物理 3D 倾斜、眨眼呼吸、扫描线与旋转光环
- **威胁拦截系统**：故障感威胁体从边缘逼近，守护者自动锁定并发射谐振光束中和
- **护盾完整性**：威胁抵达核心将冲击护盾，护盾归零触发过载休眠与重启序列
- **4 种运作模式**：守望（低威胁巡航）/ 警戒（高强度拦截）/ 庇护（快速再生）/ 共振（点击释放毁灭脉冲）
- **守护日志**：Share Tech Mono 等宽字体打字机日志，实时记录守护者状态
- **4 种氛围配色**：星穹 / 极光 / 熔核 / 虚空，流体渐变背景 + 微晶玻璃态容器
- **非线性动效**：全部过渡采用 `cubic-bezier(0.16, 1, 0.3, 1)` 物理曲线

## 交互指南

| 操作 | 效果 |
|------|------|
| 移动光标 | 守护者注视你，核心随光标倾斜 |
| 点击舞台 | 释放脉冲（共振模式下可直接湮灭威胁） |
| 模式切换 | 改变威胁强度、拦截频率与护盾再生 |
| 配色切换 | 切换整体氛围配色协议 |

## 技术说明

- 纯 Vanilla JS + CSS3 + HTML5，零构建、零依赖
- Canvas 承载环境粒子场、威胁体、光束、脉冲与爆裂粒子
- DOM + CSS 承载守护者形体（六边形玻璃核心、旋转光环、碎片轨道、护盾穹顶）
