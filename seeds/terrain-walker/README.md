# Terrain Walker — 地形漫步

基于 Simplex Noise 的交互式 3D 地形生成器与漫步体验。

## 功能

- **Simplex Noise 地形**：多层叠加噪声生成自然地形，高度着色映射
- **漫步模式**：WASD / 方向键控制角色在 3D 地形上行走，带惯性物理和行走晃动
- **轨道模式**：自由旋转视角观赏地形全貌
- **鼠标/触控旋转**：拖拽旋转相机视角，滚轮缩放
- **4 种氛围配色**：午夜、极光、熔岩、星云
- **参数调节**：海拔幅度、噪声频率、行走速度
- **重生成**：随机种子重新生成地形
- **漂浮粒子**：营造氛围的流场粒子
- **行走轨迹**：记录并可视化漫步路径

## 技术栈

- Vanilla JS + CSS3 + HTML5（零构建）
- Simplex Noise 算法（内嵌实现）
- Canvas 2D 渲染（3D 透视投影）
- 流体渐变背景 + 微晶玻璃态容器

## 操作

| 操作 | 效果 |
|------|------|
| WASD / 方向键 | 移动漫步者 |
| 鼠标拖拽 | 旋转视角 |
| 滚轮 | 缩放 |
| 漫步/轨道 切换 | 切换交互模式 |
