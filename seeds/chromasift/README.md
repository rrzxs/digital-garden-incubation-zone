# ChromaSift — 色彩筛分器

> 沉浸式渐变配色灵感探索器。通过粒子筛分物理，将色彩按色相 / 饱和度 / 明度重新排列，发现意想不到的配色组合。

## 功能

- **色彩粒子系统** — 180 颗动态粒子在 HSL 色彩空间中流动与漂移
- **拖拽采样** — 在画布上拖动鼠标/手指，即时提取并观察色彩粒子
- **HSL 精细调控** — 色相范围、饱和度、明亮度独立滑块控制
- **渐变停色数** — 支持 2~5 个渐变停色点
- **滚动调光** — 鼠标滚轮实时调整整体亮度
- **CSS 代码导出** — 一键生成 `linear-gradient` CSS 代码，支持 HEX 与 HSL 双格式
- **渐变收藏** — 双击色条保存渐变，最多存储 12 条，随时切换

## 快捷键

| 按键 | 功能 |
|------|------|
| `R` | 随机生成新配色 |
| `L` | 锁定 / 解锁画布交互 |
| `C` | 打开 CSS 代码导出弹窗 |
