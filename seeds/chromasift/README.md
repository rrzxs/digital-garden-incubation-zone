# ChromaSift - 色彩筛分器

> Shift through infinite color gradients.

沉浸式渐变配色灵感探索器。通过筛分物理将色彩粒子按色相 / 饱和度 / 明度重新排列，发现配色灵感。

## 交互

| 操作 | 行为 |
|------|------|
| 移动鼠标 | 扰动色彩粒子 |
| 点击粒子 | 采样颜色至调色板 |
| 双击画布 | 打散粒子 |
| 空格键 | 筛分 |
| R 键 | 打散 |
| 调色板色块 | 点击复制 HEX |

## 功能

- **筛分模式** — 按 H / S / L 重新排列色彩粒子
- **多调色板** — 全光谱、极光、余烬、深海
- **实时采样** — 点击粒子即可采集颜色
- **粒子物理** — 鼠标排斥、边界反弹、脉动动画
- **全屏模式** — 沉浸式探索色彩

## 技术

- 纯原生 JS + Canvas API
- 无外部依赖
- 响应式画布
