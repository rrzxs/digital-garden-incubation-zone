# Polaroid Lab · 拍立得暗房

数字花园种子区 · seed: `polaroid-lab` · maintainer: **EDEN**

## 简介

沉浸式拍立得暗房体验。拖入 / 粘贴 / 上传照片，或直接「拍摄样片」——程序化生成的合成影像会像真的即时相纸一样，在药水显影动画中从白色混沌里缓缓浮现。每张拍立得都可以弹簧物理拖拽、实时切换 6 种胶片色调、手写注记，并导出为带相纸边框的 PNG。

## 特性

- **药水显影动画**：照片以可调时长（0.6s–4s）的非线性缓动从乳白遮罩中显影，伴随扫掠微光
- **弹簧拖拽物理**：卡片以弹簧-阻尼插值柔滑追随光标，抓取时抬升层级、加深投影
- **6 种胶片色调**：Original / Noir / Sepia / Vivid / Frost / Chrome，卡片悬浮时可用色点快速切换
- **手写注记**：每张相纸底部白边可直接书写注记（Share Tech Mono 等宽字体）
- **颗粒 & 暗角**：全局颗粒度与暗角强度实时调节（SVG 噪声 + 径向渐变）
- **PNG 导出**：双击卡片（或点 ◎）进入查看浮层，导出带滤镜、暗角与注记的完整相纸
- **样片生成器**：无需任何图片素材，Canvas 程序化生成 6 种配色光斑风景样片
- **快门闪光**：每次拍摄/导入均有快门白闪反馈
- **4 种氛围配色**：Noir / Amber / Mint / Orchid 流体渐变背景实时迁移

## 技术栈

纯 Vanilla JS + CSS3 + HTML5，零构建、零依赖。字体：Inter / Outfit / Share Tech Mono。动效曲线统一采用 `cubic-bezier(0.16, 1, 0.3, 1)`。

## 使用

直接用静态服务器打开本目录（或访问 `/seed/seeds/polaroid-lab/index.html`）：

```bash
cd seeds/polaroid-lab && python3 -m http.server 8080
```

## 交互速查

| 操作 | 效果 |
| --- | --- |
| 拖拽图片文件入窗 / Ctrl+V 粘贴 / 上传 | 导入照片并显影 |
| 点击「拍摄样片」 | 生成程序化样片 |
| 拖拽卡片 | 弹簧物理移动 |
| 悬停卡片 → 色点 | 切换胶片色调 |
| 双击卡片 / ◎ | 查看大图并导出 PNG |
| ◐ / ✕ | 重新显影 / 移除相纸 |
| 右侧把手 | 展开暗房控制台 |
