# Letterflow 字符流

数字花园种子 · 沉浸式字符流微交互体验场。

## 玩法

- **输入文字 + 回车**：字符被播撒为发光 glyph，进入流场开始自己的旅程
- **移动光标**：斥力 / 引力 / 涡旋三种力场实时扰动字符群
- **点击画布**：冲击波涟漪推开字符，并迸发随机字母
- **Alt + 字母键**：快捷三连播撒

## 特性

- 4 种流场模式：河川 / 漩涡 / 漂移 / 坠流
- 弹簧-阻尼字符物理 + 呼吸缩放 + 值噪声流场
- 流体渐变背景（blur + mix-blend-mode screen）+ 微晶玻璃态控制台
- 标题乱码揭示、非线性动效统一曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 4 种氛围配色：极光 / 暮色 / 深海 / 花焰
- 实时遥测：glyph 存量 / 脉冲计数 / FPS

## 技术

Vanilla JS + Canvas 2D + CSS3，免构建，即开即用。
