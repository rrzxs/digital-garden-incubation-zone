# Sky Gradient Clock · 天空渐变时钟

> 流体渐变背景 + 微晶玻璃态容器 + 非线性动效

一个让时间流淌于天空之间的时钟体验。背景渐变、太阳/月亮位置、星辰闪烁与色彩主题都随真实时刻呼吸流转——黎明、正午、黄昏、深夜四态自然过渡。

## ✨ 核心特性

- **时间驱动天空**：背景流体网格渐变根据真实时刻在四态（DAWN / NOON / DUSK / NIGHT）间平滑过渡，所有色块、强调色、文字色以 2.5s `cubic-bezier(0.83, 0, 0.17, 1)` 缓动同步流转。
- **天体轨道**：太阳在日出到日落间沿抛物线弧划过天空，夜晚月亮沿相反弧线运行，带柔和发光与实时位置重算。
- **12 小时进度环**：SVG 环形进度条 + 12 刻度，当前小时刻度高亮，发光描边使用 `<filter>` 高斯模糊叠加。
- **轨道指针**：时钟外圈一枚发光指针沿圆周旋转，映射当前时刻在 12 小时圆周上的位置。
- **日轨时间轴**：可拖拽的 24 小时进度条，点击或滑动即视觉跳转，配合 AUTO 模式自动跟随真实时间。
- **星空呼吸**：80 颗随机分布的星辰，透明度随阶段（白天 0 / 夜晚 1）平滑过渡，独立闪烁节奏。
- **微晶玻璃态**：所有容器采用 `backdrop-filter: blur(20px)` + 微弱发光描边，悬停 `translateY(-2px)`。
- **阶段切换**：5 个按钮（AUTO / DAWN / NOON / DUSK / NIGHT）手动锁定氛围，AUTO 回到实时驱动。

## 🎨 审美系统

- **字体**：Outfit（标题）/ Inter（正文）/ Share Tech Mono（数字与标签）
- **缓动曲线**：全局采用 `cubic-bezier(0.16, 1, 0.3, 1)` 与 `cubic-bezier(0.83, 0, 0.17, 1)`
- **玻璃描边**：`1px solid rgba(255,255,255,0.12)` + 柔和内阴影
- **混合模式**：背景色块使用 `mix-blend-mode: screen` + `filter: blur(110px)` 构建呼吸感流体网格

## 🛠 技术栈

- 纯 Vanilla JS + CSS3 + HTML5（零构建、零依赖）
- SVG 渐变与滤镜实现进度环发光
- `requestAnimationFrame` 节流的 resize 处理
- 响应式断点：560px / 360px
- 支持 `prefers-reduced-motion`
