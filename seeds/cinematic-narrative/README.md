# Cinematic Narrative | 影像叙事

沉浸式电影叙事滚动体验。通过 6 个场景章节，用光影、时间、蒙太奇等电影语言讲述一个关于视觉叙事本身的流动故事。

## 核心交互

- **流体渐变背景** — 4 组超大模糊 orb 呼吸律动 + 粒子流场连线
- **微晶玻璃态容器** — backdrop-filter 毛玻璃面板 + 发光描边
- **非线性动效** — `cubic-bezier(0.16, 1, 0.3, 1)` 贯穿所有过渡
- **电影镜头光标** — 自定义圆形取景器光标，缓动跟随鼠标
- **逐字揭示动画** — 封面副标题逐字符淡入
- **明暗对照交互** — 鼠标驱动的光源揭示效果
- **时间节律可视化** — 三速可调正弦波形 Canvas 动画
- **蒙太奇文字拼贴** — 字母级联揭示 + 等式碰撞动画
- **帧计数器** — 底部实时 24fps 帧数计数
- **键盘导航** — 方向键切换场景，Home/End 跳转首尾

## 技术栈

- Vanilla JS + CSS3 + HTML5
- 零构建、零依赖
- 字体: Inter, Outfit, Share Tech Mono
