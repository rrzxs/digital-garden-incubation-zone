# Cursor Grit 光标砂砾

> 沉浸式光标砂砾微交互物理场。弹簧-阻尼物理驱动的砂砾粒子对光标产生挖掘、扫动、漩涡与摩擦响应，粒子堆积、刀切裂沟、漩涡引力与静电吸附，流体渐变背景 + 微晶玻璃态容器，4 种氛围配色。

## 核心交互

| 模式 | 行为 |
|------|------|
| **挖掘 Excavate** | 光标推力将砂砾向外排开，留下挖掘裂沟，光标速度产生拖拽效应 |
| **扫动 Sweep** | 砂砾沿光标运动方向被扫开，附带垂直散射营造砂粒质感 |
| **漩涡 Vortex** | 砂砾环绕光标切向旋转，轻微向内引力形成轨道运动 |
| **静电 Static** | 近场砂砾被吸附至光标，伴随随机抖动模拟静电吸附 |

## 参数调节

- **砂砾数量** — 800 ~ 5000 粒（自适应屏幕面积密度）
- **力场半径** — 40 ~ 320px
- **摩擦系数** — 0.70 ~ 0.98（砂砾高摩擦物理）
- **归位弹性** — 0 ~ 0.050（弹簧回弹强度）
- **砂砾尺寸** — 0.6 ~ 4.0px

## 操作

- **移动光标** — 与砂砾产生物理交互
- **点击画布** — 触发环形冲击波涟漪
- **冲击波按钮** — 以光标为中心释放全屏冲击波
- **重置砂床** — 所有砂砾归位

## 技术栈

- Vanilla JS + Canvas 2D（无构建）
- CSS3 自定义属性 + `backdrop-filter` 微晶玻璃态
- `cubic-bezier(0.16, 1, 0.3, 1)` 非线性动效曲线
- 字体：Inter / Outfit / Share Tech Mono
