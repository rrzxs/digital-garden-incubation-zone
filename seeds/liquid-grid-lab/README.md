# Liquid Grid Lab — 液态网格实验室

沉浸式液态晶格力场微交互体验场。弹簧-阻尼物理驱动的网格晶格对光标产生实时形变响应，点击画布发射冲击波涟漪，观察能量在晶格中传播共振。

## 特性

- **弹簧-阻尼物理晶格**：每个网格节点具备独立弹簧回归与速度衰减，产生液态般的非线性回弹
- **4 种力场模式**：斥力（推挤）/ 引力（牵引）/ 漩涡（螺旋）/ 波场（涌动）
- **冲击波系统**：点击画布或按下 Pulse 发射涟漪冲击波，波前推动晶格共振
- **实时遥测面板**：节点数、系统能量、活跃波数与 FPS 监控
- **可调参数**：力场半径、晶格密度实时滑块调节
- **4 种氛围配色**：Aurora / Ember / Jade / Orchid
- **流体渐变背景 + 微晶玻璃态容器**：多层模糊混合色块呼吸漂移，玻璃拟态面板与颗粒噪点

## 技术

免构建 · Vanilla JS + CSS3 + Canvas 2D · 字体 Inter / Outfit / Share Tech Mono · 动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`

## 使用

直接用浏览器打开 `index.html`，或通过数字花园主页种子卡片进入。

- 移动光标：扰动晶格
- 点击画布：发射冲击波
- 底部控制条：切换力场模式、调节参数、发射脉冲、重置晶格
- 右上角按钮：循环切换氛围配色
