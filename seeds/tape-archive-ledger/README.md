# Tape Archive Ledger · 磁带档案账本

沉浸式磁带档案账本。每一份记忆都被录制为一盘磁带，入舱后由走带机芯驱动播放——卷轴随带卷直径变化而变速旋转、机械计数器滚动、波形呼吸律动。

## 核心交互

- **走带机芯 Deck**：播放 / 暂停 / 倒带(6x) / 快进(4x) / 弹出；左右卷轴随磁带余量实时改变带卷直径
- **波形可视化**：每盘磁带由唯一种子生成伪随机波形，播放进度点亮、播放中呼吸律动
- **档案架管理**：录制新磁带（标目 / 8 种声轨类别 / 时长 / 基调）、入舱、倒带、消磁删除
- **微交互**：卡片 3D 倾斜跟随、按钮光晕跟随、随机倒带、Toast 反馈、空格键播放快捷键
- **持久化**：localStorage 保存馆藏与播放进度，首次到访预置 4 盘引导磁带

## 视觉

流体渐变背景（blur + mix-blend-mode screen）+ 微晶玻璃态容器 + 粒子流场，4 种氛围配色（极光 / 熔金 / 深渊 / 幽兰），统一动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`。

## 技术

Vanilla JS + CSS3 + HTML5，零构建、零依赖。字体：Inter / Outfit / Share Tech Mono。
