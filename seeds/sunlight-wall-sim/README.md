# Sunlight Wall Sim · 日光墙

沉浸式日光墙模拟种子。一间只有光与尘埃的房间：太阳从左侧窗口掠过，
把一块会呼吸的光斑投在墙上——百叶帘影缓缓流动、焦散微光游弋、
尘埃在光柱中亮起，窗台上的蕨叶与玻璃瓶拖出斜斜的剪影。

## 交互

| 操作 | 效果 |
| --- | --- |
| 拖动「时间」滑杆 / `←` `→` | 0–24h 太阳轨迹：黎明 → 正午 → 黄昏 → 月夜 |
| 点击窗台 | 摆放蕨叶 / 玻璃瓶 / 叠书（逆光剪影 + 投影），再点一次移除 |
| 点击墙面 | 激起光之脉冲涟漪与瞬时光量增益 |
| 云影模式 | 云层缓缓遮蔽太阳，光斑深呼吸式明暗 |
| 掌影模式 | 光标化身一片云，压暗光斑局部 |
| 微风模式 | 尘埃扬起、帘影加速、绿植摇曳 |
| 墙面主题 | 暖砂 / 灰泥 / 赤陶 / 墨青 四种氛围配色 |

## 技术

- 免构建：Vanilla JS + Canvas 2D + CSS3，无任何依赖
- 三维值噪声（fbm）驱动云影、焦散微光与尘埃流场
- 微晶玻璃态控制台（`backdrop-filter`）+ 流体渐变氛围层
- 统一非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Inter / Outfit / Share Tech Mono

## 文件

- `index.html` — 结构
- `style.css` — 玻璃态容器、流体渐变、入场动效
- `main.js` — 光照模型、噪声场、尘埃粒子与交互逻辑
