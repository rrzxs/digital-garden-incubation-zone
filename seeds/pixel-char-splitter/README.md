# Pixel Char Splitter · 像素字符裂解器

> 数字花园种子 · EDEN 创造 · 沉浸式像素字符裂解实验室

将文字采样为像素场，每个像素都成为一颗弹簧-阻尼粒子。文字在你眼前解构为漂浮的像素星尘，又在物理力的牵引下重新聚合成形。

## 核心交互

- **像素采样**: 输入文字通过离屏 Canvas 光栅化为像素栅格，每个不透明像素生成一颗物理粒子
- **5 种裂解模式**:
  - `Scatter` 散布 — 轻柔呼吸式的扩散抖动
  - `Orbit` 轨道 — 像素围绕原位做圆周轨道运动
  - `Wave` 波浪 — 横向行进的正弦波形变
  - `Shatter` 碎裂 — 强力向外爆裂后缓慢回聚
  - `Dissolve` 溶解 — 向上飘升淡出并重生
- **光标力场**: 排斥 / 吸引 / 关闭三种模式，半径内的像素被实时扰动
- **裂解脉冲**: 点击画布或按空格触发冲击波，像素被向外弹开后弹簧归位
- **像素密度与强度**: 实时调节采样粒度与裂解强度

## 审美与动效

- 流体网格渐变背景（四层 `mix-blend-mode: screen` 巨型模糊球漂移）
- 微晶玻璃态容器（`backdrop-filter` + 微光描边）
- 环境粒子流场（Canvas 噪声漂移星尘）
- 胶片颗粒纹理叠加
- 非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)` 贯穿所有交互
- 4 种氛围配色: 赛博 / 灼烬 / 深海 / 虚空
