# Emotion Terrain · 情绪地形

沉浸式情绪地形交互体验。选择情绪，观察地形在 Simplex 噪声场中实时流变，鼠标力场扰动情绪粒子，4种氛围配色。

## 功能

- **6种情绪预设**: 宁静、欢愉、忧郁、愤怒、惊叹、恐惧，每种情绪定义不同的地形参数
- **Simplex Noise 地形**: 多层噪声叠加生成动态地形，实时演化
- **鼠标力场交互**: 光标位置扰动地形高度场与粒子运动
- **粒子流场**: 情绪粒子在噪声流场中流动，带连接线效果
- **情绪脉冲**: 点击脉冲按钮触发冲击波涟漪
- **双交互模式**: 探索（排斥力场）/ 雕塑（吸引力场）
- **参数调节**: 地形振幅、噪声频率、演化速度实时滑块
- **4种氛围配色**: 深渊、极光、熔岩、翠林

## 技术栈

- Vanilla JS + CSS3 + HTML5
- Canvas 2D 渲染
- Simplex Noise 算法（内置实现）
- CSS 自定义属性主题切换
- 无构建依赖

## 使用方式

直接在浏览器中打开 `index.html` 即可体验。
