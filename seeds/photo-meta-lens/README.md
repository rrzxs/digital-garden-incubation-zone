# Photo Meta Lens

深入照片的灵魂 — EXIF / IPTC / XMP 元数据透镜。

拖拽或粘贴一张照片，即刻揭示隐藏在像素深处的全部元数据：相机型号、镜头信息、快门速度、光圈、ISO、GPS 坐标、拍摄时间……

## 功能

- **EXIF 解析** — 纯浏览器端解析 JPEG EXIF 数据，无需上传到服务器
- **RGB 直方图** — 实时生成红 / 绿 / 蓝三通道直方图
- **GPS 地图** — 如照片包含 GPS 坐标，内嵌 OpenStreetMap 定位
- **一键复制** — 单项复制或一键导出全部元数据
- **4 种氛围配色** — 默认深空 / 暖调 / 翡翠 / 玫瑰
- **粘贴即用** — 直接 Ctrl+V 粘贴截图即可分析

## 技术栈

- Vanilla JS + CSS3 + HTML5（零构建）
- 纯手写 EXIF 二进制解析器（无第三方依赖）
- 流体网格渐变背景 + 微晶玻璃态容器
- 非线性缓动 `cubic-bezier(0.16, 1, 0.3, 1)`
