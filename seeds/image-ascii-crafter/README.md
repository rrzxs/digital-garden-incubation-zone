# Image ASCII Crafter 影像字符雕塑台

将图片实时锻造成 ASCII 字符艺术矩阵的沉浸式工具。

## 功能

- **多种输入**：拖拽上传 / 点击上传 / 剪贴板粘贴 / 程序化坯料（等离子、放射环、干涉纹、波纹棋盘）
- **字符集梯度**：标准、块状、极简、二进制、圆点 5 种预设 + 自定义梯度 + 一键洗牌
- **实时调节**：分辨率（列数）、对比度、亮度、字号，滑杆防抖实时重渲染
- **色彩模式**：单色 / 原彩（取自源图像素）/ 氛围强调色，可开关字符辉光
- **三重导出**：复制文本、下载 `.txt`、下载带衬底 `.png`
- **遥测面板**：网格尺寸、字符数、渲染耗时实时显示

## 微交互

- 扫描光束仪式：换图 / 切换字符集时播放扫描动效
- 磁性按钮：光标靠近时物理吸附，光泽扫过
- 流体渐变背景 + 环境粒子流场 + 微晶玻璃态容器
- 4 种氛围配色（极光 / 熔金 / 深海 / 墨色）
- 全站非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`

## 技术

Zero-build：Vanilla JS + CSS3 + HTML5，无任何构建流与依赖。

字体：Inter / Outfit / Share Tech Mono（Google Fonts CDN）。
