# Glitch Lab 故障实验室

> 沉浸式故障艺术实验室。输入文字实时探索五种故障模式，参数调节、脉冲冲击波与微晶玻璃态容器。

## 概述

Glitch Lab 是一个赛博朋克风格的故障艺术（Glitch Art）实时交互实验场。用户输入任意文字，即可在画布上实时探索五种高级故障视觉效果，并通过参数滑块精确控制故障强度。

## 故障模式

| 模式 | 标签 | 说明 |
|------|------|------|
| 色差 Chromatic | RGB | RGB 通道分离，光标位置实时驱动色差偏移方向与幅度 |
| 损毁 Datamosh | MOSH | 数据条带错位，模拟视频压缩损毁的块状伪影 |
| 扫描 Scanline | SCAN | 水平扫描线撕裂，通道带状偏移与随机断线 |
| 排序 Pixel Sort | SORT | 字符像素级排序重排，渐进式字符编码变异 |
| 乱码 Scramble | SCRAM | 随机字符替换，幽灵叠加层与密度可控的乱码揭示 |

## 核心交互

- **文字输入** — 实时输入任意文字（最多 24 字符），即时预览故障效果
- **光标扰动** — 光标在画布内的位置实时影响 RGB 色差方向与强度
- **点击冲击** — 点击画布触发故障冲击波，文字短暂乱码后恢复
- **参数调节** — 五个滑块精确控制：故障强度 / 色差偏移 / 扫描速度 / 乱码密度 / 自动脉冲
- **四种氛围配色** — 酸性 (Acid) / 虚空 (Void) / 日蚀 (Solar) / 霜降 (Frost)
- **键盘快捷键** — `1-5` 切换模式，`Space` 触发冲击波
- **导出** — 将当前故障效果导出为 SVG 文件
- **录制** — 捕获 30 帧文字状态序列导出为 JSON

## 技术栈

- Vanilla JS + CSS3 + HTML5（零构建）
- Canvas 2D 粒子流场 + 涟漪冲击波
- CSS Variables 驱动的动态故障图层
- `cubic-bezier(0.16, 1, 0.3, 1)` 非线性动效曲线
- 字体：Inter / Outfit / Share Tech Mono
