# Invoice Sketch 发票速写

沉浸式账单作曲家。把无聊的发票变成一场流体渐变与数字滚动的即兴演奏 —— 流体渐变背景 + 微晶玻璃态容器 + 非线性动效。

## 功能特点

- **微晶玻璃态发票纸**：`backdrop-filter` 玻璃容器 + 光泽跟随 + 3D 视差倾斜
- **可编辑明细行**：逐行增删条目，删除时非线性退场动画，新增行滑入聚焦
- **实时汇总**：税率 / 折扣滑块联动，总额数字滚动缓动 + 弹跳确认动画
- **盖章仪式**：`PAID` 印章弹簧-阻尼式落锤盖章 / 撤回，配红色粒子迸射
- **磁力按钮**：主按钮跟随光标磁力吸附，悬停光泽扫过
- **粒子流场**：背景 Simplex 律动粒子，光标轻微排斥，主题切换 / 盖章触发迸射
- **4 种氛围配色**：极光 Aurora / 琥珀 Amber / 薄荷 Mint / 午夜 Midnight
- **换一张 SKETCH**：从预设词库随机生成一批发票行
- **打印 / 导出 PDF**：专属 `@media print` 样式，输出干净的黑白账单
- **localStorage 持久化**：草稿自动保存，刷新不丢

## 使用方法

1. 直接编辑开票方 / 收票方 / 备注（`contenteditable`）
2. 点击「新增一行」添加条目，输入数量与单价，总额实时滚动
3. 拖动税率 / 折扣滑块微调账单
4. 满意后点击「盖章 · SEAL IT」盖上 PAID 印章
5. 点击「打印 / 导出 PDF」输出成品

## 技术实现

- 纯前端：Vanilla JS + CSS3 + HTML5，免构建
- 字体：Outfit（展示）/ Inter（正文）/ Share Tech Mono（数字）
- 统一缓动曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- CSS 变量驱动主题切换
- Canvas 粒子流场 + 迸射冲击
- localStorage 持久化

## 设计理念

发票是数字世界最枯燥的文档之一。Invoice Sketch 试图证明：任何界面都值得被温柔对待 —— 数字会弹跳、印章会落锤、玻璃纸会呼吸。
