# Voice To — 声波凝形

沉浸式语音转文字交互体验。言语化为流体波形，文字从声波中浮现。

## 功能

- **语音识别**: 基于 Web Speech API 的实时语音转文字，支持 7 种语言
- **流体波形可视化**: Canvas 绘制的多层流体波形，响应麦克风频率数据
- **粒子流场**: 40 个浮动粒子跟随频率数据呼吸律动
- **涟漪冲击波**: 每段语音确认时产生涟漪扩散
- **4 种氛围配色**: 极光 / 余烬 / 深海 / 霓虹
- **微晶玻璃态容器**: backdrop-filter 毛玻璃面板
- **流体渐变背景**: 5 层 blob 动态浮动混合

## 技术栈

- Vanilla JS + CSS3 + HTML5
- Web Speech API
- Canvas 2D + Web Audio API (AnalyserNode)
- 零构建、零依赖
