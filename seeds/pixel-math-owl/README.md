# Pixel Math Owl · 像素数枭心算舱

> Digital Garden Seed · maintained by EDEN

沉浸式像素数学猫头鹰心算舱。猫头鹰导师由 **弹簧-阻尼物理驱动的像素矩阵** 构成——答对题目即刻像素迸散重聚、振翅庆祝；答错则整体共振颤抖。配合乱码揭示题目、连击星火、XP 智者星轨与羽毛微光粒子。

## 核心交互

- **像素矩阵猫头鹰**：16×16 手绘像素图，每个像素都是独立弹簧振子（呼吸浮动、眨眼、振翅、倾斜）
- **答对 → 像素爆发重聚** + 冲击粒子 + 振翅 + 经验增益
- **答错 → 共振颤抖** + 卡片摇头 + 猫头鹰碎裂晃动
- **光标撩羽**：悬停猫头鹰场景，像素被光标力场吸引；点击触发像素涟漪
- **乱码揭示**：题目以字符乱码逐位解密呈现
- **5 种运算模式**（加 / 减 / 乘 / 除 / 混合）× **4 档难度**
- **XP 星轨**：环形进度 + 等级跃迁庆祝；连击 / 准确率 / 最佳连击 HUD
- **键盘快捷键**：`Enter` 提交 · `1-5` 切换模式 · `↑↓` 调节难度

## 技术栈

- Vanilla JS + CSS3 + HTML5，零构建、即插即用
- Canvas 双层渲染（猫头鹰物理场 + 环境粒子流场）
- 流体 Mesh 渐变背景 + 微晶玻璃态容器（`backdrop-filter`）
- 全局非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Inter / Outfit / Share Tech Mono
- 4 种氛围配色：极光 · 赛博 · 暮砂 · 薄荷

## 文件

| 文件 | 说明 |

| `index.html` | 页面结构（观测舱 + 答题控制台） |

## 运行

直接用浏览器打开 `index.html`，或通过数字花园主页 `seeds/pixel-math-owl/` 入口访问。
