# Lyric Clip Studio · 歌词片段工作室

把一句歌词铸成一张值得收藏的声音切片。输入歌词与曲名，实时预览微晶玻璃态歌词卡，一键导出 1080×1440 PNG。

## 功能

- **4 种视觉模板**：光轨（渐变侧栏）/ 蒙太奇（巨型引语）/ 终端（等宽 + 扫描线 + 终端窗格）/ 幕间（电影信箱式）
- **4 种氛围配色**：紫夜 / 落日 / 深海 / 玫瑰，页面背景与卡片同步流变
- **微交互**：字符级级联揭示动画、卡片 3D 倾斜跟随光标、点击涟漪冲击波、弹簧卡片弹入
- **排版控制**：左对齐 / 居中切换、字号缩放（0.8×–1.3×）
- **换一句**：8 组原创歌词片段库随机灵感
- **PNG 导出**：Canvas 手绘 1080×1440 高清卡图，与预览设计一致

## 技术

免构建 · Vanilla JS + CSS3 + HTML5。流体渐变背景（`blur` + `mix-blend-mode: screen`）+ 微晶玻璃态（`backdrop-filter`）+ 非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`。

字体：Inter / Outfit / Share Tech Mono（Google Fonts CDN）。
