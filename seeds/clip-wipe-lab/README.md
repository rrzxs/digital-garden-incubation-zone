# Clip Wipe Lab 裁切擦除实验室

沉浸式 CSS clip-path 裁切擦除交互实验场。

## 功能

- **7 种擦除模式**: 圆形收缩、菱形旋转、多边形、星形展开、波浪揭幕、螺旋切割、百叶窗
- **3 种交互模式**: 拖拽控制、悬停跟随、自动播放
- **参数调节**: 擦除进度、过渡时长、边数/瓣数、旋转角度、缓动曲线
- **4 种氛围配色**: 极光、余烬、深海、虚空
- **5 个叙事场景**: 每个场景拥有独特的几何装饰与配色
- **粒子流场背景**: 跟随光标扰动的粒子网络
- **流体渐变背景**: 动态 mesh gradient 大气层

## 技术

- 纯 Vanilla JS + CSS3 clip-path
- 零构建、零依赖
- 流体渐变背景 + 微晶玻璃态容器 + 非线性动效
- 动效曲线: cubic-bezier(0.16, 1, 0.3, 1)

## 操作

| 操作 | 效果 |
|------|------|
| 拖拽右侧手柄 | 手动控制擦除进度 |
| 点击「播放擦除」 | 自动播放当前擦除效果 |
| `←` `→` 或 `Space` | 切换场景并触发擦除过渡 |
| 悬停模式 | 鼠标在视口内移动控制擦除 |
