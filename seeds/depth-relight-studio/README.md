# Depth Relight Studio · 深度重光照工作室

沉浸式深度重光照工作室。从图像亮度中蒸馏深度图，实时推导演算法线场，再用一束可拖拽的光重新雕刻画面——Lambert 漫反射 + Blinn-Phong 高光 + 距离衰减，点击触发涟漪脉冲扰动深度场。

## 功能

- **深度蒸馏引擎**：亮度 → 双重 box blur → 深度图，任意图片（上传 / 拖放）即刻立体化
- **实时重光照**：拖拽光源，法线场实时响应光照方向；点击产生冲击波涟漪扰动浮雕
- **程序化示例场景**：同心山谷 + 高光核心，无需素材即刻体验
- **光照调音台**：光色（月光白/琥珀/冷蓝/玫瑰/磷光）、强度、环境光、光源深度、浮雕强度、高光锐度
- **辅助模式**：DEPTH_MAP 视图、AUTO_ORBIT 自动环绕光源
- **氛围系统**：流体渐变背景、环境粒子流场、微晶玻璃态容器，4 种氛围配色（星云/深海/余烬/棱镜）

## 技术

Vanilla JS + CSS3 + Canvas 2D，零构建、零依赖（仅 Google Fonts CDN）。所有像素计算在 360px 宽的处理缓冲上完成，`putImageData` 放大渲染。

动效曲线统一为 `cubic-bezier(0.16, 1, 0.3, 1)`。

## 使用

直接用浏览器打开 `index.html`，或通过数字花园主页的种子卡片进入。
