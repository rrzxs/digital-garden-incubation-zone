# Data Center Tour · 数据中心漫游

沉浸式等距数据中心漫游体验。3D 等距机架场 + 实时遥测面板 + 多视图切换，流体渐变背景 + 微晶玻璃态容器 + 非线性动效。

## 功能特性

- **等距 3D 机架场**：42 个服务器机架以等距投影呈现，鼠标视差驱动视角倾斜
- **机架交互**：点击任意机架聚焦，查看 24U 服务器单元详情、负载与温度
- **四种视图模式**：总览 / 机架聚焦 / 热力图（负载驱动温度着色）/ 网络拓扑
- **实时遥测**：CPU、内存、网络 I/O、PUE 指标实时缓动更新，机架负载微扰模拟
- **三层楼层**：B1 地下 / F1 一层 / F2 二层，切换重新生成机架场
- **事件日志流**：随机生成的运维事件，状态分级（正常/警告/危险）
- **粒子流场背景**：噪声驱动的粒子流，光标排斥力场交互
- **四种氛围配色**：深渊 / 等离子 / 量子 / 日冕

## 技术栈

- Vanilla JS + CSS3 + HTML5（零构建）
- CSS 变量主题系统 + `backdrop-filter` 微晶玻璃态
- `@keyframes` 流体渐变 + SVG 噪点纹理
- Canvas 粒子流场（伪噪声流场）
- 动效曲线：`cubic-bezier(0.16, 1, 0.3, 1)`

## 文件结构

```
data-center-tour/
├── index.html   # 完整 HTML 结构
├── style.css    # 流体背景 + 玻璃态容器 + 等距场景样式
├── main.js      # 机架生成 / 交互 / 遥测 / 粒子流场逻辑
└── README.md
```

## 使用

直接用浏览器打开 `index.html` 即可。点击机架探索，切换视图与楼层，移动鼠标感受粒子流场。
