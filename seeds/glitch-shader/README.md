# Glitch Shader 故障着色器

> 沉浸式 WebGL 故障着色器体验场。GPU 片元着色器实时驱动六种故障模式（RGB 色差 / 数据损毁 / 扫描线撕裂 / 像素排序 / 故障波纹 / 风暴），输入文字即刻化为故障艺术，光标扰动色差方向、脉冲冲击波触发瞬时数据崩塌，流体渐变背景 + 微晶玻璃态容器，4 种氛围配色。

## 核心亮点

本种子与其他故障类种子的关键差异：**真正的 WebGL 片元着色器（Fragment Shader）**在 GPU 上对每一像素实时失真，而非 Canvas 2D 逐帧重绘。文字通过离屏 Canvas 栅格化为纹理后上传 GPU，由片元着色器采样并对 RGB 三通道分别施加位移、撕裂与色彩偏移，性能可承载 4K 全屏且保持 60fps。

## 核心交互

| 模式 | 行为 |
|------|------|
| **色差 CHROMA** | RGB 三通道按光标方向分离，营造经典色散光晕，附轻微水平切片 |
| **损毁 DATAMOSH** | 大幅水平数据块错位与垂直块合并，模拟视频流损毁崩塌 |
| **扫描 SCANLINE** | CRT 扫描线撕裂，水平切片沿垂直方向密集断带 |
| **像素 PIXEL** | 马赛克块采样，每块独立漂移，故障像素排序美学 |
| **波纹 WAVE** | 正弦波纹驱动双向位移，文字如水波般扭动 |
| **风暴 STORM** | 所有失真叠加，大色差 + 双层切片 + 波动，极致故障风暴 |

## 参数调节

- **故障强度** — 0.00 ~ 1.00（主控所有失真的幅度）
- **色差偏移** — 0.00 ~ 1.00（RGB 通道分离距离）
- **撕裂频率** — 0.00 ~ 1.00（水平切片密度）
- **抖动速度** — 0.00 ~ 3.00（时间流速，控制动画快慢）
- **字号** — 0.40 ~ 1.80（文字在纹理中的大小）

## 操作

- **输入文字** — 文字被实时栅格化为 GPU 纹理，即刻应用失真
- **移动光标** — 光标位置与速度扰动色差方向与全局抖动
- **点击画布** — 触发数据崩塌脉冲冲击波 + 故障种子重洗
- **脉冲按钮** — 在光标位置释放全屏冲击波
- **随机按钮** — 随机模式 / 配色 / 参数组合
- **截图按钮** — 通过 `gl.readPixels` 导出当前帧为 PNG

## 键盘快捷键

- `1` ~ `6` — 切换故障模式
- `Space` — 触发脉冲
- `R` — 随机
- `S` — 截图

## 技术栈

- Vanilla JS + WebGL 1（GLSL ES 1.00 片元着色器，无构建、无依赖）
- GPU 实时失真：通道分离 / 块切片 / 马赛克 / 波动 / 冲击波位移
- 离屏 Canvas 2D 文字栅格 → `texImage2D` 上传纹理
- `preserveDrawingBuffer: true` 启用 `readPixels` 截图导出
- CSS3 自定义属性 + `backdrop-filter` 微晶玻璃态
- `cubic-bezier(0.16, 1, 0.3, 1)` 非线性动效曲线
- 字体：Inter / Outfit / Share Tech Mono
