# Shot Blocker Previs 封盖预演

沉浸式篮球封盖预演交互体验。以 PREVIS（预视化）为核心隐喻：拖拽篮球瞄准时实时绘制虚线轨迹预测，松手出手后弹簧-阻尼封盖者会延迟反应、锁定预测拦截点并扑向球线——SCORE / BLOCKED / MISS 三态判定。

## 交互

- **拖拽瞄准**：从出手点拖拽篮球形成弹弓张力，力度环实时显示强度，虚线为 PREVIS 轨迹预测
- **三档封盖者**：ROOKIE / PRO / ELITE，对应不同反应延迟、预测误差、触达半径与弹簧刚度
- **弹簧-阻尼封盖物理**：`F = −kx − cv`，封盖者追踪带过冲与回弹
- **判定反馈**：SCORE（涟漪粒子 + 冲击波）、BLOCKED（反应时间遥测）、MISS
- **实时遥测面板**：出手角度 / 力度 / 预测弧顶 / 封盖者状态 / 飞行时间
- **4 种氛围配色**：Aurora / Ember / Abyss / Vapor

## 技术

Vanilla JS + Canvas 2D + CSS3，零构建、零依赖。流体渐变背景 + 微晶玻璃态容器，全局动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`。
