# Sound Canvas 声弦画布

> 落笔即成曲，松手即成画。

沉浸式声画合成画布。以光标作画即谱曲——纵向定位音高（音阶量化）、横向控制声像漫游、笔速调节音色明暗与线宽。松手后画作永久留存，回放模式让扫描线扫过笔迹，逐点触发音符与光尘绽放，画作即乐谱。

## 玩法

1. **作画即演奏**：按住画布拖动，纵向位置映射音高（实时量化到所选音阶），左右映射声像，快笔轻盈、慢笔沉稳。
2. **回放**：点击「回放」或按 `Space`，扫描线从左至右扫过画作，逐点重新触发音符与绽放光晕。
3. **撤销 / 清空**：管理笔迹层级，音符数与时长 HUD 实时更新。

## 配置矩阵

- **音色 × 4**：Glass（玻璃）/ Bell（钟磬）/ Pluck（拨弦）/ Pad（氛围）
- **音阶 × 4**：大调五声 / 小调五声 / Dorian / Lydian
- **氛围配色 × 4**：星云 / 深海 / 余烬 / 极光（背景流体渐变与笔迹色相同步切换）

## 技术

- Vanilla JS + CSS3 + HTML5，零构建、零依赖
- Web Audio API 实时合成（双振荡器 + 低通 + 立体声声像 + 反馈延迟空间感）
- Canvas 双层渲染：持久画层（呼吸透明度合成）+ 效果层（光尘粒子 / 回放绽放）
- 弹性笔刷物理（弹簧追踪插值）、笔速-力度耦合
- 流体网格渐变背景 + 微晶玻璃态容器 + `cubic-bezier(0.16, 1, 0.3, 1)` 非线性动效
- 字体：Inter / Outfit / Share Tech Mono
