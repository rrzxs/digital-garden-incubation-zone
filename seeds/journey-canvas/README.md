# Journey Canvas 旅途画布

沉浸式手绘旅途航线体验。在画布上随手画一条线，它即刻被平滑为发光航线：自动生成诗意里程碑站点、旅行者光球沿轨迹行驶、可拖拽时间线回溯旅途。

## 功能

- **手绘航线**：按住拖动画出路径，Chaikin 切角平滑成流体航线
- **自动里程碑**：沿途按弧长自动布站，12 组诗意站名与诗句随机编排
- **旅行者光球**：弹簧-阻尼进度物理，速度尾翼 + 发光轨迹拖尾
- **乱码揭示站点卡**：抵达站点时站名与诗句以乱码揭示动画浮现
- **时间线回溯**：可拖拽进度条，点击站点标记直接跳转
- **粒子流场**：环境粒子受噪声流场与光标力场双重扰动
- **4 种氛围配色**：深海 / 极光 / 余烬 / 虚空
- **速度调节**：0.2x ~ 3x 旅途速度
- **键盘控制**：空格播放/暂停，R 重画，C 清除

## 技术栈

- Vanilla JS + CSS3 + HTML5（免构建）
- Canvas 2D：路径渲染 / 旅行者 / 粒子流场 / 涟漪
- Chaikin 切角平滑算法 + 二分弧长查询
- CSS 流体渐变背景 + 微晶玻璃态容器
- 非线性动效 cubic-bezier(0.16, 1, 0.3, 1)

## 操作

| 操作 | 效果 |
|------|------|
| 画布按住拖动 | 绘制旅途航线 |
| 松开 | 航线生成，站点就位 |
| 点击「出发」/ 空格 | 旅行者沿航线行驶 |
| 拖动时间线 | 回溯 / 前进旅途 |
| 点击时间线站点标记 | 跳转至该站点 |
| 点击画布 | 涟漪扩散 |
| 速度滑块 | 调节行驶速度 |
| R / C | 重新作画 / 清除 |
| 主题按钮 | 切换氛围配色 |
