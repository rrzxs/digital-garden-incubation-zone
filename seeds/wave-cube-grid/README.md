# Wave Cube Grid 波态立方阵列

> 沉浸式 3D 波纹立方体微交互体验场。

## 概述

Wave Cube Grid 是一个基于 CSS 3D Perspective + Spring-Damper 物理模型的交互式立方体阵列体验。鼠标移动时，网格中的立方体会像水面被触碰一样产生波纹起伏，每个立方体独立响应光标力场，拥有弹性升降、轴向旋转、缩放脉动与发光高亮四重物理反馈。

## 核心交互

### 五种力场模式

| 模式 | 描述 |
|------|------|
| **Ripple 涟漪** | 光标半径内的立方体受径向力场升降，越近越高 |
| **Wave 波浪** | 距离驱动的正弦波相位，立方体呈连续波浪起伏 |
| **Vortex 漩涡** | 切向力场驱动立方体旋转倾斜，形成漩涡形态 |
| **Pulse 脉冲** | 周期性脉冲力场，立方体随节律呼吸跳动 |
| **Auto 自动** | 光标自动巡游，周期性触发涟漪脉冲，展示模式 |

### 物理模型

- **Spring-Damper 弹簧阻尼系统**：每个立方体拥有独立的 elevation / rotation / scale 三个物理通道
- **非线性缓动**：所有过渡使用 `cubic-bezier(0.16, 1, 0.3, 1)` 物理曲线
- **可调参数**：波纹半径、弹性强度、阻尼系数实时调节

### 视觉特性

- **流体渐变背景**：4 层 mix-blend-mode:screen 的动态 blob 构建呼吸感氛围
- **微晶玻璃态容器**：backdrop-filter:blur(44px) + 发光描边的主面板
- **3D 透视舞台**：perspective(900px) 赋予立方体立体景深
- **Canvas 粒子轨迹**：光标移动留下渐隐粒子流，点击触发粒子迸射
- **涟漪环传播**：点击产生双层涟漪环，影响沿途所有立方体
- **HUD 遥测面板**：实时显示模式、立方体数、FPS 与能量条

## 技术栈

- Vanilla JS + CSS3 + HTML5
- 零构建、零依赖
- 字体：Inter / Outfit / Share Tech Mono
- Google Fonts CDN 引入

```
wave-cube-grid/

├── style.css    # 完整样式（背景、容器、动效）
├── main.js      # 交互逻辑（物理引擎、渲染、控制）

```

## 使用方式

直接在浏览器中打开 `index.html` 即可体验。移动鼠标唤醒立方体，点击触发脉冲涟漪，切换模式探索不同力场效果。
