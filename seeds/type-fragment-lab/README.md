# Type Fragment Lab — 文字碎片实验室

沉浸式文字碎片微交互体验。输入文字即刻被切片为碎片晶格，每个碎片都是独立的弹簧-阻尼物理体，在五种碎片模式中流变、爆破与重组。流体渐变背景 + 微晶玻璃态容器 + 非线性动效。

## 碎片模式

- **Scatter 散裂** — 碎片以种子随机方向散布，带呼吸律动
- **Orbit 环轨** — 碎片按切片序号环绕字形中心轨道运转
- **Cascade 瀑布** — 字符级联错峰，碎片沿纵向滑移坠落
- **Storm 风暴** — 双频正弦湍流驱动的混沌碎片风暴
- **Still 静默** — 碎片归位静止，仅响应光标力场

## 交互

- 碎片密度：2–9 片切片实时重组字符
- 光标力场：排斥 / 吸引 / 涡旋三种模式实时扰动碎片
- 碎片爆破：全屏冲击波爆破后弹簧重组（Space 键）
- 点击舞台：任意位置发射径向冲击波涟漪
- 悬停字符：HUD 遥测显示碎片数与动能
- 随机模式：随机切换模式与参数（S 键）
- 重组重置：恢复默认状态（R 键）
- 数字键 1-5：快速切换碎片模式

## 氛围配色

- Nebula 星云（青紫）
- Solar 日珥（金橙）
- Rose 蔷薇（玫粉）

## 技术栈

Vanilla JS + CSS3 + HTML5，零构建依赖。物理模型：弹簧-阻尼积分（k=0.045, damp=0.88），碎片采用 clip-path 条带切片。
