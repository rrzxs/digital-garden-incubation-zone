# Brand Morph Timeline — 品牌形变时间线

沉浸式品牌形变时间线交互体验。时间轴驱动品牌色彩、字体与形态流变，微晶玻璃态容器 + 非线性动效 + 粒子流场。

## 功能

- **7 个品牌纪元**：从 Prism 到 Aether，每个纪元拥有独特的色彩、字体权重与字距
- **4 种形态模式**：光棱 / 球体 / 晶体 / 波场，Simplex 噪声驱动的实时形变
- **可拖拽时间轴**：拖拽滑块或点击节点跳转纪元，支持键盘方向键
- **4 种氛围配色**：极光 / 余烬 / 深海 / 翠林
- **粒子流场**：背景噪声粒子系统，鼠标力场交互与邻近连接线
- **自动播放**：空格键或按钮启动自动循环播放
- **参数调节**：变形速度、粒子密度、噪声扰动实时可调

## 交互

| 操作 | 效果 |
|------|------|
| 点击时间轴节点 | 跳转至对应纪元 |
| 拖拽时间轴滑块 | 连续切换纪元 |
| 左右方向键 | 上一个 / 下一个纪元 |
| 空格键 | 切换自动播放 |
| 鼠标移动 | 扰动背景粒子流场 |

## 技术

- Vanilla JS + CSS3 + HTML5
- Simplex Noise 2D 算法
- Canvas 2D 粒子系统与形态绘制
- CSS 变量驱动的主题切换
- 无构建依赖，即开即用
