# Demo Activator 唤醒之触

沉浸式高阶微交互剧场 — 一个集合 6 种「唤醒」类微交互的展示舞台，并以中央可唤醒的「核心」串起整体能量叙事。

## 核心体验

舞台被切分为六个微交互模块，围绕中心的**唤醒体（Core）**展开：

1. **Core 中央唤醒体** — 长按蓄能，能量充满时迸发冲击波涟漪，并触发全局闪光
2. **Pulse Charge 脉冲蓄能** — 按住按钮蓄能，SVG 进度环非线性增长，释放产生涟漪
3. **Magnetic Drift 磁力漂移** — 光标进入磁场范围，碎片被引力牵引后柔顺归位
4. **Spring Drag 弹簧拖拽** — 可拖拽节点带越界限制，松手后弹簧-阻尼系统唤回
5. **Reveal Stencil 模板揭示** — CSS mask 光标遮罩切开上层文字
6. **Flow Trail 流体轨迹** — 局部 Canvas 流场粒子尾迹，速度驱动发射密度
7. **Sequence Burst 级联迸发** — 随机洗牌序列级联点亮网格单元

## 技术实现

- 纯 Vanilla JS + CSS3 + HTML5，零依赖、免构建
- 4 种氛围配色：深海 / 极光 / 余烬 / 虚空（CSS 变量动态切换）
- 弹簧-阻尼物理模型驱动 Spring 模块归位
- Canvas 2D 渲染全局背景流场与 Module 05 局部流场
- SVG dashoffset 实现 Pulse 蓄能环非线性进度
- CSS `mask-image` 实现 Reveal 光标遮罩
- 全部交互动效使用 `cubic-bezier(0.16, 1, 0.3, 1)` 非线性缓动
- 流体渐变背景 + 4 层 blob 漂浮 + 噪点纹理
- 微晶玻璃态容器（backdrop-filter + 高光描边 + 内阴影）

## 字体

- Outfit — 标题与品牌字
- Inter — 正文
- Share Tech Mono — 数据/HUD/编号

## 配色方案

4 种氛围配色：深海 / 极光 / 余烬 / 虚空

## 键盘 / 鼠标提示

- **按住** 中央核心：唤醒能量
- **按住** Pulse 按钮：蓄能
- **拖拽** Spring 节点：感受弹性
- **移动** 光标：触发磁场与揭示
- **点击** Sequence 按钮：触发级联迸发
