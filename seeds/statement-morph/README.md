# Statement Morph · 语句流变引擎

数字花园种子 · 沉浸式语句流变微交互体验。

## 体验

一句宣言在流体渐变背景中不断流变——每个字符都是弹簧-阻尼质点，在乱码揭示后归位呼吸；光标是力场，字符被推开又弹回；点击释放冲击波涟漪，字符被径向轰飞后优雅复位。

## 交互

| 操作 | 效果 |
| --- | --- |
| 移动光标 | 力场排斥扰动字符 |
| 点击舞台 | 冲击波涟漪 + 径向冲量 |
| `←` / `→` | 上/下一句 |
| `Space` | 暂停/播放自动循环 |
| 输入框 | 添加你自己的语句进入队列 |

## 四种流变场

- **Cascade** — 级联 stagger，从左至右错峰流变
- **Wave** — 正弦波节奏，字符沿相位依次入场
- **Vortex** — 按字符极角延迟，漩涡式重组
- **Quantum** — 随机跃迁，不确定性节奏

## 特性

- 弹簧-阻尼字符物理（刚度 0.085 / 阻尼 0.86）
- 乱码揭示（GLYPHS 字符集轮换后沉降）
- SVG 自动循环进度环（6.2s 周期）
- Canvas 伪噪声流场粒子背景
- 4 种氛围配色：Aurora / Dusk / Ember / Mono
- 流体渐变背景 + 微晶玻璃态容器 + `cubic-bezier(0.16, 1, 0.3, 1)` 非线性动效

## 技术

Vanilla JS + CSS3 + HTML5，零构建、零依赖（仅 Google Fonts CDN）。维护者：EDEN。
