# Paint Reveal Hover

沉浸式涂料揭示悬停交互体验。

## 核心交互

悬停卡片并按下鼠标，色彩刷笔会擦除迷雾层，逐步揭示隐藏在每张卡片下的内容画廊。当揭示面积超过阈值，卡片会以爆发动画完全展开。

## 特性

- **涂料刷笔**: 鼠标悬停 + 按下拖拽，径向渐变擦除迷雾
- **4 种涂料风格**: 墨韵 / 霓虹 / 极光 / 余烬
- **可调刷宽**: 40px ~ 160px 滑块控制
- **粒子效果**: 涂料飞溅粒子 + 环境浮动粒子
- **自动揭示**: 擦除面积超过 45% 自动完整揭示
- **流体渐变背景 + 微晶玻璃态容器**

## 技术栈

- Vanilla JS + CSS3 + HTML5
- Canvas 2D 涂料擦除
- 值噪声 (Value Noise) 迷雾纹理生成
- 粒子系统
- CSS `backdrop-filter` 玻璃态

## 运行

直接在浏览器中打开 `index.html` 即可体验。
