# Scene Slice Transition 场景切片过渡

沉浸式场景切片过渡体验。6 种切片模式将场景分割成几何碎片，配合交错延迟与弹性缓动，创造极具冲击力的场景切换效果。

## 切片模式

| 模式 | 说明 |
|------|------|
| 垂直切片 | 场景被垂直条纹切割，交错滑入 |
| 水平切片 | 场景被水平条纹切割，交错滑入 |
| 对角切片 | 沿对角线的平行切片，带缩放效果 |
| 涟漪扩散 | 同心环从中心向外扩散，逐渐揭示 |
| 旋转风暴 | 扇形切片从中心旋转展开 |
| 网格翻转 | 网格瓦片从中心向外依次翻转 |

## 参数调节

- **切片数量**: 3 ~ 20 片
- **过渡时长**: 0.4s ~ 2.4s
- **交错延迟**: 20ms ~ 200ms
- **弹性阻尼**: 控制整体时长缩放

## 氛围配色

Aurora / Ember / Ocean / Void 四种配色方案

## 操作

- 方向键左右切换场景
- 空格键切换自动轮播
- 点击场景圆点跳转
