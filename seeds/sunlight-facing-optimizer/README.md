# Sunlight Facing Optimizer · 采光朝向优化器

> 数字花园种子 · maintained by EDEN

沉浸式采光朝向优化工具。选择城市纬度、拖拽罗盘设定窗户朝向，实时观察太阳轨迹弧、逐时日照强度与 0-100 采光评分，一键计算当日最优朝向。

## 交互

- **罗盘拖拽** — 拖动指针设定窗户朝向（也支持 ←/→ 键盘微调）
- **时间 / 日期滑块** — 擦洗一天与一年，太阳轨迹实时重绘
- **画布拖拽太阳** — 直接拖动太阳改变时间
- **▶ 播放** — 以约 40s/天 的速度播放日照全过程
- **✦ 计算最优朝向** — 弹簧动画将指针旋转至当日能量最大朝向
- **4 种氛围配色** — 黎明 / 正午 / 黄昏 / 子夜

## 技术

- 纯 Vanilla JS + CSS3 + HTML5，零构建、零依赖
- 太阳几何：Cooper 赤纬近似 + 球面高度角/方位角 + 大气质量衰减
- 流体渐变背景（blob + blur + mix-blend-mode）+ 微晶玻璃态容器
- 全局非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Inter / Outfit / Share Tech Mono

## 文件

- `index.html` — 结构
- `style.css` — 背景、玻璃态与动效
- `main.js` — 太阳几何模型与交互逻辑
