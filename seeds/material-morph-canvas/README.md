# Material Morph Canvas 材质形变画布

沉浸式材质形变交互体验场。弹簧-阻尼物理驱动的顶点网格在五种材质形态（液态 / 玻璃 / 晶体 / 等离子 / 织物）间实时形变，光标力场扰动、点击冲击波涟漪、粒子流场与参数调节，流体渐变背景 + 微晶玻璃态容器。

## 交互

- **鼠标移动** — 力场排斥扰动材质顶点，光标速度传递动量
- **点击画布** — 触发冲击波涟漪 + 粒子迸射
- **材质切换** — 五种材质形态间平滑过渡（顶点速度继承）
- **参数滑块** — 张力 / 粘度 / 噪声实时调节物理表现
- **脉冲** — 中心冲击波爆发
- **随机** — 随机扰动所有顶点
- **重置** — 恢复初始状态
- **键盘** — `1-5` 切换材质 · `空格` 脉冲 · `R` 重置

## 五种材质形态

| 材质 | 特征 |
|------|------|
| 液态 Liquid | 流体波动 · 表面张力 · Catmull-Rom 平滑曲线 |
| 玻璃 Glass | 刚性多面体 · 棱角切面 · 锐利多边形边 |
| 晶体 Crystal | 尖锐星形 · 对称生长 · 内部辐射连接线 |
| 等离子 Plasma | 高能无序 · 开放曲线 · 粒子连接网络 |
| 织物 Fabric | 柔顺垂坠 · 经纬编织 · 径向网格线 |

## 技术栈

- Vanilla JS + Canvas 2D + CSS3
- 值噪声 (Value Noise) 驱动形态扰动
- 弹簧-阻尼物理模型 (Spring-Damper)
- Catmull-Rom 二次贝塞尔平滑路径
- CSS `backdrop-filter` 微晶玻璃态
- CSS `@keyframes` 流体渐变背景
- `cubic-bezier(0.16, 1, 0.3, 1)` 非线性缓动
