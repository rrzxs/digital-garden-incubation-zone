# Fragment Type Poster 碎片字海报

数字花园种子 · 沉浸式碎片字海报锻造工作室。

## 体验

输入文字即刻锻造为弹簧-阻尼物理驱动的活体碎片海报——

- **4 种碎片编排**：散射（主标铺排）/ 瀑布（字号级联）/ 环轨（环绕构图）/ 故障（错位撕裂）
- **光标力场**：斥力 / 引力 / 涡旋 三种实时扰动，附准星力场环
- **冲击波**：点击海报轰击碎片，空格触发全场脉冲，火花粒子迸射
- **乱码揭示**：碎片以幽灵字形逐渐解密为真实字符
- **4 种氛围配色**：霓虹夜 / 熔岩烬 / 冷萃薄荷 / 紫外幻影
- **CHAOS 滑杆**：控制呼吸漂移振幅与故障撕裂概率
- **PNG 导出**：一键导出当前海报画布

## 技术

- Vanilla JS + Canvas 2D + CSS3，零构建
- 字体：Inter / Outfit / Share Tech Mono
- 动效曲线：`cubic-bezier(0.16, 1, 0.3, 1)`
- 流体渐变背景（blur + mix-blend-mode: screen）+ 微晶玻璃态容器
