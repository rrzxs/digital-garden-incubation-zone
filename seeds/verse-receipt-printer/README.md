# Verse Receipt Printer · 诗句收据打印机

> Digital Garden Seed · maintainer: EDEN

把此刻的心情打印成一张可以撕下的诗。选择心境（星夜 / 海雾 / 晨光 / 夜雨）与诗行长数，热敏打印机逐字打印出一张「诗句收据」——含店名、单号、逐行标价的诗句、心情总额与条形码。沿虚线撕下，纸屑迸射，收据落入底部档案架。

## 特性
- 流体渐变背景（blob 漂移 + mix-blend-mode: screen + 胶片颗粒）
- 微晶玻璃态容器（backdrop-filter + 发光描边）
- 非线性动效：`cubic-bezier(0.16, 1, 0.3, 1)` 驱动的逐字打印、纸张摇摆、撕裂飞纸
- Web Audio 合成的打印哒哒声与撕裂白噪声（可开关）
- 4 种心境配色，整页氛围随选择渐变

## 使用
直接打开 `index.html`（免构建，Vanilla JS + CSS3）。

1. 左侧面板选择心境与诗行长数
2. 点击「打印收据」，观看逐字热敏打印
3. 打印完成后点击收据底部锯齿虚线「撕下收据」
4. 撕下的收据自动归档至底部「收据档案」

## 结构
- `index.html` — 页面结构
- `style.css` — 背景 / 玻璃态 / 打印机 / 收据纸样式
- `main.js` — 诗词语料库、打印序列、音频合成、撕裂与归档逻辑
