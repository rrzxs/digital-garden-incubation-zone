# Scroll Comic | 滚动漫画

沉浸式滚动漫画叙事体验。将浏览器窗口化作一卷活生生的漫画书，7 幕故事分镜随着你的滚动逐一展开。每个分镜包含独特的纯 CSS 艺术场景、对话气泡、旁白字幕与逐字揭示动画。

## 故事概要

**Signal from the Void** — 一段来自虚空的信号，一次无法回头的觉醒。从午夜信号塔的脉冲，到深渊之眼的睁开，到邂逅未知存在，到面临不可能的选择，最终——融为一体，成为新的灯塔。

## 交互亮点

- **滚动驱动分镜揭示** — 每个分镜面板进入视口时交错浮现
- **逐字对话揭示** — 对话气泡文字逐字符浮现
- **视差深度** — 艺术面板与叙事面板以不同速度滚动，营造纵深
- **纯 CSS 艺术场景** — 信号塔脉冲波、开合巨眼、深渊隧道、实体碎片轨道、抉择双球、螺旋融合
- **粒子流场** — Canvas 粒子受鼠标吸引并自动连线
- **光标追踪光晕** — 鼠标位置发出柔和紫色辉光
- **顶部 HUD** — 实时章节名与分镜编号
- **侧边进度轨** — 可点击的面板导航圆点
- **重播功能** — 从头重新阅读，所有揭示动画复位

## 技术栈

- Vanilla JS + CSS3 + HTML5（零构建）
- Google Fonts: Inter, Outfit, Share Tech Mono
- 动效曲线: `cubic-bezier(0.16, 1, 0.3, 1)`
- IntersectionObserver 驱动分镜揭示
- Canvas 粒子流场系统
- 纯 CSS keyframes 驱动所有艺术场景动画
