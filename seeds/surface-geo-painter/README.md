# Surface Geo Painter · 曲面几何画师

沉浸式 3D 曲面雕塑绘画工作室。不同于平面绘画——这里的画布是一张**活的微晶曲面**：每一次拖拽都在旋转的 40×40 高度场上塑形，弹簧-阻尼物理与邻域波动耦合让几何以非线性曲线呼吸、回弹与涟漪传播。

## 核心交互

- **6 种雕塑画笔**: Raise 隆起 / Carve 雕刻 / Smooth 平滑 / Ripple 涟漪（速度脉冲激发传播波）/ Spike 晶峰（随机结晶）/ Flatten 抚平
- **轨道视角**: 空格或右键拖拽旋转、滚轮缩放、Spin 自转模式，随时环视作品
- **径向对称**: 1×~8× 对称笔触，让构图自发涌现
- **笔刷光环**: 光标处的曲面投影实时预览笔刷半径
- **程序化地形**: FBM 值噪声一键生成边缘衰减的高原地形
- **撤销 / 重做 / PNG 导出**: 完整创作闭环
- **3 种渲染风格**: Solid 实体（法线光照 + 深度雾）/ Wire 线框 / Dots 点阵
- **环境呼吸**: 待机时曲面以极缓的正弦节律起伏

## 微交互细节

- 曲面物理: `弹簧归位 + 拉普拉斯波动耦合 + 阻尼衰减`，画家算法深度排序 + 背面剔除
- 所有 UI 状态迁移使用 `cubic-bezier(0.16, 1, 0.3, 1)` 非线性曲线
- 流体网格渐变背景（5 团 mix-blend-mode 光斑）+ 微晶玻璃态容器 + 粒子流场
- 点击涟漪、Toast、光标光晕惯性跟随、滚动揭示入场

## 快捷键

`1-6` 画笔 · `空格` 轨道 · `A` 自转 · `R` 随机地形 · `F` 抚平 · `Z/⇧Z` 撤销/重做 · `E` 导出

## 配色

极光 Aurora / 余烬 Ember / 深渊 Abyss / 兰若 Orchid

## 技术

Vanilla JS + Canvas 2D + CSS3，免构建，即开即用。
