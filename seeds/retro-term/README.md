# Retro Term — 复古终端

沉浸式复古终端模拟体验。流体渐变背景 + 微晶玻璃态容器 + CRT 扫描线效果 + Web Audio 音效反馈。

## 功能

- 完整终端模拟：命令输入、历史记录（↑↓）、Tab 自动补全
- 多种内置命令：help, about, sysinfo, matrix, ping, fortune, figlet, cowsay, glitch, color, date, whoami, echo, theme, clear, sound
- 4 种配色方案：Phosphor (绿)、Amber (琥珀)、Cyan (青)、Rose (玫红)
- CRT 扫描线效果 + 流体网格渐变背景
- Web Audio API 音效：击键声、回车声、错误声、成功提示音
- 开机启动序列动画 + 故障艺术效果
- 微晶玻璃态 (Glassmorphism) 容器

## 技术

- Vanilla JS + CSS3 + HTML5，零构建
- 字体：Share Tech Mono, Inter, Outfit
- 动效曲线：cubic-bezier(0.16, 1, 0.3, 1)

## 使用

直接打开 `index.html` 即可使用。点击页面任意位置后开始输入命令。
