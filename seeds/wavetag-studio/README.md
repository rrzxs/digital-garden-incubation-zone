# Wavetag Studio 波痕标签工坊

数字花园种子 · 免构建（Vanilla JS + Canvas + CSS3）

## 简介

输入一句话，每个字符都会凝成一颗弹簧-阻尼物理实体，在流形波场上起伏、避让与共振。

## 交互

- **撒入波场**：输入任意文字（≤28 字符），回车或点击按钮，字符从中心弹射入场
- **力场模式**：斥力 / 引力 / 漩涡 三种光标力场，实时扰动字符
- **点击冲击波**：点击画布发射涟漪冲击波，字符被径向推散后弹簧回归
- **波幅调节**：拖动滑杆改变波场振幅
- **氛围配色**：深海电台 / 熔金落日 / 翡翠磷光 / 霓虹夜曲 四种氛围
- **遥测面板**：字符数 / 波场能量 / 光标力 / 涟漪计数实时读数

## 技术要点

- 弹簧-阻尼物理（stiffness 42 / damping 7.5）驱动的字符回归与旋转
- 三重正弦叠加流形波场作为字符锚点
- 流体渐变背景（超大模糊 + screen 混合模式）
- 微晶玻璃态容器（backdrop-filter + 发光描边）
- 全局非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Outfit / Inter / Share Tech Mono
