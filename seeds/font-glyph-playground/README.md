# Font Glyph Playground — 字形游乐场

一个交互式字体字形形变实验场。输入任意文字，实时操控字重、字宽、字距、斜度、字号五大字体坐标轴，配合 5 种动画预设与涂抹扰动模式，感受字体的非线性形变与呼吸。

## 核心交互

- **字体坐标轴操控**: Weight (字重 100–900)、Width (字宽 50–150%)、Tracking (字距)、Slant (斜度 ±30°)、Size (字号)
- **5 种动画预设**:
  - `Idle` 静止 — 仅响应悬停
  - `Breathe` 呼吸 — 字符随正弦周期缩放发光
  - `Jitter` 抖动 — 高频微抖动，故障美学
  - `Wave` 波浪 — 横向波动起伏
  - `Bounce` 弹跳 — 上下弹动节奏
- **涂抹模式 (Brush)**: 按下并拖拽鼠标，字符被冲击波推开、旋转、放大并发光
- **悬停磁吸**: 光标靠近字符时，字符被磁力吸引并发光高亮
- **扰动按钮**: 一键对所有字符施加随机物理冲击
- **实时文字输入**: 顶部输入框即时更新舞台内容（支持中英文，最多 32 字符）

## 特色

- 弹簧-阻尼物理模型驱动的字符动力学
- 粒子流场背景 + 光标连接线
- 4 种氛围配色: 虚空 / 翡翠 / 日蚀 / 极地
- 流体网格渐变背景 + 微晶玻璃态容器
- 全非线性 `cubic-bezier(0.16, 1, 0.3, 1)` 动效曲线

## 技术栈

- Vanilla JS + CSS3 + HTML5 (Zero-Build)
- Canvas 2D 粒子渲染
- CSS `font-weight` / `font-stretch` / `letter-spacing` 字体坐标轴
- 弹簧物理系统 + requestAnimationFrame 循环
