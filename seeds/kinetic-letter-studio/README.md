# Kinetic Letter Studio · 动力学字符工作室

沉浸式动力学字符微交互体验。输入任意文字，每个字符即刻成为弹簧-阻尼物理实体——在四种力场模式中流变、迸散与归位。

## 交互

- **Magnetic** — 光标磁力吸附字符，字符越近越"粘"
- **Repel** — 光标斥力场推开字符，带旋转反作用
- **Vortex** — 切向涡旋力场，字符环绕光标旋转
- **Gravity** — 重力坠落 + 地面弹跳 + 值噪声风场扰动
- **点击舞台** — 冲击波涟漪迸散字符 + 粒子爆裂
- **拖拽扫过字符** — 直接注入动量抛掷
- **S / Space / R** — 随机重组 / 冲击波 / 复位归位

## 特性

- 弹簧-阻尼物理（刚度 / 阻尼 / 力场强度可调）
- 乱码揭示入场动画（scramble reveal）
- 值噪声驱动的环境粒子流场
- 流体渐变背景 + 微晶玻璃态容器
- 4 种氛围配色：Aurora / Ember / Cyber / Mono
- 全部动效遵循 `cubic-bezier(0.16, 1, 0.3, 1)` 非线性曲线

## 技术

Vanilla JS + CSS3 + HTML5，免构建，直接打开 `index.html` 即可运行。
