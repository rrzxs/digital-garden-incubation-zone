# Humanoid Compare · 人形机体对比舱

沉浸式人形机器人双机对比工具。选取两台机体，见证参数在流体场中交锋——共振雷达、能力脉冲条、规格卡片与数字递增。

## 特性

- **双机对抗选择**：8 台虚构混合规格机体，两侧选择自动防冲突，磁力交换按钮一键对调
- **共振雷达**：Canvas 绘制的双多边形雷达图，呼吸微扰动 + 点击涟漪 + 展开缓动
- **能力脉冲条**：7 项指标归一化对比，悬停扫光 + 差值遥测读数
- **规格卡片**：3D 倾斜物理 + 眩光跟随 + 数字递增动画
- **流体渐变背景**：多层 blob 漂移 + mix-blend-mode screen + 环境粒子流场
- **微晶玻璃态容器**：backdrop-filter blur + 发光描边
- **4 种氛围配色**：Aurora / Nebula / Reactor / Abyss，主题持久化

## 技术栈

- Vanilla JS + CSS3 + HTML5，免构建
- 字体：Inter / Outfit / Share Tech Mono
- 动效曲线：`cubic-bezier(0.16, 1, 0.3, 1)`

## 使用

直接用浏览器打开 `index.html`，或通过数字花园主站种子卡片进入。
