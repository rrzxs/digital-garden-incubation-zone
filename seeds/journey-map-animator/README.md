# Journey Map Animator 旅途地图动画

沉浸式旅途地图动画体验。Catmull-Rom 样条曲线路径、实时旅行者轨迹绘制、粒子流场与微晶玻璃态容器。

## 功能

- **旅途路径动画**：6 个故事站点，Catmull-Rom 样条曲线平滑连接
- **旅行者轨迹**：实时绘制发光轨迹，记录旅途足迹
- **粒子流场**：120 个粒子漂浮，鼠标力场交互扰动
- **站点交互**：点击站点跳转，自动播放 / 手动导航
- **4 种氛围配色**：深海 / 极光 / 余烬 / 虚空
- **速度调节**：0.2x ~ 3x 可调旅途速度
- **键盘控制**：空格播放/暂停，左右箭头导航

## 技术栈

- Vanilla JS + CSS3 + HTML5
- Canvas 2D 粒子系统 & 轨迹绘制
- Catmull-Rom 样条插值算法
- CSS 流体渐变背景 + 微晶玻璃态容器
- 非线性动效 cubic-bezier(0.16, 1, 0.3, 1)

## 操作

| 操作 | 效果 |
|------|------|
| 点击「出发」按钮 | 开始旅途动画 |
| 空格键 | 播放 / 暂停 |
| 左右箭头 | 上一站 / 下一站 |
| 点击站点标记 | 跳转至该站点 |
| 点击画布空白处 | 涟漪效果 |
| 速度滑块 | 调节旅途速度 |
| 主题按钮 | 切换氛围配色 |
