# Voice Botanical Print · 声音植物图谱

> 沉浸式声音植物标本采集器。你的嗓音是一粒种子——对着麦克风说话、低吟或哼唱，声音的音高、起伏、气量与脉动实时催生一株独一无二的植物版画，压制为腊叶标本，盖上学名铭牌，收入档案柜。

## 核心交互

- **采集发声**：按下录音，Web Audio 实时分析音高（自相关检测）与振幅——音量催生枝叶（能量驱动生长进度），音高雕琢株高与蜿蜒，起伏决定分枝密度，脉动孕育花果。
- **活体生长**：录制过程中植物随声能逐节抽枝，孢子自生长顶端迸出；定稿后以真实声纹确定性重生为最终形态。
- **学名铭牌**：由声纹特征哈希生成拉丁双名（如 *Vocanthe fortis*），种加词由主导特质决定（fortis 雄浑 / mollis 轻柔 / acutissima 高亢 / tremula 颤曳…），附口述转写（Web Speech API，可回退）与采集编号。
- **风与涟漪**：光标掠过标本触发非线性摇曳，点击迸发冲击波与孢子。
- **腊叶档案**：每株标本压制为羊皮纸缩略卡片，点击重览、可销毁。
- **合成样本**：无麦克风环境下一键合成随机声纹样本。

## 技术说明

- 免构建：Vanilla JS + CSS3 + HTML5，无任何依赖。
- 流体渐变背景（多层 blur blob + 混合模式）+ 微晶玻璃态容器（backdrop-filter）。
- 全局动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`，弹簧曲线用于卡片与按钮。
- 4 种氛围配色：铜绿 / 蓝晒 / 暮玫 / 夜阑。
- 音频全程本地分析，不上传任何数据。
- 字体：Outfit（展示）/ Inter（正文）/ Share Tech Mono（标本数据）。
