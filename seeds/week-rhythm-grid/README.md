# Week Rhythm Grid · 周律网格

沉浸式一周能量节律可视化网格。在 7 天 × 6 级能量标度上点击或拖拽涂抹，节律曲线即刻显形——Catmull-Rom 平滑曲线、粒子迸射、弹跳点亮与节律读数（均值 / 峰值 / 低谷 / 均衡度）。

## 特性

- **网格涂抹**：点击设置能量层级，拖拽连续涂抹，再点顶层即清空
- **节律曲线**：SVG Catmull-Rom 平滑曲线 + 渐变描边 + 呼吸节点，随涂抹实时形变
- **高阶微交互**：弹簧弹跳点亮、粒子迸射、幽灵预览、非线性缓动 `cubic-bezier(0.16, 1, 0.3, 1)`
- **节律预设**：早鸟型 / 夜猫型 / 均衡型 / 冲刺型 + 随机与清空
- **节律读数**：平均能量、峰值之日、低谷之日、节律均衡度进度条与智能短评
- **4 种氛围配色**：极光 / 余烬 / 深海 / 林间
- **本地持久化**：localStorage 保存网格与配色

## 技术

Vanilla JS + CSS3 + HTML5，零依赖免构建。流体渐变背景（超大模糊 + screen 混合）+ 微晶玻璃态容器（backdrop-filter + 发光描边）。
