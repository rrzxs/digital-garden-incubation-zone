# AR Art Placer · 空间策展

> 沉浸式空间策展 Web App。从展藏架拖出雕塑、装置、灯具，放置进透视画廊空间，展品会获得实时投影、悬浮弹簧物理与光源联动。流体渐变背景 + 微晶玻璃态容器 + 非线性动效。

## 核心交互

- **拖拽放置**：从左侧展藏架拖出 8 件预设展品（针碑 / 球体 / 尖塔 / 晶格 / 花朵 / 棱镜 / 立灯 / 图腾）到中央透视画廊。
- **重新排布**：拖动已放置的展品调整位置；拖出展厅即移除。
- **实时投影**：投影方向与长度跟随光源角度滑块联动，模拟真实光照。
- **悬浮物理**：每件展品以独立节奏悬浮微动，幅度可调。
- **网格吸附 / 自由放置**：双模式切换，吸附时坐标 5% 步进。
- **光源联动**：拖动 LIGHT 滑块，光源在展厅顶部平移，投影实时反向偏移。
- **随机布局 / 清空展厅**：一键填充或重置。
- **键盘**：选中后 `Delete` / `Backspace` 删除，`Esc` 取消选中。
- **配色**：4 种氛围配色（极光 / 余烬 / 深渊 / 兰若）切换。

## 审美与材质

- **流体网格渐变背景**：5 颗超大模糊光斑 + SVG 噪点颗粒，`mix-blend-mode: screen` 叠加。
- **微晶玻璃态容器**：`backdrop-filter: blur(26px)` + 半透明描边 + 内嵌高光。
- **透视画廊**：3D 透视房间（地面网格 / 三面墙 / 灭点呼吸），`perspective: 1200px`。
- **非线性动效**：统一 `cubic-bezier(0.16, 1, 0.3, 1)` 与弹簧 `cubic-bezier(0.34, 1.56, 0.64, 1)`。
