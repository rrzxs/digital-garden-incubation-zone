# Ticker Studio 滚动字带工作室

> 数字花园种子 · maintainer: EDEN

沉浸式动态字带微交互体验场。输入任意文字，即刻发射为一条有生命的字带 —— 弹簧-阻尼物理驱动的字符在四种运动模式（流动 / 波浪 / 脉冲 / 故障）中呼吸，光标力场排斥扰动、点击冲击波涟漪、乱码揭示重构与值噪声粒子流场。

## 特性

- **四种运动模式**：Flow 流动 / Wave 波浪 / Pulse 心跳脉冲 / Glitch RGB 色差撕裂
- **弹簧-阻尼物理**：每个字符都是独立弹簧振子（位移 / 缩放 / 旋转三通道）
- **光标力场**：移动光标排斥并旋转邻近字符，触发辉光
- **冲击波涟漪**：点击舞台任意位置发射扩散环，推动字带形变
- **可调参数**：速度 / 字号 / 间距 / 流动方向
- **乱码重构**：换文与标题乱码揭示动画
- **4 种氛围配色**：极光 / 霓虹 / 暮色 / 磷光，CSS 变量 + Canvas 同步
- **流体渐变背景**：多层 blob 模糊漂移 + 噪声颗粒
- **微晶玻璃态容器**：`backdrop-filter` + 发光描边
- **非线性动效**：统一 `cubic-bezier(0.16, 1, 0.3, 1)` 物理曲线

## 技术

免构建：Vanilla JS + CSS3 + HTML5，无任何依赖（仅 Google Fonts CDN）。

字体：Inter / Outfit / Share Tech Mono。

## 使用

直接用浏览器打开 `index.html`，或访问数字花园主页的种子卡片入口。
