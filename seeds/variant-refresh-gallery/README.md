# Variant Refresh Gallery · 变体刷新画廊

沉浸式变体刷新画廊。点击「刷新变体」（快捷键 `R`）生成全新一批画廊变体——每张卡片携带随机流体渐变色板、乱码揭示标题与语义标签，以 `cubic-bezier(0.16, 1, 0.3, 1)` 非线性曲线级联入场/退场，伴随全屏涟漪冲击波。「重组」（快捷键 `S`）以 FLIP 技术对现有卡片执行物理重排动画。

## 特性

- **流体渐变背景**：四团超大模糊 blob 以 `mix-blend-mode: screen` 缓慢漂移呼吸，叠加胶片颗粒噪点
- **微晶玻璃态容器**：`backdrop-filter: blur()` + 微小发光描边的全层面板与卡片
- **非线性动效**：统一的 `cubic-bezier(0.16, 1, 0.3, 1)` 物理曲线，入场含位移/缩放/旋转/模糊四维复合形变
- **高阶微交互**：3D 倾斜 + 光泽跟随（`--gx/--gy` 径向光斑）、色板流光扫过、乱码字符揭示、惯性光标辉光
- **FLIP 重组**：记录位置 → 洗牌 → 反演位移 → Web Animations 播放
- **4 种氛围配色**：极光 / 暮色 / 深渊 / 薄荷，一键切换全局色板
- **遥测面板**：等宽字体实时显示代际、变体数、色板与缓动曲线

## 技术栈

Vanilla JS + CSS3 + HTML5，零构建、零依赖。字体：Inter / Outfit / Share Tech Mono。
