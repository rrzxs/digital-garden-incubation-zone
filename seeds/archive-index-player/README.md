# Archive Index Player · 档案索引播放器

沉浸式档案索引播放体验。每一份卷宗都是一张唱片——在索引列表中检索，在播放舞台上让尘封的记录重新流转。

## 体验

- **索引面板**：12 份虚构档案条目，悬停滑移 + 乱码揭示标题，激活条目弹性缩进并自动滚动至视野
- **播放舞台**：卷轴装饰随播放旋转，标题字符级乱码揭示，波形示波器实时渲染播放包络
- **传输控制**：播放/暂停、上下卷、随机抽卷、AUTO 连续播放、SFX 索引音色
- **进度轨道**：可拖拽跳转（pointer capture），播放头竖线 + 缓冲层 + 时间读数
- **音景**：Web Audio 合成——每份档案对应一个正弦低鸣音色，操作伴随三角波 blip
- **高阶微交互**：点击涟漪冲击波、粒子流场背景（播放时流速加倍）、胶片颗粒、呼吸光晕

## 快捷键

| 键 | 功能 |
|---|---|
| `SPACE` | 播放 / 暂停 |
| `↑` `↓` / `W` `S` | 上 / 下一卷 |
| `←` `→` | 回退 / 快进 2s |
| `T` | 切换氛围配色 |
| `R` | 随机抽卷 |

## 技术

- Vanilla JS + CSS3 + HTML5，零构建、零依赖
- 流体渐变背景：`@keyframes` 漂移 + `filter: blur(90px)` + `mix-blend-mode: screen`
- 微晶玻璃态：`backdrop-filter: blur(22px)` + 发光描边
- 非线性动效统一使用 `cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Outfit（标题）/ Inter（正文）/ Share Tech Mono（档案代码）
- 4 种氛围配色：Noir / Amber / Jade / Rose
