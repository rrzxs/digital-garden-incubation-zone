# Color Story Scroller · 色彩叙事卷轴

沉浸式色彩叙事卷轴体验。7 幕色彩章节讲述可见光光谱的故事，每幕拥有独立的色彩主题。

## 特性

- **7 幕色彩叙事** — 从原点到归一，讲述赤红、金黄、翠绿、深蓝、幽紫的色彩故事
- **滚动驱动色彩蜕变** — 每个章节自动切换强调色、粒子颜色与光晕效果
- **光谱进度条** — 底部实时显示当前滚动位置对应的可见光光谱位置
- **色板交互** — 点击色板触发色彩闪烁反馈
- **色相环动画** — 金辉章节的旋转色相环与波长指示
- **翠生粒子花园** — 交互式 Canvas 粒子系统，鼠标排斥力场
- **深蓝深度可视化** — 渐进式深度条动画
- **幽紫光谱揭示** — 逐条展开的 HSL 色谱条
- **粒子流场** — 全局 Canvas 粒子系统，鼠标吸引交互
- **4 种氛围配色** — Obsidian / Dusk / Verdant / Scarlet
- **键盘导航** — 方向键切换章节

## 技术栈

- Vanilla JS + CSS3 + HTML5（零构建）
- 字体: Inter, Outfit, Share Tech Mono
- 动效曲线: `cubic-bezier(0.16, 1, 0.3, 1)`

## 使用

直接在浏览器中打开 `index.html` 即可体验。
