# Mission Timeline — 任务时间线

沉浸式任务时间线交互体验。滚动驱动的非线性节点编排、流体渐变背景 + 微晶玻璃态容器 + 弹簧物理动效，让任务规划化为流动叙事。

## 功能

- **3 套任务集**：产品发布 / 远征探索 / 研究计划，每套含 6 个递进里程碑
- **可拖拽时间轴**：拖拽滑块或点击节点/标签跳转里程碑，支持键盘方向键
- **进度环可视化**：SVG 圆环实时反映完成进度，渐变描边与发光呼吸
- **里程碑卡片**：微晶玻璃态卡片网格，点击聚焦、勾选完成，错峰入场动画
- **动态任务添加**：随时追加新的里程碑节点，时间线自动重新编排
- **4 种氛围配色**：极光 / 余烬 / 深海 / 翠林
- **粒子流场**：Simplex 噪声驱动背景粒子系统，鼠标力场交互与邻近连接线

## 交互

| 操作 | 效果 |
|------|------|
| 点击时间轴节点 / 标签 | 聚焦对应里程碑 |
| 拖拽时间轴滑块 | 连续切换里程碑 |
| 左右方向键 | 上一个 / 下一个里程碑 |
| 空格 / 回车键 | 切换当前里程碑完成状态 |
| 点击卡片勾选按钮 | 标记 / 撤回完成 |
| 鼠标移动 | 扰动背景粒子流场 |

## 技术

- Vanilla JS + CSS3 + HTML5
- Simplex Noise 2D 算法
- Canvas 2D 粒子流场系统
- SVG 渐变进度环 (stroke-dashoffset)
- CSS 变量驱动的主题切换
- cubic-bezier(0.16, 1, 0.3, 1) 非线性动效
- 无构建依赖，即开即用
