# Ripple Canvas — 涟漪画布

基于像素级水波物理模拟的交互式涟漪画布。

## 特性

- **像素级波纹传播** — 使用双缓冲区交替算法，模拟真实水波在二维平面的传播、反射与衰减
- **光线折射偏移** — 波纹梯度驱动像素偏移，产生真实的水面折射效果
- **双交互模式** — 物理模式（点击产生单波，拖拽留下波迹）与绘画模式（持续绘制涟漪）
- **粒子系统** — 120 个浮动粒子跟随波纹梯度运动，具有轨迹渲染与发光效果
- **4 种氛围配色** — 深渊 / 极光 / 余烬 / 星云
- **实时参数调节** — 波纹强度、阻尼系数、折射率滑块

## 技术实现

- Vanilla JS + Canvas 2D 像素操作（`ImageData` + `putImageData`）
- 波纹物理：邻域平均传播 + 指数阻尼
- 流体网格渐变背景 + 微晶玻璃态容器
- 非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 响应式布局，支持触屏

## 使用

直接在浏览器中打开 `index.html`，点击或拖拽画布产生涟漪。
