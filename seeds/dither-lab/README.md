# Dither Lab | 抖动实验室

实时交互式抖动艺术生成器，探索像素美学的无限可能。

## 功能特性

### 抖动算法
- **Floyd-Steinberg** - 经典误差扩散算法，效果自然
- **Ordered 4x4** - Bayer 矩阵有序抖动，复古风格
- **Atkinson** - Macintosh 原创算法，高对比度
- **Burkes** - 改进的误差扩散，细节丰富
- **Sierra** - Sierra Lite 算法，平衡效果
- **Stucki** - 高精度误差扩散，专业级输出

### 色彩模式
- 黑白 - 经典单色
- GameBoy - 复古游戏机绿调
- 复古棕 - 怀旧暖色调
- 赛博 - 霓虹赛博朋克风
- 日落 - 暖色渐变
- 深海 - 冷色调海洋风

### 参数调节
- 像素化强度
- 对比度
- 亮度

### 交互特性
- 拖放上传图片
- 实时预览对比（拖动滑块对比原图与效果）
- PNG 导出

## 技术实现

- 纯 Vanilla JS + CSS3 + HTML5
- 无构建依赖，开箱即用
- 流体渐变背景 + 微晶玻璃态 UI
- 非线性动效 `cubic-bezier(0.16, 1, 0.3, 1)`

## 使用方式

1. 打开 `index.html`
2. 拖放或点击上传图片
3. 选择算法和色彩模式
4. 调节参数实时预览
5. 导出 PNG 保存作品
