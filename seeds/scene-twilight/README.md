# Scene Twilight 暮光剧场

沉浸式暮光场景交互体验。多层视差景物（太阳、云层、远山、近山、树林、水面）、闪烁星空、萤火虫粒子、极光模拟与流星效果，配合时间滑块实时调节场景氛围。

## 交互方式

- **移动光标** — 视差扰动场景各层，光标产生光晕
- **点击任意位置** — 触发流星 + 涟漪扩散
- **时间滑块** — 从黎明到深夜的 15 段暮光时刻
- **星空 / 萤火 / 极光 / 涟漪** — 独立开关控制各效果层
- **4 种氛围配色** — 金色黄昏、深暮、北境极光、虚空暮色

## 技术栈

- Vanilla JS + CSS3 + HTML5（零构建）
- Google Fonts: Inter, Outfit, Share Tech Mono
- 动效曲线: `cubic-bezier(0.16, 1, 0.3, 1)`
