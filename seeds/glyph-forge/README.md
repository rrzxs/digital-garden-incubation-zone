# Glyph Forge 字符锻造炉

沉浸式字符锻造微交互体验。键入字符投入熔炉，每一次落锤都将滚烫的字形锻进铁砧——弹簧-阻尼物理、余烬粒子、淬火涟漪与光标热场。

## 玩法

- **锻造**：在输入框键入文字后回车或点击「锤锻」，字符依次坠入铁砧，落定时触发挥锤动画
- **锤型**：压印（弹跳落定）/ 迸裂（碎散后弹簧重组）/ 环绕（热字形环绕光标公转）
- **热场**：光标靠近的字形会被重新加热至炽亮，字形随热度冷却逐渐褪色
- **淬火**：点击铁砧任意位置产生淬火涟漪，迅速冷却附近字形并蒸腾白汽；「淬火」按钮全炉冷却
- **热度滑块**：调节熔炉温度（HUD 实时显示）
- **4 种氛围配色**：余烬 / 寒钢 / 翠焰 / 紫熔

## 技术

- 免构建：Vanilla JS + CSS3 + HTML5，单 rAF 循环
- 流体渐变背景（多层模糊 blob + `mix-blend-mode: screen`）
- 微晶玻璃态容器（`backdrop-filter: blur` + 发光描边）
- 非线性动效统一使用 `cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Inter / Outfit / Share Tech Mono
