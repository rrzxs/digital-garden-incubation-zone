# Magnetic - 磁力光标交互

一个展示磁力光标交互效果的 Web 应用，光标移动时周围的 UI 元素会被磁力吸引或排斥，产生流动的视觉效果。

## 功能特性

- **三种磁力类型**：
  - ⊕ 吸引：元素被光标吸引，跟随移动
  - ⊖ 排斥：元素被光标推开，远离移动
  - ↻ 环绕：元素围绕光标旋转，同时受吸引影响

- **可调参数**：
  - 磁场强度：控制磁力的整体强度
  - 影响半径：控制光标的影响范围
  - 阻尼系数：控制元素回归原位的速度

- **视觉效果**：
  - 流体渐变背景动画
  - 微晶玻璃态卡片容器
  - 自定义光标与拖尾效果
  - 平滑的非线性动效

## 技术实现

- Vanilla JS + CSS3 + HTML5
- 无需构建工具，即开即用
- 使用 `requestAnimationFrame` 实现流畅动画
- 响应式设计，支持移动端

## 使用方式

1. 直接在浏览器中打开 `index.html`
2. 移动鼠标感受磁力交互效果
3. 使用底部控制面板调整参数
