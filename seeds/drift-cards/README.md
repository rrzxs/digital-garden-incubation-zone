# Drift Cards · 漂流卡片

数字海洋上的漂流瓶式讯息卡片。每张微晶玻璃态卡片承载一句留言，随多重正弦噪声流场在洋流中缓缓漂移，像小船一样随速度侧倾、随波呼吸。

## 交互

- **拖拽抛掷** — 抓住卡片甩出，惯性 + 阻尼滑行
- **点击空处** — 涟漪冲击波推开周围卡片，并令翻面卡片复位
- **双击卡片** — 3D 翻转揭示背面「回声」回信
- **光标力场** — 漂流模式下排斥卡片，磁吸模式下温柔牵引
- **三种流场模式** — 漂流（平静洋流）/ 磁吸（光标引力）/ 风暴（湍流 chaos）
- **投递新卡** — 从词库生成新的漂流瓶，超出上限自动沉底最旧的一张
- **4 种氛围配色** — 深渊 / 极光 / 暮色 / 烬火

## 技术说明

- Vanilla JS + CSS3 + HTML5，免构建
- 物理引擎：噪声流场推进 + 阻尼限速 + 软边界橡皮筋回弹
- 流体渐变背景：超大模糊 blob + `mix-blend-mode: screen`
- 微晶玻璃态容器：`backdrop-filter` + 发光描边 + 光泽跟随
- 全局非线性动效曲线：`cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Outfit（展示）/ Inter（正文）/ Share Tech Mono（遥测）
