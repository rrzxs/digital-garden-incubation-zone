# Flow Canvas — 流体画布

沉浸式流体画布交互体验。Simplex 噪声流场驱动的粒子绘画系统。

## 功能特性

- **4 种流场模式**: 旋度场 / 湍流场 / 漩涡场 / 脊线场
- **5 种画笔风格**: 丝带 / 星尘 / 霓虹 / 水墨 / 余烬
- **3 种力场交互**: 吸引 / 排斥 / 漩涡
- **4 种氛围配色**: 极光 / 焰火 / 深海 / 霓虹
- **点击脉冲**: 点击画布创建力场脉冲冲击波
- **参数调节**: 粒子密度、流场强度、流场演化速度、笔触衰减、力场半径

## 技术实现

- Simplex Noise 3D 驱动的流场计算
- 双 Canvas 分层：粒子追踪层 + 绘画轨迹层
- `destination-out` 渐隐实现拖尾效果
- CSS 变量驱动的主题切换系统
- 触摸设备兼容

## 使用方式

直接在浏览器中打开 `index.html`，无需构建。
