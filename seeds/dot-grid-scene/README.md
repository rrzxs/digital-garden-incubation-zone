# Dot Grid Scene — 点阵场景

沉浸式弹簧物理驱动的点阵力场微交互体验场。

## 概述

每个格点是一个具有弹簧-阻尼归位的质点，受光标力场与冲击波涟漪驱动产生非线性位移。配合粒子流场、十字准星与微晶玻璃态容器，营造深空科技感氛围。

## 核心交互

- **排斥**：光标推开周围格点
- **吸引**：光标拉近周围格点
- **漩涡**：格点沿切线方向旋转环绕
- **波场**：格点按距离与时间形成同心波纹

点击画布任意位置释放冲击波涟漪，环形冲击带驱动力场级联扰动。

## 可调参数

| 参数 | 说明 |
|------|------|
| 网格密度 | 格点间距，影响节点总数 |
| 力场半径 | 光标影响范围 |
| 场强 | 力场位移强度 |
| 弹性 | 阻尼系数，控制回弹速度 |

## 配色

极光 / 余烬 / 苔藓 / 暮色 四种氛围配色。

## 技术

- Vanilla JS + CSS3 + HTML5（免构建）
- Canvas 2D + 弹簧-阻尼物理积分
- 流体网格渐变背景（`filter: blur` + `mix-blend-mode: screen`）
- 微晶玻璃态容器（`backdrop-filter: blur`）
- 非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
