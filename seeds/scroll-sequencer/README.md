# Scroll Sequencer · 滚动音序器

沉浸式滚动音序器体验。滚动化身播放头穿越 16 步序列，五轨微晶玻璃态垫合成节拍：

1. **序曲 Overture** — 视差深度层 + 漂浮音符/光环背景 + 音频启用引导
2. **序列器 Sequencer** — 16 步 × 5 轨可点击音序器网格 + 滚动驱动播放头 + 实时统计
3. **波形 Waveform** — 触发音符涌出涟漪波形 + 滚动速度驱动振幅
4. **速度 Tempo** — 三环呼吸可视化器 + BPM 随滚动速度映射 (60~180)
5. **轨道 Tracks** — 五种音色图例 + 3D 倾斜展示卡
6. **终章 Finale** — 收束与回归

## 交互

- **滚动**：播放头在 16 步间移动，越过激活的步进即触发该轨道音符
- **点击单元格**：激活或静音该步进——你是这张谱的编曲者
- **鼠标移动**：卡片 3D 倾斜 + 视差层位移 + 光晕追踪 + 粒子吸引
- **键盘 ↑↓**：在章节间跳跃
- **右上角 HUD**：实时显示步进 (01/16)、Tempo 速度、BPM、累计触发数
- **左上角音频开关**：点击启用 Web Audio 合成引擎
- **左侧进度轨**：点击圆点跳转章节
- **右下角配色**：4 种氛围配色 (Aurora / Ember / Ocean / Void)

## 音色合成

- **Kick 底鼓** — 正弦波 120→30Hz 指数衰减，0.3s 包络
- **Snare 军鼓** — 高通白噪爆破 + 三角波 200Hz 调音
- **Hat 踩镲** — 7kHz 高通短噪点，0.05s 极短包络
- **Bass 贝斯** — 锯齿波 82Hz + 低通滤波扫频，酸性律动
- **Lead 主音** — 三角+正弦双振荡五声音阶旋律线

## 技术栈

- Vanilla JS + CSS3 + HTML5（免构建）
- Web Audio API 实时合成（无采样文件）
- Canvas 2D 粒子流场 + 波形涟漪渲染
- IntersectionObserver 驱动的逐字/逐行揭示
- CSS 变量主题系统
- `cubic-bezier(0.16, 1, 0.3, 1)` 非线性动效曲线
- Inter / Outfit / Share Tech Mono 字体
