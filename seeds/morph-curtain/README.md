# Morph Curtain 变形幕

沉浸式窗帘变形体验。基于弹簧-阻尼物理模型的布料模拟，三种变形模式与四种氛围配色。

## 交互方式

- **鼠标悬停** — 光标附近的布料点产生推力/吸力
- **鼠标拖拽** — 直接拖拽布料产生更大形变
- **触摸** — 移动端完整支持

## 变形模式

| 模式 | 描述 |
|------|------|
| 推开 | 顶部固定的帷幕，鼠标推力推开布料 |
| 裂开 | 两侧固定，鼠标从中撕开裂口 |
| 溶解 | 布料在交互后逐渐溶解消散 |

## 参数控制

- **刚度** — 约束迭代次数，影响布料回复力
- **阻尼** — 速度衰减系数，影响摆动持续时间
- **鼠标力** — 光标对布料点的作用力强度

## 配色

- 深海 (Deep Ocean) — 靛蓝色系
- 极光 (Aurora) — 青绿色系
- 余烬 (Ember) — 橙红色系
- 虚空 (Void) — 淡紫色系

## 技术

- Vanilla JS + Canvas 2D
- Verlet 积分法布料物理模拟
- 弹簧-阻尼约束求解器
- 流体粒子背景 + 微晶玻璃态容器
- 非线性缓动曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
