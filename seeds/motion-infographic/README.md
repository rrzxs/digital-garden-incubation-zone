# Motion Infographic 动效信息图

> 沉浸式数据脉动信息图。数据指标卡以非线性动效弹入视野，环形贡献星图、脉冲柱阵、事件时间线在流体粒子流场中呼吸跳动。

## ✨ 特性

- **流体粒子流场**：Simplex 风格噪声场驱动上百颗粒子在背景持续流动，光标排斥、点击涟漪冲击
- **流体网格渐变背景**：四颗超大模糊光团 + `mix-blend-mode: screen` 构建呼吸感氛围
- **微晶玻璃态容器**：所有卡片采用 `backdrop-filter: blur(28px) saturate(1.6)` 与发光描边
- **非线性动效**：全部交互采用 `cubic-bezier(0.16, 1, 0.3, 1)` 物理曲线
- **数字递增动画**：指标卡进入视口时从 0 弹性递增至目标值
- **环形贡献星图**：SVG 描边动画 + 环绕节点轨道运动 + 中心数值同步
- **脉冲柱阵**：错峰高度递增 + 悬浮高亮顶点
- **事件时间线**：横向脉动节点，悬浮放大发光
- **3D 倾斜卡片**：玻璃容器跟随光标做透视倾斜
- **磁吸光标光晕**：缓动追随光标的辉光层
- **双交互模式**：悬浮（磁吸偏移）/ 轨道（3D 旋转）
- **4 种氛围配色**：深海 / 极光 / 余烬 / 虚空

## 🎮 操作

| 操作 | 说明 |
|------|------|
| 移动光标 | 排斥粒子、磁吸光晕、卡片 3D 倾斜 |
| 点击空白 | 产生涟漪冲击波 |
| 悬浮指标卡 | 触发数字递增 + 上浮高亮 |
| 切换模式 | 悬浮 / 轨道 两种卡片交互物理 |
| 切换配色 | 深海 / 极光 / 余烬 / 虚空 |

## 🧩 技术栈

- Vanilla JS（IIFE 模块封装，零依赖）
- CSS3 自定义属性 + Glassmorphism + Mesh Gradient
- HTML5 Canvas 2D 粒子流场
- SVG 环形进度 + 描边动画
- Google Fonts: `Inter` / `Outfit` / `Share Tech Mono`
