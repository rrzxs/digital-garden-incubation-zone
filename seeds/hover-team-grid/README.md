# Hover Team Grid · 星阵团队网格

> 沉浸式团队网格悬浮微交互。光标进入单元即刻引爆聚焦揭示，邻近单元退入深空，3D 倾斜物理 + 技能光环 + 排版引语，流体渐变背景 + 微晶玻璃态容器，4 种氛围配色。

## 体验

- **聚焦膨胀** — 悬停某单元时，它以 `flex-grow` 非线性膨胀占据主导宽度，其余单元同时收缩、降亮度、降饱和度，退入深空。一进一退之间是星阵的呼吸。
- **竖向折叠态** — 默认状态下每个单元是一条窄竖条，仅显示编号、巨型字母与竖排姓名，营造画廊式阵列。
- **错峰揭示** — 聚焦后徽章、姓名、角色、生平、技能光环、引语、社交以递增的 `transition-delay` 依次浮现，层次分明。
- **技能光环** — 每位成员三项核心技能，以延迟触发的进度条形展示，数值 0–100。
- **签名引语** — 每张卡片配一句成员的个人哲学，斜体引号样式 + 主题色发光左边框。
- **3D 倾斜物理** — 光标在卡片内移动，玻璃表面以 `perspective(1200px)` 实时倾斜（最大 7 度），跟随鼠标的高光光泽层。
- **HUD 实时反馈** — 顶部 HUD 显示当前聚焦成员姓名 + 闪烁指示点，脚注实时显示聚焦成员。
- **光标跟随光晕** — 全局光晕跟随光标，平滑插值移动。
- **4 种氛围配色** — Aurora 极光 / Ember 余烬 / Abyss 深渊 / Orchid 兰若。

## 审美与交互

- 流体网格渐变背景（5 颗高斯模糊 blob + screen 混合 + SVG 噪点颗粒层）
- 微晶玻璃态容器（`backdrop-filter: blur` + 发光描边）
- 全局非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 粒子流场 + 鼠标引力 + 近邻连线
- 点击涟漪、单元错峰入场、键盘可聚焦揭示
- 移动端自动退化为卡片堆叠布局

## 团队成员

8 位虚构成员，涵盖创意总监 / 主程 / 动效设计师 / 系统架构师 / 研究负责人 / 声学工程师 / 产品策略师 / 交互工程师，每人配有差异化技能光环与签名引语。

## 技术栈

Vanilla JS + CSS3 + HTML5，零构建、零依赖。字体：Inter / Outfit / Share Tech Mono。

## 文件结构

```
hover-team-grid/
├── index.html   # 结构：序言 + 团队网格 + 脚注
├── style.css    # 流体背景 + 玻璃态 + flex-grow 聚焦 + 4 主题
├── main.js      # 单元构建 + 聚焦逻辑 + 3D 倾斜 + 粒子流场 + 配色
```

## 使用

直接用浏览器打开 `index.html`。悬停任意单元即可聚焦揭示详情，移动光标体验 3D 倾斜物理。键盘 Tab 聚焦、触摸点击也可触发。点击右上角色板切换氛围。
