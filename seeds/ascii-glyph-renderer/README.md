# ASCII Glyph Renderer · 字符渲染台

沉浸式 ASCII 字形渲染器。输入任意字符或短词，字形被拆解为 ASCII 字符矩阵——每个字符都继承原始字形的明度，并可被光标扰动、冲击波脉冲重塑。

## 特性

- **字形采样引擎**：离屏画布绘制 + 逐像素亮度采样，任意字形（汉字 / 符号 / 短词）实时转译为 ASCII 矩阵
- **三种交互模式**：白热（光标加热字符辉光）、乱码（局部字符沸腾解构）、位移（弹簧-阻尼物理推开字符）
- **冲击波脉冲**：点击画布 / 空格键 / 面板按钮触发扩散涟漪环，字符被点亮与推挤后非线性回弹
- **可调参数**：采样精度（48~160）、对比度、明度反转、自动脉冲
- **4 种字符梯度**：Standard / Blocks / Binary / Runes
- **4 种氛围配色**：星云 / 余烬 / 翠林 / 兰曦
- **导出**：一键复制完整 ASCII 矩阵文本
- **微交互细节**：标题乱码揭示、中心扫开式入场动画、FPS 遥测 HUD

## 技术栈

Vanilla JS + Canvas 2D + CSS3，零构建、零依赖。流体渐变背景 + 微晶玻璃态控制面板，全局动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`。

## 使用

直接用浏览器打开 `index.html`，或通过数字花园主页种子卡片进入。

- 移动光标：局部扰动矩阵
- 点击画布：触发冲击波脉冲
- 空格键：中心脉冲
- 面板输入：更换渲染字形
