# Sound Index 声音索引

沉浸式声音索引乐器。索引本身即乐谱：8 枚微晶玻璃态词条，每一枚都是一件 Web Audio 合成乐器（拨奏/铃音/持续音/声呐/低频/编钟/故障/泛音）。

## 交互

- **悬停** 词条 → 弱音预览（带防抖）
- **点击** 词条 → 全力度演奏 + 涟漪冲击波
- **键盘 [1-8]** → 直接击打对应词条
- **Space** → 全场级联脉冲
- **底部色盘** → 4 种氛围配色（极光 / 深渊 / 余烬 / 薄荷）

## 技术

- 免构建：Vanilla JS + CSS3 + HTML5，无任何依赖
- Web Audio 多分音合成 + 指数衰减包络 + AnalyserNode 实时频谱
- 流体网格渐变背景（blur + mix-blend-mode: screen）+ 微晶玻璃态容器
- 全局动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`，卡片 3D 光标倾斜、错峰入场、播放光晕脉冲
