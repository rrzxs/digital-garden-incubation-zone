# Mascot Stage 吉祥物舞台

沉浸式吉祥物角色互动体验场。流体渐变背景 + 微晶玻璃态容器 + 非线性动效，与可爱的吉祥物实时互动。

## 交互方式

- **鼠标移动** — 吉祥物眼睛实时追踪光标，头部微微倾斜
- **单击舞台** — 触发火花粒子效果
- **双击舞台** — 触发抚摸动画，爱心飘浮
- **拖拽（上）** — 吉祥物跳跃
- **拖拽（下）** — 吉祥物挤压
- **触摸** — 移动端完整支持

## 表情系统

| 表情 | 描述 |
|------|------|
| 开心 | 微笑 + 腮红浮现 |
| 兴奋 | 大嘴 + 耳朵竖起 + 跳跃 |
| 困倦 | 眼皮半闭 + 小嘴 |
| 惊讶 | 大眼 + 圆嘴 + 震动 |
| 爱心 | 瞳孔变心形 + 粉色腮红 + 飘浮爱心 |
| 好奇 | 歪嘴 + 微笑 |

## 动作按钮

- **戳一戳** — 挤压弹性动画 + 火花迸射 + 随机表情切换
- **喂食** — 弹跳动画 + 好感度 +5 + 爱心飘浮
- **抚摸** — 爱心表情 + 好感度 +8 + 大量爱心与火花

## 配色

- 星尘 (Cosmos) — 靛蓝色系
- 极光 (Aurora) — 青绿色系
- 余烬 (Ember) — 橙红色系
- 虚空 (Void) — 淡紫色系

## 技术

- Vanilla JS + Canvas 2D
- CSS3 弹簧-阻尼非线性动画
- 实时眼球追踪 + 面部表情系统
- 粒子流场背景 + 光标力场交互
- 好感度系统 + 自动眨眼 + 呼吸空闲动画
- 非线性缓动曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
