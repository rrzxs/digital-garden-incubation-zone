# Typo Morph — 字形流变实验室

沉浸式字形流变交互体验。输入文字，观察字符在五种变形场中实时流变，配合粒子流场与微晶玻璃态容器。

## 变形模式

- **Elastic 弹性** — 弹簧阻尼振荡，字符如橡皮筋般拉伸回弹
- **Crystal 晶格** — 晶体结构运动，字符沿 90° 轴向刚性位移
- **Vortex 漩涡** — 中心辐射涡旋，字符绕中心点旋转偏移
- **Pulse 脉动** — 心跳级联脉冲，字符依次膨胀收缩
- **Shatter 碎裂** — 碎片化散布，字符随机碎裂飞散

## 交互

- 鼠标力场：排斥 / 吸引 / 环绕三种光标力场模式
- 爆炸脉冲：一键触发冲击波级联（Space 键）
- 随机变形：随机切换模式与参数（S 键）
- 重置：恢复默认状态（R 键）
- 数字键 1-5：快速切换变形模式

## 氛围配色

- Nebula 星云（紫粉）

Vanilla JS + CSS3 + HTML5，零构建依赖。
