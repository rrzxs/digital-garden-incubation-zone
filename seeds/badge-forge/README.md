# Badge Forge 徽章熔铸台

沉浸式 SVG 徽章熔铸工作台。调配形制、纹理与铭文，实时预览，一键熔铸入库。

## 玩法

- **LABEL / SUB**：输入主铭文与副铭文，徽章实时重铸
- **SHAPE**：盾形 / 六边 / 圆徽 / 菱切 / 星辉 五种形制
- **STYLE**：微晶 / 熔渐 / 描金 / 全息 四种质感
- **SIGIL**：六枚纹章符号
- **PALETTE**：余烬 / 寒钢 / 翠焰 / 紫熔 四种氛围配色，联动全局流体背景与粒子
- **熔铸**：点击按钮或徽章舞台 — 弹簧落章动画 + 冲击波 + 粒子迸射，徽章入库档案
- **档案**：点击历史卡片可恢复其完整配置
- **导出**：复制 SVG 源码 / 下载 .svg 文件

## 技术

- Vanilla JS + CSS3 + HTML5，免构建、零依赖
- SVG 程序化徽章生成（`<text>` + `<linearGradient>` + `<filter>`）
- Canvas 双层粒子（环境流场 + 熔铸迸射）
- 3D 倾斜 + 光泽追踪（`perspective` + 弹簧阻尼插值）
- 全站动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Inter / Outfit / Share Tech Mono
