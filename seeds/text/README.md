# 文字解密 | Text Scramble

文字从乱码逐渐解密成目标文字的动画效果，支持多种微交互模式。

## 功能特性

- 🔐 **解密动画** - 文字从随机字符逐渐解密成目标文字
- 🎨 **流体渐变背景** - 动态渐变光球营造氛围感
- 💎 **微晶玻璃态容器** - 毛玻璃效果的信息面板
- ⚡ **非线性动效** - 使用 `cubic-bezier(0.16, 1, 0.3, 1)` 缓动曲线
- 🎮 **多模式支持** - 单次解密、循环播放、级联效果
- 🔧 **可配置** - 支持调整解密速度和字符集
- 🖱️ **光标跟随** - 微妙的鼠标光晕效果
- 📱 **响应式设计** - 适配桌面和移动端

## 技术栈

- Vanilla JavaScript (无框架)
- CSS3 动画与 Glassmorphism
- Google Fonts: Inter, Outfit, Share Tech Mono

## 使用方式

1. 打开 `index.html`
2. 在输入框中输入目标文字
3. 选择解密速度和字符集
4. 点击「开始解密」观看动画
5. 或点击预设文字快速体验

## 模式说明

- **单次解密** - 执行一次解密动画后停止
- **循环播放** - 自动随机选择预设文字循环播放
- **级联效果** - 按顺序播放预设文字列表
