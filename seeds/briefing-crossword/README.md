# Briefing Crossword - 填字游戏

氛围感填字游戏，具有流体渐变背景、微晶玻璃态容器与高阶微交互。

## 功能特性

- **填字游戏核心**：支持横向(ACROSS)和纵向(DOWN)两种方向
- **多谜题系统**：内置多个谜题，支持切换新谜题
- **智能高亮**：选中格子时自动高亮整个单词
- **提示功能**：点击 HINT 获取当前单词的下一个字母
- **检查功能**：点击 CHECK 验证所有已填字母
- **完成动画**：完成全部填字后展示庆祝动画

## 交互说明

1. **选择格子**：点击任意非空白格子
2. **输入字母**：使用键盘输入 A-Z
3. **删除字母**：按 Backspace 删除
4. **切换方向**：再次点击同一格子切换横/纵方向
5. **移动光标**：使用方向键移动
6. **跳转单词**：按 Tab 跳转到下一个单词

## 视觉风格

- 流体渐变背景（Mesh Gradient）
- 微晶玻璃态容器（Glassmorphism）
- 非线性动效曲线：`cubic-bezier(0.16, 1, 0.3, 1)`
- 配色：青绿主色调 + 蓝色辅色调

## 技术栈

- Vanilla JS + CSS3 + HTML5
- 免构建，无依赖
- 字体：Inter, Outfit, Share Tech Mono
