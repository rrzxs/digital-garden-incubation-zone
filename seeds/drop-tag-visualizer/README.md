# Drop Tag Visualizer · 标签液滴可视化器

沉浸式标签液滴可视化器。输入标签，它即刻凝为一颗微晶玻璃液滴坠入思想的液面——飞溅粒子、涟漪冲击波与表面波在撞击中苏醒，随后在液池中漂浮、聚类、呼吸。

## 核心交互

1. **液滴坠落 (Drop)** — 输入标签回车（或点击"滴落"），液滴自控制台坠落，重力加速度 + 挤压拉伸（squash & stretch）形变
2. **撞液飞溅 (Splash)** — 触液瞬间按动能决定飞溅规模：粒子迸射 × 双层涟漪环 × 表面波沿液面向两侧传播衰减
3. **3 种漂浮模式 (Modes)** — 流场 Flow（噪声流场漂移 + 深度浮力）/ 聚类 Cluster（同类标签向色心归拢并缓慢自转）/ 晶格 Grid（弹簧吸附网格槽位）
4. **拖拽抛掷 (Drag & Throw)** — 抓起任意标签甩出，带惯性速度；抛出液面会再次坠落并二次飞溅
5. **光标斥力场 (Cursor Force)** — 光标靠近时液滴被推开，挤压形变
6. **点击冲击波 (Shockwave)** — 点击空白处激发冲击波，推开全场液滴并掀起表面波
7. **双击迸裂重生 (Burst & Rebirth)** — 双击标签迸裂为粒子，0.6s 后从天顶重新滴落
8. **标签雨 (Rain)** — 一阵随机标签雨连缀坠落；「蒸发」按钮让全场标签依次汽化离场

## 交互方式

- **输入框 + Enter**：滴落自定义标签（自动按关键词猜分类着色）
- **数字键 1 / 2 / 3**：切换流场 / 聚类 / 晶格
- **拖拽**：抓起液滴抛掷，边界弹性碰撞
- **点击空白**：冲击波涟漪
- **双击标签**：迸裂重生
- **右上角配色**：4 种氛围配色 (Aurora / Ember / Ocean / Void)

## 审美系统

- **流体渐变背景**：4 颗超大模糊光球 `mix-blend-mode: screen` 呼吸漂移 + 胶片噪点层
- **微晶玻璃态容器**：控制台 / 模式坞 / HUD 均为 `backdrop-filter: blur()` + 发光描边
- **液滴标签**：玻璃药丸 + 分类色呼吸光点，同类邻近时浮现连接线
- **非线性动效**：统一 `cubic-bezier(0.16, 1, 0.3, 1)` 物理曲线
- **字体**：Outfit (标题) / Inter (正文) / Share Tech Mono (遥测)

## 技术栈

- Vanilla JS + CSS3 + HTML5（零构建）
- Canvas 2D：液面波动方程 / 涟漪环 / 飞溅粒子 / 环境流场粒子 / 同类连接线
- DOM 玻璃液滴 + rAF 弹簧物理（分离 / 斥力 / 浮力 / 边界弹性）
- CSS 变量主题系统（4 氛围配色实时切换，Canvas 同步取色）
