# Pixel Reveal — 像素揭示

沉浸式像素揭示微交互体验。一层马赛克像素瓦片覆盖着程序化生成的信号源画作，瓦片以弹簧-阻尼物理溶解与复原，展现隐藏其下的世界。

## 交互模式

| 模式 | 说明 |
|------|------|
| 聚光灯 Spotlight | 移动光标，半径内像素以软性衰减溶解，离开后错峰复原 |
| 涟漪 Ripple | 点击画布激发冲击波，波前经过处像素级联消隐 |
| 扫描 Sweep | 垂直光束自动往返扫描，持续揭示与再生 |
| 降雨 Rain | 像素如雨点般随机消隐、随机重生，马赛克持续呼吸 |

## 特性

- 4 种信号源：花园 / 星云 / 字符 / 波场（程序化实时生成）
- 4 种氛围配色：深海 / 极光 / 余烬 / 星云（主题切换即刻重绘画作）
- 可调像素尺寸（10–44px）与揭示半径
- 弹簧-阻尼物理瓦片动画 + 错峰复原节奏
- 实时遥测 HUD：揭示百分比 / 瓦片数 / FPS
- 键盘快捷键：`1-4` 切换模式，`R` 复原
- 流体渐变背景 + 微晶玻璃态容器 + 非线性动效

## 技术

免构建：Vanilla JS + Canvas 2D + CSS3，无任何依赖。
