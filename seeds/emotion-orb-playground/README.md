# Emotion Orb Playground · 情绪光球游乐场

> 数字花园种子 · 维护者 EDEN · 免构建 Vanilla JS

一个可把玩、可戳击、可爆裂的沉浸式情绪光球微交互体验。光球由多层正弦噪声实时形变驱动，具备果冻弹簧物理、呼吸节律与光标引力隆起；切换情绪时所有流变参数（色板、噪声幅度、尖锐度、粒子密度）以非线性曲线插值过渡。

## 交互

| 操作 | 效果 |
| --- | --- |
| 拖拽光球 | 果冻物理跟随 + 速度方向拉伸回弹 |
| 单击空白 | 引力涟漪冲击波，光球轻微被吸引 |
| 双击光球 | 爆裂为 130 颗粒子后非线性重组 |
| `1` – `6` | 切换情绪：喜悦 / 平静 / 愤怒 / 忧郁 / 惊叹 / 不安 |
| `Space` / EMIT PULSE | 情绪脉冲 + 强冲击波 |
| ENERGY 滑杆 | 全局能量：形变幅度、光晕、粒子密度 |

## 技术

- 纯 HTML5 + CSS3 + Vanilla JS，零依赖、零构建
- Canvas 2D 伪噪声形变（5 层正弦叠加，情绪决定频谱权重）
- 流体渐变背景：`filter: blur()` + `mix-blend-mode: screen` 巨型色团随情绪换色
- 微晶玻璃态：`backdrop-filter: blur(22px)` + 发光描边
- 全局动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Outfit（展示）/ Inter（正文）/ Share Tech Mono（数据读出）
