# Gravity Drop Trail 引力坠迹

沉浸式重力粒子轨迹体验场。

## 交互方式

- **点击画布**：在点击位置创建引力源，同时释放一簇粒子
- **拖拽引力源**：拖动紫色圆点调整引力场位置
- **悬停删除**：鼠标悬停到引力源上出现红色删除按钮
- **模式切换**：4种发射模式（坠滴 / 喷泉 / 轨道 / 漩涡）
- **参数调节**：引力强度、尾迹长度、弹性系数
- **配色切换**：宇宙 / 深海 / 余烬 / 极光

## 物理模型

- 重力加速度作用于所有粒子
- 引力源产生平方反比引力场
- 底部碰撞反弹带能量损失
- 速度限制与空气阻力

## 技术栈

- Vanilla JS + Canvas 2D
- CSS3 流体渐变背景 + 微晶玻璃态容器
- 非线性动效曲线 cubic-bezier(0.16, 1, 0.3, 1)
