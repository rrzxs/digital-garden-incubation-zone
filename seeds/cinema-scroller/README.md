# Cinema Scroller | 影院卷轴

沉浸式影院卷轴滚动体验。将浏览器窗口化作一卷活生生的电影胶片，6 幕场景章节依次展开，配合粒子流场、胶片齿孔、倒计时动画、逐字揭示与非线性动效。

## 交互亮点

- **胶片齿孔边栏** — 左侧固定胶片孔洞随滚动位移
- **影片倒计时** — 点击 scroll cue 触发经典 3-2-1 倒计时环
- **逐字揭示** — 文字从空白中逐字符浮现
- **滚动谷物感** — 快速滚动时叠加电影颗粒噪点
- **光标追踪光晕** — 鼠标位置发出柔和紫色辉光
- **粒子流场** — Canvas 粒子受鼠标吸引并自动连线
- **场景导航** — 右侧圆点指示器可点击跳转
- **影片进度条** — 右侧实时滚动进度可视化

## 技术栈

- Vanilla JS + CSS3 + HTML5（零构建）
- Google Fonts: Inter, Outfit, Share Tech Mono
- 动效曲线: `cubic-bezier(0.16, 1, 0.3, 1)`
- IntersectionObserver 驱动场景揭示
- Canvas 粒子系统
