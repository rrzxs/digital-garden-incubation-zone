# Swatch Drift · 色卡漂移

沉浸式色卡漂移微交互体验。微晶玻璃态色卡随噪声洋流场缓缓漂移呼吸——拖拽抛掷、光标斥力场、点击涟漪冲击波与双击聚焦取色，选中色卡实时驱动全局主题与流体渐变背景。

## 交互

| 手势 / 控件 | 行为 |
| --- | --- |
| 拖拽色卡 | 弹性跟手，松手抛掷（速度继承） |
| 双击色卡 | 聚焦取色 → 主题色即时流变 + 可复制 HEX |
| 点击空白 | 涟漪冲击波推开附近色卡 |
| 光标扫过 | 斥力场扰动，快移推力更强 |
| 漂移模式 | 风平（缓洋流）/ 湍流（剧烈湍流）/ 环汐（绕心公转） |
| 色卡集 | 暮霞 / 深海 / 密林 / 熔金 四组 |
| 洋流强度 | 0.2× ~ 2.5× 连续调节 |
| 洗牌 / 脉冲 | 重新布阵 / 全场冲击波爆发 |

## 技术说明

- 免构建：Vanilla JS + CSS3 + HTML5，无任何依赖
- 物理：速度阻尼积分 + 弹性边界回弹 + 分层正弦噪声洋流场
- 材质：`backdrop-filter` 微晶玻璃 + 超大模糊流体渐变 + 细噪点
- 动效统一曲线：`cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Inter / Outfit / Share Tech Mono
