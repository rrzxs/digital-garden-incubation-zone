# Motion Reel 韵动卷轴

沉浸式动效展示卷轴 — 一个集合 8 种高阶微交互动效的展示画廊。

## 核心体验

每个场景卡片都包含一个可交互的动效演示：

1. **弹簧阻尼** — 弹簧-阻尼物理模型，可拖拽的弹性方块
2. **涟漪扩散** — 点击产生多层同心波纹
3. **形态流变** — 噪声驱动的有机形状变形
4. **粒子流场** — 鼠标驱动的粒子引力系统
5. **故障美学** — RGB 分离与文字乱码
6. **弹性波纹** — 延迟级联的弹性波传播
7. **轨道共振** — 多层椭圆轨道的粒子系统
8. **遮罩揭示** — 跟随鼠标的圆形遮罩揭密

## 技术实现

- 纯 Vanilla JS + CSS3 + HTML5，零依赖
- Canvas 2D 渲染粒子系统与物理模拟
- 弹簧-阻尼物理模型驱动弹性交互
- 噪声函数驱动有机形变
- `cubic-bezier(0.16, 1, 0.3, 1)` 非线性缓动
- 支持键盘、鼠标拖拽、滚轮、触屏滑动

## 配色方案

4 种氛围配色：深海 / 极光 / 余烬 / 虚空
