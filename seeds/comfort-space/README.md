# Comfort Space - 你的舒适空间

沉浸式情绪安抚微交互 Web App。

## 功能

- **情绪选择** - 6 种情绪气泡，选中后动态切换主题色与安抚文案
- **呼吸练习** - 3 种呼吸模式（4-7-8 / 箱式 / 舒缓），SVG 环形进度动画
- **能量语句** - 15 条随机安抚语句，点击刷新带淡入动画
- **环境声场** - Web Audio API 合成白噪声 / 粉噪声 / 棕噪声 + 鸟鸣振荡器，4 通道独立音量调节
- **氛围配色** - 晨曦 / 雨声 / 星夜 / 森林 4 种氛围主题，实时切换流体渐变色
- **粒子流场** - Canvas 粒子系统，鼠标吸引力场 + 连接线
- **点击涟漪** - 全局点击涟漪扩散动效

## 技术栈

- Vanilla JS + CSS3 + HTML5
- Web Audio API (程序化噪声生成)
- Canvas 2D 粒子系统
- CSS Fluid Mesh Gradient 动画
- Glassmorphism 容器
- 字体: Inter, Outfit, Share Tech Mono
