# Gravity - 重力场粒子模拟

一个交互式的重力场粒子模拟器，让用户通过点击创建引力源，观察粒子在多重力场中的运动轨迹。

## 功能特性

- **多种引力模式**：吸引、排斥、环绕三种不同的力场效果
- **实时参数调节**：引力强度、粒子数量、粒子尺寸
- **四种配色方案**：宇宙紫、极光青、余烬橙、冰霜蓝
- **粒子轨迹**：带有动态拖尾效果
- **性能监控**：实时显示 FPS、粒子数、总能量

## 交互说明

1. 点击画布创建引力中心
2. 选择不同模式改变力场类型
3. 拖动滑块调节参数
4. 使用清除/重置按钮控制模拟

## 技术实现

- 纯 Vanilla JS + Canvas 2D
- 牛顿万有引力公式模拟
- 高斯模糊背景动效
- 微晶玻璃态 UI 组件
