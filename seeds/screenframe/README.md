# ScreenFrame — 沉浸式屏幕框架微交互

沉浸式屏幕框架交互体验。3D 透视响应鼠标移动的显示器框架，带有微晶玻璃态效果与粒子流场。

## 交互模式

- **悬浮 (Float)** — 鼠标靠近框架时产生 3D 倾斜响应，远离时自然漂浮
- **轨道 (Orbit)** — 框架自动沿轨道旋转，展示全角度视角
- **故障 (Glitch)** — RGB 色散分离 + 随机倾斜抖动，赛博朋克风格

## 功能

- 3 种交互模式：悬浮 / 轨道 / 故障
- 4 种氛围配色：深渊 / 极光 / 余烬 / 棱镜
- 可调参数：透视强度、倾斜幅度、发光强度
- 粒子流场跟随鼠标
- 点击脉冲冲击波
- 流体渐变背景 + 微晶玻璃态容器

## 技术栈

- Vanilla JS + CSS3 + HTML5
- 字体：Inter, Outfit, Share Tech Mono
- 动效曲线：cubic-bezier(0.16, 1, 0.3, 1)
