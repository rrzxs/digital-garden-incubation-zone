# Editorial Scroller | 编年卷轴

沉浸式编辑滚动体验，通过视差、淡入、文字揭示等高阶微交互，讲述一个流动的故事。

## 核心特性

- **视差滚动** - 多层元素以不同速度移动，创造真实的深度感
- **文字揭示动画** - 文字逐行淡入，像墨水在水中晕开
- **呼吸节奏** - 滚动体验有韵律、有停顿
- **交互反馈** - 涟漪按钮效果、光标跟随光晕
- **键盘导航** - 支持方向键、Home/End 快捷键

## 技术实现

- 纯 Vanilla JS + CSS3，免构建
- IntersectionObserver 实现滚动检测
- CSS 变量驱动的动效系统
- 流体渐变背景 + 微晶玻璃态容器

## 交互指南

- 鼠标滚动或方向键导航
- 点击右侧章节点快速跳转
- 移动鼠标在视差区域体验深度效果
- 点击涟漪按钮感受交互反馈
