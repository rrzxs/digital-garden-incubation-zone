# Fluid 流体

交互式流体模拟体验 - 基于 Navier-Stokes 方程的实时流体渲染。

## 特性

- **实时流体模拟**: 基于物理的流体动力学计算
- **高阶微交互**: 鼠标/触摸驱动的流体扰动
- **动态配色系统**: 极光、日落、深海、霓虹四种预设配色
- **参数调节**: 可调节粘性系数和扩散速度
- **全屏模式**: 沉浸式全屏体验
- **性能监控**: 实时 FPS 和粒子数显示

## 技术实现

- 基于 Jos Stam 的 Stable Fluids 算法
- 128x128 网格密度
- Gauss-Seidel 迭代求解器
- Canvas 2D 像素级渲染

## 交互方式

- 移动鼠标或触摸屏幕产生流体扰动
- 速度和密度随鼠标移动方向注入
- 使用滑块调节流体物理参数
- 点击色板切换渲染配色
