# Keyflow Navigator

Keyboard-driven spatial navigation experience with fluid gradient backgrounds and glassmorphism containers.

Navigate between interconnected nodes using WASD/Arrow keys. Press Space to emit a pulse wave, Enter to activate nodes, and 1-4 to switch color themes.

## Interactions

- **WASD / Arrow Keys** - Navigate between connected nodes
- **Tab / Shift+Tab** - Cycle through nodes
- **Space** - Emit pulse shockwave
- **Enter** - Activate focused node
- **1-4** - Switch themes (Aurora / Ember / Ocean / Void)
- **Mouse** - Parallax depth effect on nodes

## Tech

Vanilla JS + CSS3 + HTML5. Zero build. No dependencies.
