# Glyph Field — 字形力场

一个交互式字形力场体验。屏幕上铺满异域字符，鼠标移动时字符被力场吸引、排斥或卷入漩涡，产生物理驱动的非线性微交互。

## 核心交互

- **吸引模式**: 字符被鼠标吸引，聚拢成群
- **排斥模式**: 字符被推开，形成空洞
- **漩涡模式**: 字符围绕鼠标旋转，形成螺旋

## 特色

- 4 种字符集: 片假名 / 卢恩符文 / 几何符号 / 代码符号
- 4 种氛围配色: 虚空 / 翡翠 / 日蚀 / 极地
- 弹簧-阻尼物理模型驱动的字形动力学
- 粒子流场 + 连线效果
- 可调力场强度、弹性、影响半径
- 洗牌功能：随机打乱并触发物理扰动

## 技术栈

- Vanilla JS + CSS3 + HTML5
- Canvas 2D 粒子渲染
- 弹簧物理系统
- `cubic-bezier(0.16, 1, 0.3, 1)` 非线性动效曲线
