# Mineral Choir · 矿物唱诗班

沉浸式晶体合唱声景。9 枚程序化晶簇沿洞窟弧线排布，构成一座可以「演奏」的矿物唱诗班。

## 交互

| 手势 | 效果 |
|------|------|
| 悬停晶体 | 低吟哼鸣（hum），晶体微微膨胀发光 |
| 点击晶体 | 长鸣（strike）+ 粒子迸射 + 弹簧颤动 |
| 按住拖拽 | 扫弦（strum），掠过的晶体依次发声 |
| `Space` / Bloom 按钮 | 合唱绽放：全晶簇上行琶音齐鸣 |

## 声音引擎

- Web Audio 全程序化合成，无采样：正弦基音 + 三角泛音 + 失谐合唱层
- 三种和声模式：独声 / 双声（±5 音分）/ 唱诗（-8, 0, +7 音分）
- 生成式洞穴卷积混响（指数衰减噪声脉冲响应），可调湿度
- 4 种音阶：五声 / 多利亚 / 利底亚 / 平调子（Hirajoshi），根音 A3

## 视觉

- 弹簧-阻尼物理驱动的晶体脉冲与姿态摆动
- 晶体间共鸣连线：能量越足，共鸣越亮
- 共振粒子流场 + 冲击迸射
- 流体渐变背景（`blur` + `mix-blend-mode: screen`）+ 微晶玻璃态控制台
- 4 种氛围配色：紫晶 / 翡晶 / 黄晶 / 月石
- 全局动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`

## 技术

免构建 Vanilla JS + CSS3 + HTML5，无任何依赖（字体经 Google Fonts CDN）。音频需首次点击后由浏览器手势策略激活。
