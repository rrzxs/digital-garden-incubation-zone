# Proof Counter Hero · 证明计数英雄

> 沉浸式英雄计数器体验。里程仪式翻牌计数、里程碑冲击波、粒子迸射与击键节奏遥测，让每一次计数都成为一场仪式。

## 体验

- **里程仪式翻牌计数** — 数字体以发牌式数字列呈现，每次变更弹簧上浮欢腾，引导零点自动弱化，位数增长自动扩位。
- **里程碑系统** — 抵达 10 / 25 / 50 / 100 / 250 / 500 / 1000… 触发三重冲击波、粒子礼花、祝词浮层与数字列错峰欢腾。
- **里程碑编年史** — 每座界碑铭刻入右侧编年史面板，徽章核同步脉冲。
- **进度环** — 呼吸态圆环实时显示距下一里程碑的进度。
- **击键节奏遥测** — Tempo BPM 实时测算连击节奏，节奏条随频率呼吸，满档触发专属文案。
- **狂热脉冲** — 一键 ×10 连击交错爆发，粒子四处迸射。
- **多种交互** — 舞台点击计数、按钮长按连发、键盘（Space / ←→ / ↑ / R）全支持。
- **4 种氛围配色** — Aurora 极光 / Ember 余烬 / Abyss 深渊 / Orchid 兰若。

## 审美与交互

- 流体网格渐变背景（5 颗高斯模糊 blob + screen 混合 + SVG 噪点颗粒层）
- 微晶玻璃态容器（`backdrop-filter: blur` + 发光描边）
- 全局非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 粒子流场 + 鼠标微引力 + 近邻连线 + 计数迸射粒子
- `prefers-reduced-motion` 无障碍降级

## 技术栈

Vanilla JS + CSS3 + HTML5，零构建、零依赖。字体：Inter / Outfit / Share Tech Mono。

## 文件结构

```
proof-counter-hero/
├── index.html   # 结构:三栏布局 (遥测 / 英雄计数器 / 编年史)
├── style.css    # 流体背景 + 玻璃态 + 翻牌动效 + 4 主题
├── main.js      # 翻牌引擎 + 里程碑系统 + 粒子流场 + 节奏遥测

```

## 使用

直接用浏览器打开 `index.html`。点击舞台或按 Space 计数，长按按钮连发，抵达里程碑见证礼花。
