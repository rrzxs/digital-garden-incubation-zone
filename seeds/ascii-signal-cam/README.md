# ASCII Signal Cam · 字符信号摄像机

沉浸式 ASCII 字符信号摄像机 Web App。将合成信号场或实时摄像头画面实时转译为字符矩阵，配合信号透镜、脉冲冲击波与故障撕裂等高阶微交互。流体渐变背景 + 微晶玻璃态容器 + 非线性动效。

## 功能特性

- **五种信号源**
  - `Plasma` — 多重正弦叠加等离子场
  - `Tunnel` — 视角透视隧道
  - `Wave` — 双源波干涉图样
  - `Static` — 模拟信号白噪点（带残影）
  - `Cam` — 实时摄像头（getUserMedia，被拒绝时自动回退白噪点）
- **5 种字符集** — ASCII 经典阶梯 / 方块 / 二进制 / 半角片假名 / 盲文密度阶梯
- **信号透镜微交互** — 光标悬停区域字符局部放大 + 增亮 + 十字准星，平滑衰减
- **脉冲冲击波** — 点击画布产生以 26 cells/s 扩散的采样坐标扰动波
- **故障撕裂** — 随机水平条带位移 + 故障字形替换，频次由 Glitch 滑块驱动（`G` 键手动触发）
- **实时参数调制** — 分辨率（48–144 列）、对比度、亮度、故障强度
- **动作系统** — FREEZE 冻结帧 / INVERT 反相 / SNAPSHOT 导出 `.txt` 字符画（附闪光反馈）
- **键盘快捷键** — `[1-5]` 切换信号源 / `[F]` 冻结 / `[S]` 快照 / `[G]` 故障 / `[I]` 反相
- **4 种氛围配色** — Phosphor 磷光 / Vapor 蒸汽 / Ember 余烬 / Arctic 极地（字符色阶随主题实时重建）
- **CRT 质感** — 扫描线 + 暗角 + 微闪烁叠层
- **信号面板** — SIG / LUMA / NOISE / FPS 实时指标与底部遥测 Ticker

## 技术栈

- Vanilla JS + Canvas 2D + CSS3（零构建）
- 字体：Inter / Outfit / Share Tech Mono
- 动效曲线：`cubic-bezier(0.16, 1, 0.3, 1)`
- 采样管线：Float32Array 亮度缓冲 → 对比度/亮度/反相后期 → 亮度→字形阶梯映射

## 使用

直接用浏览器打开 `index.html` 即可。Cam 模式需要 HTTPS 或 localhost 环境并授予摄像头权限；无摄像头时自动回退到白噪点信号源。
