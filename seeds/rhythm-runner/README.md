# Rhythm Runner 韵律奔跑

> 沉浸式节律微交互体验场。光球沿水平轨道飞驰，节拍节点从右侧滑入，在它们进入判定环的瞬间按下空格或点击，越精准，连击越长，能量越足。

## ✨ 特性

- **节拍同步判定**：基于 BPM 的节点调度，Perfect / Good / Miss 三级判定窗口
- **连击与能量系统**：连续命中累积连击倍率（最高 x3.0），能量条驱动视觉反馈
- **流体网格渐变背景**：四颗超大模糊光团 + `mix-blend-mode: screen` 构建呼吸感氛围
- **微晶玻璃态容器**：HUD 面板采用 `backdrop-filter: blur(40px) saturate(1.6)` 与发光描边
- **非线性动效**：全部交互采用 `cubic-bezier(0.16, 1, 0.3, 1)` 物理曲线
- **Canvas 粒子系统**：环境飘浮粒子 + 命中爆发粒子 + 冲击波环 + 光球尾迹
- **4 种氛围配色**：深海 / 极光 / 余烬 / 虚空

## 🎮 操作

| 操作 | 按键 | 说明 |
|------|------|------|
| 判定 / 开始 | `Space` | 在节点进入判定环时按下 |
| 判定（触屏） | 点击轨道 | 同上 |
| 暂停 / 继续 | `P` 或 开始按钮 | — |
| 重置 | `R` 或 重置按钮 | 清空分数与连击 |
| 切换速度 | 速度按钮 | 0.8x / 1.0x / 1.25x / 1.5x |

## 🧩 技术栈

- Vanilla JS（IIFE 模块封装，无依赖）
- CSS3 自定义属性 + Glassmorphism
- HTML5 Canvas 2D
- Google Fonts: `Inter` / `Outfit` / `Share Tech Mono`

## 📐 判定窗口

- **Perfect**: 距理想时刻 ±80ms（100 分 × 连击倍率）
- **Good**: ±170ms（50 分 × 连击倍率）
- **Miss**: 超出窗口或自动超时（连击清零，能量扣减）
