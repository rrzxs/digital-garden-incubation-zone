# Audio Terrain · 声波地形

沉浸式声波地形交互体验 —— 声音即大地。

## 概念

声音化为大地：Web Audio 频谱实时驱动 Simplex 噪声地形隆起流变。四个频段（SUB / BASS / MID / HIGH）分别拥有地形的不同区域——超低频隆起中央山核，低频撑起环带丘陵，中高频塑造起伏细节与边缘碎峰。

## 功能

- **三种音源**：内置合成音源（雾海漂移 / 脉冲心跳 / 雷暴降临 / 星尘合唱 4 种预设）、实时麦克风、静默平原
- **双交互模式**：聆听（光标扰动声场）· 雕塑（按住拖拽雕刻山脉）
- **点击冲击波**：涟漪在地形上传播推挤山体
- **频谱 HUD**：RMS / PEAK 电平表 + 四频段实时条
- **粒子流场**：Simplex 噪声流场粒子随音能加速上升
- **4 种氛围配色**：深渊 · 极光 · 熔岩 · 翠林

## 技术

- Vanilla JS + CSS3 + HTML5，零构建
- Canvas 2D 等距投影地形（画家算法深度排序）
- 内嵌 Simplex 噪声（fbm 多倍频叠加）
- Web Audio AnalyserNode 频谱分析；麦克风路径静音监听以避免回授
- 动效曲线统一 `cubic-bezier(0.16, 1, 0.3, 1)`
- 流体渐变背景 + 微晶玻璃态容器（backdrop-filter）

## 使用

浏览器直接打开 `index.html`。首次点击页面任意处启动音频引擎（浏览器手势策略）。
