# Bill Split

> Split smart, settle easy.

智能账单分摊工具 — 支持多人多种分摊规则与实时结算预览。

## 功能

- 添加菜品 / 项目与金额
- 添加用餐者（自动生成彩色头像）
- **均分模式**：选中用餐者后自动平均分配
- **自定义模式**：手动指定每人分摊金额
- **拖拽分配**：将菜品卡片拖拽至用餐者头像
- 实时结算预览，差额提示
- 重置全部

## 技术栈

- Vanilla JS + CSS3 + HTML5
- 零构建，即插即用
- Glassmorphism UI + Mesh Gradient 背景
- 物理曲线微交互 (`cubic-bezier(0.16, 1, 0.3, 1)`)
