# Dragonfly Hover Trail 蜻蜓悬停轨迹

> 沉浸式蜻蜓悬停轨迹微交互体验。弹簧-阻尼物理驱动的蜻蜓群追随光标悬停飞舞，留下流体光痕轨迹，4 种飞行模式（追随/环绕/编队/散逸）、脉冲冲击波、漂浮花粉粒子流场与微晶玻璃态容器，4 种氛围配色。

## 核心交互

| 模式 | 行为 |
|------|------|
| **追随 Chase** | 蜻蜓群悬停在光标后方，形成动态尾随轨迹，随光标速度调整滞后距离 |
| **环绕 Orbit** | 蜻蜓以各自轨道半径环绕光标旋转，速度与方向由悬停半径调制 |
| **编队 Formation** | 光标快速移动时蜻蜓列成 V 字雁阵紧随其后；静止时径向散布 |
| **散逸 Scatter** | 蜻蜓被排斥至光标外围形成警戒圈，保持安全距离环绕飞舞 |

## 参数调节

- **蜻蜓数量** — 4 ~ 48 只
- **悬停半径** — 40 ~ 360px
- **飞行弹性** — 0.010 ~ 0.160（弹簧刚度，越大越紧贴目标）
- **空气阻尼** — 0.70 ~ 0.97（阻尼系数，越大滑翔越远）
- **轨迹长度** — 0 ~ 60 节点（流体光痕拖尾）

## 操作

- **移动光标** — 引领蜻蜓群飞舞，自动留下发光轨迹
- **点击画布** — 触发涟漪冲击波，蜻蜓惊飞散开
- **聚拢按钮** — 将所有蜻蜓强力拉向光标
- **惊飞按钮** — 以光标为中心释放全屏冲击波

## 技术栈

- Vanilla JS + Canvas 2D（无构建）
- 弹簧-阻尼飞行物理 · 翅膀拍频随速度提升 · 短弧角度插值平滑转向
- CSS3 自定义属性 + `backdrop-filter` 微晶玻璃态
- `cubic-bezier(0.16, 1, 0.3, 1)` 非线性动效曲线
- 字体：Inter / Outfit / Share Tech Mono
