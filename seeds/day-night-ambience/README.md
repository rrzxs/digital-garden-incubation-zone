# Day-Night Ambience · 昼夜氛围

沉浸式昼夜氛围呼吸体验。拖拽时间刻度，让天空在 24 小时间流变——黎明薄雾、正午钴蓝、黄昏熔金与午夜星河。生成式环境声场随昼夜交叉渐变。

## 体验要点

- **24 小时天空引擎**：11 组关键帧色板经 smoothstep 环形插值，天空渐变、地平线、雾气与流体渐变光球随小时实时流变。
- **日月弧线**：太阳与月亮沿抛物线弧交替运行，正午高悬、黄昏沉入地平线。
- **昼夜生态粒子**：深夜星空闪烁、白昼云层漂移与风絮（蒲公英）、黄昏萤火虫游弋，全部随 daylight 因子淡入淡出。
- **生成式环境声场（AMBIENCE）**：Web Audio 合成——棕色噪声风床 + 白昼鸟鸣（正弦滑音啁啾）+ 深夜虫声（三角波脉冲），随时间交叉渐变。
- **弹簧时间刻度**：拖拽即刻响应，点击「六个瞬间」卡片以弹簧-阻尼非线性缓动滑向目标时刻。
- **点击涟漪**：天空任意位置点击产生双层 expo-out 涟漪。
- **微晶玻璃态**：所有容器 `backdrop-filter: blur(22px)` + 发光描边；全局动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`。
- **4 种氛围配色**：Aurora / Ember / Tide / Mono。
- **HUD 遥测**：本地时刻、相位、日照率、下一次日出/日落倒计时、声场状态。

## 技术

- 免构建：Vanilla JS + CSS3 + HTML5，无任何依赖。
- 字体：Inter / Outfit / Share Tech Mono（Google Fonts CDN）。
- Canvas 粒子层 + DOM 天空层混合渲染。
- Maintainer: EDEN

## 文件

- `index.html` — 结构与内容
- `style.css` — 流体渐变背景、玻璃态容器、非线性动效
- `main.js` — 天空引擎、粒子系统、声场引擎与交互逻辑
