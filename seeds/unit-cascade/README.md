# Unit Cascade 级联单元

沉浸式级联微交互体验场。点击画布触发级联坍缩，观察单元方块在重力、弹性和链式碰撞中的动力学行为。

## 核心交互

- **级联坍缩**: 点击画布任意位置触发冲击波，周围方块被弹飞并产生链式碰撞反应
- **力场模式**: 鼠标产生排斥力场，推开附近悬浮的单元方块，场线可视化
- **波浪模式**: 正弦波场驱动所有已沉淀方块产生呼吸般的波浪起伏
- **粒子火花**: 碰撞和级联时迸射发光粒子，涟漪环从触发点向外扩散
- **重力物理**: 可调重力、级联力、弹性参数，影响方块运动行为

## 三种交互模式

| 模式 | 描述 |
|------|------|
| Cascade 级联 | 点击触发冲击波级联坍缩，方块弹飞后重新沉淀 |
| Field 力场 | 鼠标产生排斥力场，推开附近方块并显示场线 |
| Wave 波浪 | 正弦波驱动方块产生连绵起伏的波浪效果 |

## 技术实现

- 纯 Vanilla JS + Canvas 2D 渲染
- 重力 + 碰撞检测 + 弹性物理模拟
- 冲击波涟漪传播与级联链式反应
- 粒子火花系统 (Sparkle Particles)
- CSS `backdrop-filter` 微晶玻璃态容器
- 流体网格渐变 (Mesh Gradient) 动态背景
- `cubic-bezier(0.16, 1, 0.3, 1)` 非线性缓动曲线
- 4 种氛围配色: 黑曜石 / 极光 / 余烬 / 霜降
- 全响应式布局，支持移动端触控
