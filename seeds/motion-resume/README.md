# Motion Resume 韵动履历

沉浸式高阶微交互履历体验。流体渐变背景 + 微晶玻璃态容器 + 非线性动效，将个人履历转化为一场可滚动、可触摸的视觉旅程。

## 核心交互

- **流体粒子场**: 90 个粒子在 Simplex 噪声流场中流动，受鼠标引力扰动，滚动时产生垂直漂流，带拖尾轨迹与邻近连线
- **滚动进度轨**: 左侧固定导航轨实时反映滚动进度，节点高亮当前章节，点击平滑跳转
- **字符揭示**: Hero 与章节标题逐字符错峰浮现，配合 `cubic-bezier(0.16, 1, 0.3, 1)` 非线性缓动
- **磁力 CTA**: 按钮与联络链接被光标磁力吸引，产生弹性位移
- **3D 倾斜卡片**: 自述、编年与造物卡片响应鼠标进行透视倾斜
- **数字滚动**: 年限与造物计数以 ease-out-expo 曲线滚动至目标值
- **乱码揭示**: 状态文字从随机字符解密为目标文本
- **技能星座**: 13 个技能芯片分布于三层轨道，悬停/点击展示熟练度进度条
- **编年时间线**: 滚动驱动的脊柱进度条 + 脉冲标记节点
- **4 种配色**: 黑曜石 / 极光 / 余烬 / 霜降

## 技术实现

- 纯 Vanilla JS + Canvas 2D 渲染，免构建零依赖
- `requestAnimationFrame` 驱动 60fps 粒子流场
- `IntersectionObserver` 思路的滚动检测驱动 reveal 动画
- CSS `backdrop-filter` 微晶玻璃态容器
- 流体网格渐变背景（`filter: blur(140px)` + `mix-blend-mode: screen`）
- `cubic-bezier(0.16, 1, 0.3, 1)` 非线性缓动曲线贯穿全部交互
- 全响应式布局，支持移动端与 `prefers-reduced-motion`

## 字体

- **Inter** — 正文
- **Share Tech Mono** — 数值、标签与等宽文本
