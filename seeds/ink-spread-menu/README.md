# Ink Spread Menu - 墨韵展开菜单

沉浸式墨韵展开导航菜单。点击画布任意位置，墨滴从指尖扩散，径向菜单从墨迹中浮现。

## 交互方式

- **点击空白区域**：在点击位置展开墨韵菜单
- **点击菜单项**：选中并触发墨纹涟漪反馈
- **点击菜单外区域**：收起当前菜单
- **ESC 键**：关闭菜单
- **鼠标移动**：扰动背景粒子场

## 视觉特性

- 流体渐变背景 + 微晶玻璃态容器
- 墨滴中心点 + 多层涟漪环 + 不规则墨斑扩散
- 径向菜单项带弹簧物理出场动画
- Canvas 涟漪波纹 + 粒子迸射
- 连接线从中心向菜单项辐射
- 4 种氛围配色：墨夜 / 月墨 / 朱砂 / 虚空

## 技术栈

- Vanilla JS + CSS3 + HTML5
- Canvas 2D 粒子系统
- CSS Custom Properties 主题切换
- 零依赖、零构建
