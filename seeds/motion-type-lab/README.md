# Motion Type Lab — 动效字体实验室

沉浸式动效字体微交互体验。输入文字，观察字符在邻近力场、弹簧-阻尼物理与非线性缓动中实时呼吸。流体渐变背景 + 微晶玻璃态容器 + 非线性动效。

## 动效模式

- **Breath 呼吸** — 字符随正弦节律脉动膨胀、字重渐变、字距起伏
- **Wave 波纹** — 邻近力场触发字重激增与字距扩张，光标即笔触
- **Depth 景深** — 邻近字符模糊离焦、缩放偏移，营造 z 轴纵深
- **Orbit 轨道** — 字符绕力场中心旋转倾斜，3D 透视归位
- **Scramble 乱码** — 邻近字符化为乱码，远离后逐字解密揭示

## 交互

- 光标力场：排斥 / 吸引 / 环绕三种方向模式
- 冲击波脉冲：点击舞台或空格键触发环形冲击波，字符与粒子被推开
- 随机调参：一键随机模式、方向与参数（S 键）
- 重置参数：恢复默认（R 键）
- 数字键 1-5：快速切换动效模式
- 字符遥测：悬浮显示最近字符的邻近度、字重等实时数据
