# MotionPath Gallery 运动轨迹画廊

## 概述
沉浸式运动轨迹画廊。8种数学运动路径（轨道、无限、螺旋、波浪、利萨如、玫瑰线、内旋轮线、噪声场）以微晶玻璃态卡片呈现。点击卡片激活轨迹动画，观察粒子在画廊空间中绘制优美的数学曲线。活跃轨迹之间自动生成流动连接线。

## 功能特性
- **8种运动路径**: Orbit轨道 / Infinity无限 / Spiral螺旋 / Wave波浪 / Lissajous利萨如 / Rose玫瑰线 / Hypotrochoid内旋轮 / Noise噪声场
- **微晶玻璃态卡片**: 每张卡片内嵌迷你 Canvas 实时预览运动轨迹
- **画廊级轨迹画布**: 激活的卡片在共享画布上绘制带弹簧物理的流动轨迹
- **粒子流场背景**: Simplex 噪声驱动的粒子随鼠标轻柔响应
- **曲线连接线**: 活跃轨迹之间自动生成贝塞尔曲线连接
- **脉冲冲击波**: 激活/切换时产生涟漪脉冲扩散
- **速度控制**: 0.2x ~ 3.0x 可调节动画速率
- **全部启动 / 随机脉冲**: 一键激活所有或随机子集
- **4种氛围配色**: 黑曜石 / 极光 / 余烬 / 虚空
- **流体渐变背景**: 4层模糊光斑有机漂移
- **光标追踪光晕**: 鼠标位置产生氛围感光晕

## 技术实现
- Vanilla JS + CSS3 + HTML5，零构建依赖
- Canvas 2D 多层渲染（背景粒子 / 路径轨迹 / 迷你预览）
- Simplex Noise 2D 噪声算法
- 弹簧-阻尼物理模型（轨迹粒子跟随）
- CSS Custom Properties 驱动主题切换
- `cubic-bezier(0.16, 1, 0.3, 1)` 非线性缓动曲线
- `backdrop-filter` 微晶玻璃态容器
