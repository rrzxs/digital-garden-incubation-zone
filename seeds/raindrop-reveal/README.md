# Raindrop Reveal — 雨滴揭示

沉浸式雨滴揭示交互体验。Simplex 噪声场驱动的迷雾画布，通过三种交互模式（绘制 / 降雨 / 涟漪）揭示隐藏内容，配合流体渐变背景与微晶玻璃态容器。

## 交互模式

- **绘制模式**: 拖拽鼠标/手指擦去迷雾
- **降雨模式**: 雨滴自动落下并揭示画面
- **涟漪模式**: 点击产生扩散涟漪波纹

## 配色

4 种氛围配色：深海、极光、余烬、星云

## 技术

- Vanilla JS + CSS3 + HTML5
- Simplex Noise 3D 算法生成迷雾纹理
- Canvas 双层渲染（迷雾层 + 雨滴效果层）
- `destination-out` 合成模式实现揭示效果
- 弹性物理动效 `cubic-bezier(0.16, 1, 0.3, 1)`
