# Constellation Report Canvas · 星座报告画布

沉浸式星座报告生成器。输入姓名与降生之日（或直接点击星座符号），观测台即刻为你绘制一张独一无二的星图报告。

## 体验亮点

- **星座连线逐笔绘制**：Canvas 星图以非线性缓动逐段描绘，笔尖携带行进光点，恒星随连线抵达依次点亮并持续闪烁
- **特质雷达扫描**：六维特质（直觉/意志/共情/创造/理性/活力）以雷达扫描动画呈现，数值由观测者姓名 + 生日 + 星座的种子哈希确定性生成
- **能量指标脉动**：四项宇宙指标（星光强度/引力共振/逆行缓冲/宇宙幸运）滚动数字 + 弹性进度条错峰入场
- **确定性随机**：Mulberry32 种子随机——同一观测者永远得到同一份报告，「再观测一次」才引入新的扰动盐值
- **流体渐变背景**：四个超大模糊光球以 mix-blend-mode: screen 呼吸漂移，叠加 160 颗视差星尘与颗粒噪点
- **微晶玻璃态容器**：backdrop-filter 毛玻璃卡片 + 发光描边，全局自定义光标（辉光 + 弹性跟随圆环）
- **4 种氛围配色**：Nebula 星云 / Aurora 极光 / Ember 余烬 / Void 虚空，一键切换整体色彩场

## 技术规范

- 纯 Vanilla JS + CSS3 + HTML5，零构建、零依赖、零 package.json
- 字体：Inter（正文）/ Outfit（展示）/ Share Tech Mono（数据读数）
- 全局动效曲线：`cubic-bezier(0.16, 1, 0.3, 1)`
- 尊重 `prefers-reduced-motion`

## 运行

直接用浏览器打开 `index.html`，或经数字花园主页导航进入。
