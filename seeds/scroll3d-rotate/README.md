# Scroll 3D Rotate · 滚动三维旋转

沉浸式滚动三维旋转体验场。滚动驱动的六种 3D 旋转模式，让平面卡片在三维空间中翻飞：

1. **倾斜 (Tilt)** — 玻璃态卡片跟随光标做透视倾斜，光晕追踪
2. **翻转 (Flip)** — 卡片沿 Y 轴翻转，正反两面交替显现，可点击切换
3. **翻滚 (Tumble)** — 卡片沿 X 轴翻滚 + Z 轴扭转，叠放群次第翻转
4. **轨道 (Orbit)** — 六个节点沿椭圆轨道环绕核心公转 + 自转
5. **螺旋 (Spiral)** — 八个节点沿 DNA 双螺旋路径旋转上升
6. **立方体 (Cube)** — 完整六面立方体在掌心做三轴旋转

## 交互

- **滚动**：驱动每一幕的 3D 旋转核心
- **鼠标移动**：卡片透视倾斜 + 光晕追踪 + 粒子吸引
- **点击翻转卡**：手动切换正反面
- **键盘 ↑↓ ←→**：切换章节
- **右上角 HUD**：实时显示当前 X/Y/Z 旋转角度读数
- **右下角配色**：4 种氛围配色 (Aurora 极光 / Ember 余烬 / Ocean 深海 / Void 虚空)

## 技术栈

- Vanilla JS + CSS3 + HTML5（免构建）
- CSS `transform-style: preserve-3d` + `perspective` 三维变换
- Simplex Noise（内联实现）粒子流场
- Canvas 2D 粒子系统
- CSS 变量主题系统
- `cubic-bezier(0.16, 1, 0.3, 1)` 非线性动效曲线
