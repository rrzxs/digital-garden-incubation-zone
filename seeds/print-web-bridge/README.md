# Print Web Bridge — 印物桥

沉浸式屏幕与纸面之间的流体桥接工作台。@page 参数工作台 + 双视口实时同步预览 + 墨色映射 + 打印 CSS 一键导出。

## 功能

- **双视口桥接预览**：左侧屏幕文档视口（数字态）与右侧纸面视口（物理态）并排呈现，中央桥接连接器实时流转粒子，三态切换（桥接 / 仅屏幕 / 仅纸面）
- **@page 参数工作台**：
  - 纸张规格（A4 / A5 / Letter / Legal）
  - 纵横向切换
  - 页边距滑块（0–40mm）
  - 字体族（Sans / Serif / Mono）
  - 字号（9–16pt）与行高（1.2–2.2）调节
- **墨色映射**：浓墨 / 省墨模式，对比度滑块（60–100%）
- **输出选项**：出血标记、页眉页脚、分栏、水印四开关
- **纸面负载计算**：实时计算密度百分比与页数估算
- **CSS 导出抽屉**：一键生成完整的 `@media print` 样式表，支持复制与下载
- **系统打印唤起**：直接调用浏览器原生打印对话框
- **Simplex 噪声粒子流场**：背景粒子受流场与光标双重驱动
- **桥接粒子流**：双视口间周期性粒子流转动画
- **自定义光标** + 流体渐变背景 + 微晶玻璃态容器
- **遥测面板**：视口、规格、边距、字号、墨色、FPS 实时显示
- **4 种氛围配色**：墨石（深沉）、素笺（浅色）、暮霞（暖色）、深渊（冷蓝）
- **键盘快捷键**：`1-4` 切换配色、`S` 重置、`Esc` 关闭抽屉

## 技术

Vanilla JS + CSS3 + HTML5，零构建依赖。内置 Simplex 噪声实现驱动粒子流场。字体使用 Inter / Outfit / Share Tech Mono / Playfair Display。动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)` 与弹簧曲线 `cubic-bezier(0.34, 1.56, 0.64, 1)`。
