FRAME 003
ACT I // THE INCITING INCIDENT

你的指尖 是最锋利的剪辑刀

每一次滚动都是一次 cut。快划是蒙太奇，慢移是长镜头。 你正在用指尖导演一部只属于你的电影。

FRAME 004
ACT II // RISING ACTION

节奏是 最安静的叙事者

好的分镜师知道何时让画面静止，何时让节奏加速。 每一帧之间的留白，才是故事真正呼吸的地方。

FRAME 005
ACT II // PARALLAX DEPTH

深度是 用速度伪造的魔术

前景的网格快速掠过，中景的文字悠然滑行，背景的光球几乎不动。 三层速度叠加，二维屏幕便拥有了 Z 轴的幻觉。

FRAME 006
ACT III // THE CLIMAX

高潮是 所有线索在同一帧碰撞

分镜的高潮帧总是被画得最满、最密、最用力。 所有的线条在这一刻汇聚，所有的情感在这一帧引爆。

FRAME 007
EPILOGUE // FADE OUT

故事不会结束 它只是等待下一次滚动

每一帧分镜都是一扇门。你推开它，走进去，然后发现—— 门后还有无数帧。而你，永远是自己故事的总导演。
