# Cursor Replay Studio · 光标回放工作室

录制你的光标手势，然后以电影化的方式回放它。每一次移动、每一次点击，都被赋予彗尾、回声、缎带与迸射四种演出风格，配合残影光标错峰追随，让光标轨迹成为一场可反复欣赏的演出。

## 交互

- **录制 (R)** — 点击「录制」后自由移动光标，点击画布标记事件点，最长 30 秒自动收尾并回放
- **播放 / 暂停 (Space)** — 回放当前录制的手势，支持循环模式
- **停止 (Esc)** — 停止回放并归零
- **时间轴拖拽** — 底部时间轴可任意拖拽定位回放时刻，已触发的点击事件会重新校准
- **四种轨迹风格** — 彗尾（渐变发光描边）/ 回声（等距脉冲历史点）/ 缎带（速度映射宽度的实体缎带）/ 迸射（沿路径持续喷发粒子）
- **残影滑杆** — 0~5 个残影光标以固定时间间隔错峰追随主光标
- **速度 / 余辉** — 0.25×~2× 变速回放，全局辉光强度调节
- **遥测 HUD** — 实时显示时长、采样数、点击数与瞬时速度
- **4 种氛围配色** — 深渊 / 极光 / 暮色 / 烬火
- 页面加载即自动演出一段利萨如签名演示手势

## 技术说明

- Vanilla JS + CSS3 + HTML5，免构建
- 录制：rAF 采样 + 距离阈值去重；回放：二分查找 + smoothstep 插值
- 流体渐变背景：超大模糊 blob + `mix-blend-mode: screen`
- 微晶玻璃态容器：`backdrop-filter` + 发光描边
- 全局非线性动效曲线：`cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Outfit（展示）/ Inter（正文）/ Share Tech Mono（遥测 HUD）
