# Focus Pulse 专注脉冲

一个有氛围感的番茄钟/专注计时器，帮助你在工作与休息之间找到平衡。

## 功能特点

- **25分钟专注 + 5分钟休息**：经典的番茄工作法时间设定
- **圆环进度动画**：直观显示剩余时间
- **脉搏动画效果**：背景随时间节奏产生柔和的呼吸感
- **深色流体背景**：深蓝/紫色基调配合青色/粉色高光
- **温柔提醒**：计时完成时弹出优雅的完成提示
- **可选声音提示**：使用 Web Audio API 生成柔和的提示音
- **累计统计**：记录完成的番茄数和总专注时间

## 使用方法

1. 点击中心圆环开始专注计时
2. 再次点击可暂停计时
3. 专注完成后会弹出休息提示
4. 休息结束后可继续下一个专注周期
5. 点击重置按钮可随时重新开始

## 快捷键

- `Space`：开始/暂停计时
- `R`：重置计时器（仅在未运行时）

## 技术实现

- 纯前端实现：Vanilla JS + CSS3 + HTML5
- 无构建依赖，开箱即用
- SVG 圆环进度动画
- CSS 变量驱动的主题切换
- localStorage 持久化统计数据
- Web Audio API 生成提示音

## 设计理念

专注脉冲追求宁静、专注、有呼吸感的视觉体验。采用流体网格渐变背景配合微晶玻璃态设计，让使用者在专注工作时感受到平静与舒适。
