# Page Transition Studio 页面过渡实验室

沉浸式页面过渡动效体验场 — 流体渐变背景 + 微晶玻璃态容器 + 非线性动效。

> 过渡即设计语言。这是一座关于"页面如何变化"的电影级剧场 — 6 种高阶过渡模式实时演绎数字界面的流动美学。

## 体验特色

- **6 种过渡模式** — 实时切换并预览六种电影级页面过渡
  - **液态形变 (Liquid Morph)** — 缩放 + 斜移 + 模糊的流体推拉
  - **裁切揭示 (Clip Reveal)** — `clip-path` inset 横向擦除
  - **尺度纵深 (Scale Depth)** — Z 轴推拉的 3D 纵深感
  - **故障溶解 (Glitch Dissolve)** — RGB 色散 + 扫描线 + 阶跃抖动
  - **幕帘裂分 (Curtain Split)** — `clip-path` polygon 垂直裂幕
  - **轨道流转 (Orbital Flow)** — 旋转 + 弧线位移的轨道感
- **5 幕叙事内容** — 每页讲述一段关于"流动界面"的设计哲思（序章 / 节奏 / 纵深 / 故障 / 终章）
- **流体粒子场** — 130 个带轨迹粒子全屏流动，光标附近产生引力扰动与贝塞尔流线
- **4 种氛围配色** — 黑曜 / 静昼 / 余烬 / 苍翠，一键切换全局色彩生态
- **多模态导航** — 键盘方向键、空格、数字键、滚轮、触摸滑动、点击指示器
- **重播按钮** — 一键重播当前页过渡，方便细品每种模式的物理质感
- **光标辉光** — 跟随鼠标的径向渐变光晕，随主题变色
- **电影级缓动** — 每种模式配对专属 `cubic-bezier` 曲线，HUD 实时显示当前缓动函数

## 技术栈

- Vanilla JS + CSS3 + HTML5
- 零依赖，免构建
- Google Fonts: Inter, Outfit, Share Tech Mono
- 动效曲线: `cubic-bezier(0.16, 1, 0.3, 1)` 为基准，每种模式有独立缓动

## 操作方式

| 输入 | 动作 |
|------|------|
| `← →` / `↑ ↓` | 切换页面 |
| `Space` | 下一页 |
| `1` ~ `5` | 跳转到指定页 |
| 鼠标滚轮 | 切换页面 |
| 触摸滑动 | 切换页面 |
| 底部指示器 | 点击跳转 |
| 页面内 CTA | 前进 / 回到序章 |
| 模式胶囊 | 切换过渡模式并自动重播 |
| 重播按钮 | 重播当前过渡 |

## 过渡模式架构

每种过渡模式通过 `body[data-mode]` 选择器驱动 CSS 类状态机：

```
hidden → entering → active → leaving → hidden
```

JavaScript 负责时序编排（reflow + class swap），CSS 负责每种模式下的
`transform` / `opacity` / `clip-path` / `filter` 终态。这样实现了
动效逻辑与视觉表现的彻底解耦。
