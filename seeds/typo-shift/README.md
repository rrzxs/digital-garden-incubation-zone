# Typo Shift — 字形位移实验室

沉浸式排版位移交互体验。输入文字，观察字间距、行高、字重、字号在流体曲线下实时形变。

## 功能

- **4 种位移模式**：Wave（波浪）、Breathe（呼吸）、Scatter（散射）、Cascade（瀑布）
- **实时参数控制**：字号、字重、字距、行高、振幅、速度
- **乱码揭示动画**：输入文字时字符从随机符号逐字解密
- **4 种氛围配色**：极光、烬火、森林、虚空
- **随机变形**：一键随机化所有参数
- **字符悬停元数据**：悬停显示实时位移数据
- **流体渐变背景** + 微晶玻璃态容器
- **键盘快捷键**：`1-4` 切换模式、`S` 随机、`R` 重置

## 技术

Vanilla JS + CSS3 + HTML5，零构建依赖。字体使用 Inter / Outfit / Share Tech Mono。动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`。
