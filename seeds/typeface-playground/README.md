# Typeface Playground — 排版铸造实验室

沉浸式字体排版游乐场。实时操控字重、字宽、斜度、光学尺寸、字距与行高，拖拽字距张力球精修字符间距，一键导出可复制的 CSS。流体渐变背景 + 微晶玻璃态容器 + 非线性动效。

## 核心交互

- **Typography Axes 排版轴**：字重（100–900）、字宽、斜度、字号、字距、行高六轴实时塑形
- **Kerning Pair Tension 字距张力**：拖拽字符间的张力球，可视化精修任意字符对的间距，改动计入导出的 CSS
- **Magnetic Hover 磁力悬停**：光标靠近字符产生磁力上浮与发光描边
- **Force Field 力场扰动**：开启后光标如斥力场推开字符与粒子流
- **Baseline Grid 基线网格**：随行高自适应的律动参考线
- **Texture 纹理**：渐变描色 / 描边光泽 / 全大写 / 斜体 四象可叠加
- **Generated CSS**：参数实时编译为带语法高亮的 CSS 代码，一键复制

## 氛围配色

- **Obsidian 黑曜**（紫粉，默认）
- **Verdigris 铜绿**（青绿）
- **Ember 余烬**（金橙）
- **Halcyon 静海**（淡蓝银）

## 操作

- 鼠标移动：字符磁力响应 / 力场扰动
- 拖拽张力球：调节字符对间距
- `随机`：随机铸造一组排版参数
- `重置`：恢复默认状态
- `复制`：复制生成的 CSS 到剪贴板

## 字体

- 展示字 / 字形：Outfit（100–900 可变字重）
- 界面文字：Inter
- 数值 / 代码：Share Tech Mono

## 技术栈

Vanilla JS + CSS3 + HTML5，零构建依赖。动效曲线统一 `cubic-bezier(0.16, 1, 0.3, 1)`。
