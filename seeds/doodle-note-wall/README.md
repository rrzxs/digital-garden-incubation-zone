# Doodle Note Wall 涂鸦便签墙

沉浸式涂鸦便签墙体验场。输入念头按 Enter 掷向墙面——弹簧-阻尼物理驱动的微晶玻璃态便签弹跳生根，可拖拽抛掷、光标斥力场温柔推挤、点击空壁激起冲击波涟漪、双击便签撕毁并迸射粒子。

## 特性

- **弹簧-阻尼物理**：便签归位弹簧 + 阻尼 + 值噪声环境漂移呼吸
- **拖拽抛掷**：惯性抛出、边界弹性反弹、姿态旋转弹簧
- **冲击波涟漪**：点击空壁触发传播波前，途经便签获得径向冲量
- **乱码揭示**：便签文字以乱码逐字解码浮现
- **粒子层**：环境流场尘埃 + 撕毁迸射碎屑
- **氛围配色**：拂晓 / 正午 / 暮色 / 极光 四种流体渐变背景
- **免构建**：Vanilla JS + CSS3 + HTML5，零依赖即插即用

## 技术

- 动效曲线统一 `cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Inter / Outfit / Share Tech Mono
- 微晶玻璃态容器：`backdrop-filter: blur()` + 发光描边

## 使用

直接打开 `index.html`，或经数字花园主页进入。
