# Logo Context Menu — 徽标语境菜单

沉浸式徽标语境菜单微交互体验。一个可形变的动态徽标居于微晶玻璃态舞台中央，右键（或长按）唤起径向语境菜单，菜单项将徽标实时形变为球体、晶片、绽放、波环、星辰、虚空六种形态。

## 交互方式

- **右键点击（舞台任意位置）**：在指针处唤起径向语境菜单
- **左键点击徽标**：在徽标中心唤起菜单
- **长按徽标（移动端）**：触感震动后唤起菜单
- **点击菜单项**：徽标实时形变 + 粒子迸射 + Toast 反馈
- **点击菜单外 / ESC**：收起当前菜单
- **鼠标移动**：扰动背景粒子流场

## 视觉特性

- 流体网格渐变背景（4 层 blob 呼吸漂浮）
- 微晶玻璃态主容器 + 玻璃态菜单项
- 徽标由 SVG 多层组成：旋转虚线环 + 路径形变体 + 呼吸核心
- 径向菜单：中心点 + 多层涟漪环 + 连接线辐射 + 弹簧出场
- Canvas 粒子流场（拖尾）+ 冲击波环 + 迸射粒子
- 非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 实时 HUD 面板：形态、氛围、自旋脉冲呼吸条、操作日志
- 4 种氛围配色：极光 / 余烬 / 深渊 / 绽放

## 徽标形态

| 形态 | 说明 |
|------|------|
| ORB 球体 | 呼吸正圆 |
| SHARD 晶片 | 六边形晶体 |
| BLOOM 绽放 | 八瓣花瓣 |
| WAVE 波环 | 正弦波动的圆环 |
| STAR 星辰 | 五角星 |
| VOID 虚空 | 噪声扰动的有机团块 |

## 技术栈

- Vanilla JS + CSS3 + HTML5（零依赖、零构建）
- SVG 动态 path 形变（每帧重算 `d` 属性）
- Canvas 2D 粒子系统 + 冲击波
- CSS Custom Properties 主题切换
- 支持 `prefers-reduced-motion`
