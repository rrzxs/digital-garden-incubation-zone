# ✨ 回声打字机 | Echo Typing

> 打字时每个字符都会产生视觉回声和音效，营造沉浸式写作体验

## 项目简介

回声打字机是一个创新的文本编辑体验工具，旨在为打字过程增添沉浸式的视听反馈。每一次按键都会触发独特的视觉效果和音频回声，让写作变得更加有趣和富有表现力。

## 核心特性

- 🎨 **视觉回声效果**: 每个字符输入时会产生扩散的视觉回声动画
- 🔊 **动态音效**: 根据字符编码生成独特的音效反馈
- 📊 **实时统计**: 显示字符数、回声次数和打字节奏
- 🎛️ **自定义控制**: 可独立开关音效和回声效果
- 💫 **流畅动画**: 使用 cubic-bezier 非线性曲线的顺滑过渡
- 📱 **响应式设计**: 完美适配桌面和移动设备

## 技术实现

### 前端技术栈
- **HTML5**: 语义化结构
- **CSS3**: 
  - 流体网格渐变背景
  - 微晶玻璃态设计 (Glassmorphism)
  - CSS 动画与过渡
- **Vanilla JavaScript**: 
  - Web Audio API 音效生成
  - DOM 操作与事件处理
  - ResizeObserver 响应式适配

### 设计原则
- 免构建优先：无需 package.json 或构建工具
- 现代字体：Inter, Outfit
- 高级材质：backdrop-filter 模糊效果
- 非线性交互：cubic-bezier(0.16, 1, 0.3, 1) 缓动曲线

## 使用说明

1. 点击输入框开始打字
2. 观察每个字符产生的视觉回声效果
3. 听到基于字符生成的独特音效
4. 使用顶部控制栏：
   - 🔊 开关音效
   - 💫 开关回声效果
   - 🗑️ 清空内容
5. 查看底部统计面板了解打字数据
