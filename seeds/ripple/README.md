# Ripple 涟漪

交互式涟漪扩散体验 - 点击或触摸产生优雅的波纹扩散效果。

## 特性

- **实时涟漪模拟**: 物理驱动的波纹扩散与衰减
- **高阶微交互**: 鼠标/触摸/多点触控驱动
- **动态配色系统**: 海洋、极光、樱花、午夜四种预设配色
- **参数调节**: 可调节涟漪半径、衰减速率和强度
- **自动模式**: 自动生成涟漪的沉浸体验
- **全屏模式**: 沉浸式全屏体验
- **性能监控**: 实时 FPS 和涟漪数显示

## 交互方式

- 点击或触摸屏幕产生涟漪
- 移动鼠标持续产生涟漪轨迹
- 使用滑块调节涟漪参数
- 点击色板切换渲染配色
