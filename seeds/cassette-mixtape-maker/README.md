# Cassette Mixtape Maker · 卡带混音带工坊

沉浸式卡带混音带制作体验。为 SIDE A 录制曲目，看着磁带在两个卷轴间流转——收带盘越转越满、供带盘越缩越小，机械计数器走字、VU 表随种子音景律动。

## 玩法
- **录制曲目**：输入曲名与时长（`m:ss`），按 `＋ REC` 卷进磁带（SIDE A 上限 30 分钟）
- **走带控制**：`Space` 播放/暂停 · `R` 倒带 · `F` 快进 · `E` 退带回起点
- **点击曲目**直接跳播；**拖拽 ⠿** 重排（FLIP 物理动画）；`×` 抹除单曲
- **随机重排**洗牌歌单；**消磁清空**恢复空白带（卷轴归零）
- **MONITOR** 开关：Web Audio 合成磁带嘶声 + 曲目名种子驱动的 Drone 音景
- 4 种氛围配色（极光 / 熔金 / 深渊 / 幽兰）

## 微交互细节
- 卷轴角速度随带卷半径实时变化（ω = v / r），卡带壳随走带方向微微倾侧
- 乱码揭示标签、点击涟漪扩散、粒子流场（播放时流速加倍）
- 全站 `cubic-bezier(0.16, 1, 0.3, 1)` 非线性缓动

## 技术
Vanilla JS + CSS3 + HTML5，零构建。字体：Inter / Outfit / Share Tech Mono。
