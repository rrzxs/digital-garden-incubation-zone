# Idea Boardwalk 创意栈道

沉浸式创意栈道漫步体验。黄昏的海滨木栈道上，每一个念头都是一盏悬浮的微晶玻璃灯卡——漫步、拾光、点亮新的想法。

## 核心交互

- **漫步物理**: 拖拽 / 滚轮 / 方向键滑行栈道，弹簧-阻尼惯性动量
- **视差纵深**: 远海 · 木板步道 · 灯杆 · 前景芦苇四层差速视差
- **灯卡动力学**: 正弦浮动律动 + 悬停 3D 倾斜 + 点击轻推 + 冲击波弹簧
- **涟漪冲击波**: 点击空处激起光环，按距离高斯衰减推挤附近灯卡
- **点亮仪式**: 输入想法 → 乱码揭示 + 点燃闪光 + 弹簧滑向新灯卡
- **光标光晕**: 弹簧跟随的柔光晕随漫游呼吸

## 氛围配色

暮色 ☄ · 极光 ✦ · 晨曦 ☀ · 子夜 ☾（右上角切换，localStorage 持久化）

## 技术栈

- Vanilla JS + CSS3 + HTML5，零构建、零依赖
- 字体: Inter / Outfit / Share Tech Mono
- 动效曲线: `cubic-bezier(0.16, 1, 0.3, 1)`
- 流体渐变背景: `@keyframes` + `filter: blur()` + `mix-blend-mode: screen`
- 微晶玻璃态: `backdrop-filter: blur()` + 发光描边

| 文件 | 说明 |
