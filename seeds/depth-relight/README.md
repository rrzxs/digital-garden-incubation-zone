# Depth Relight · 深度重光

沉浸式程序化深度场重光体验场。Simplex 噪声生成流动的高度场，实时推演表面法线，
拖拽光源即刻重雕画面的光影结构——Lambert 漫反射 / Blinn-Phong 高光 / 边缘轮廓光 /
深度透视四种着色模式，点击释放涟漪脉冲扰动深度场，光锥中尘埃微粒缓缓盘旋。

## 特性

- **程序化深度场**：三层 fbm Simplex 噪声高度场，随时间流变，空格键随机换地形
- **实时光照引擎**：高度场 → 法线推演 → 四种着色模式（漫反射 / 高光 / 轮廓光 / 透视）
- **弹簧光源**：拖拽光源带非线性缓动追踪与惯性漂移
- **涟漪脉冲**：点击地面释放扩散波，实时扰动深度场并可见涟漪环
- **尘埃微粒**：光锥范围内悬浮微粒朝光源盘旋
- **可调参数**：光源高度 / 光照强度 / 环境光 / 地形起伏 / 流变速度
- **4 种氛围配色**：极光 / 熔金 / 深海 / 幻夜
- 流体渐变背景 + 微晶玻璃态容器 + `cubic-bezier(0.16, 1, 0.3, 1)` 非线性动效

## 技术

免构建：Vanilla JS + CSS3 + HTML5，无任何依赖。低分辨率光照场（168×105）
离屏渲染后放大合成，兼得性能与柔光质感。
