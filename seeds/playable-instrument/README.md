# Playable Instrument 光奏盘

沉浸式可演奏 Web 乐器。环形手盘音垫 + Web Audio 实时合成，敲击即成曲。

## 特性

- **环形音垫**: 8 枚微晶玻璃态音垫环绕中央共鸣腔，支持点击 / 触摸 / 键盘（A–K）演奏
- **Web Audio 合成**: 双分音加法合成 + 指数包络，回声链路（delay + feedback + lowpass）实时可调
- **4 种音阶**: 五声宫调 / 多利亚 / 利底亚 / 日本律音阶
- **4 种音色**: SINE 纯音 / TRI 暖光 / GLASS 晶振 / AIR 气鸣
- **高阶微交互**: 击打弹性形变（cubic-bezier(0.16, 1, 0.3, 1)）、共鸣腔脉冲环、涟漪冲击波、粒子迸射、背景呼吸增强
- **4 种氛围配色**: 星云 / 余烬 / 苔绿 / 深海，实时切换流体渐变背景
- **快捷键**: `SPACE` 随机即兴 · `R` 声场重置 · 点击共鸣腔触发琶音

## 技术栈

纯 Vanilla JS + CSS3 + HTML5，零构建、零依赖。字体: Inter / Outfit / Share Tech Mono。
