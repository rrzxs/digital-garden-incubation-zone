# Data Center Builder · 数据中心构建器

沉浸式数据中心布局构建器。从元件库拖拽机架、服务器、冷却、电源、交换机、存储到 12×8 网格平面图，实时计算 PUE 能效比、供电平衡与散热指标，流体渐变背景 + 微晶玻璃态容器 + 非线性动效。

## 功能特性

- **拖拽构建**：从元件库拖入 6 类元件（机架 / 服务器 / 冷却 / 电源 / 交换机 / 存储）至 12×8 网格
- **实时遥测**：PUE 能效比、供电盈亏、负载、散热四项核心指标实时缓动更新
- **状态徽章**：节点在线、电力缺口 / 盈余、散热不足 / 充足、规模化部署等动态状态提示
- **元件统计**：每类元件数量芯片，部署后高亮
- **预设布局**：一键加载经典冷热通道布局示例
- **随机布局**：一键生成随机拓扑
- **清空 / 移除**：点击已放置元件移除，双击清空单元，工具栏一键清空
- **粒子流场背景**：噪声驱动的粒子流场，光标排斥力场，近邻粒子连线网络
- **四种氛围配色**：深渊（青绿）/ 等离子（紫红霓虹）/ 量子（青绿蓝）/ 日冕（暖橙金）
- **移动端支持**：点击元件库选中，再点网格放置

## 交互

- **桌面**：拖拽元件库项目至网格 → 放置；点击已放置元件 → 移除；双击 → 清空单元
- **移动端**：点击元件库选中类型 → 点击空网格单元放置
- **工具栏**：清空 / 示例 / 随机

## 技术栈

- Vanilla JS + CSS3 + HTML5（零构建、零依赖）
- CSS 变量主题系统 + `backdrop-filter` 微晶玻璃态
- `@keyframes` 流体网格渐变 + 多层模糊光斑 + `mix-blend-mode: screen`
- Canvas 粒子流场（伪噪声流场 + 鼠标排斥）
- HTML5 Drag & Drop API + 自定义拖拽浮层
- 动效曲线：`cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Inter / Outfit / Share Tech Mono

## 文件结构

```

├── main.js      # 拖拽构建 / 容量计算 / 粒子流场 / 主题切换
```

## 使用

直接用浏览器打开 `index.html` 即可。拖拽元件库项目到网格，观察实时遥测，切换氛围配色，感受粒子流场。
