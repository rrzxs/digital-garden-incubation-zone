# Infinite Canvas Map — 无限画布

沉浸式无限画布地图体验。在无尽的数字空间中自由漫游，创建节点、建立连接，构建属于你的思想地图。

## 交互方式

| 操作 | 效果 |
|------|------|
| 拖拽空白区域 | 平移画布 |
| 滚轮 | 缩放 |
| 双击空白 | 添加节点 |
| 双击节点 | 编辑节点（名称/描述/颜色） |
| 拖拽节点 | 移动节点位置 |
| 快捷键 V / N / C / X | 切换工具（平移/添加/连接/删除） |
| ESC | 取消连接/关闭编辑器 |

## 视觉特性

- 流体渐变背景 (Mesh Gradient) 呼吸律动
- 微晶玻璃态 (Glassmorphism) 控制面板
- 节点脉冲呼吸动画 + 出生粒子迸射
- 贝塞尔曲线连接线 + 流动虚线效果
- 4 种氛围配色（黑曜石/极光/余烬/冰霜）
- 非线性缓动 `cubic-bezier(0.16, 1, 0.3, 1)`

## 技术栈

Vanilla JS + CSS3 + HTML5 + Canvas 2D，零依赖，免构建。
