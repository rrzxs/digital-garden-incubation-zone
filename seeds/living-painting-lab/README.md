# Living Painting Lab · 活体绘画实验室

> 画下的每一笔都是活的——颜料粒子在噪声流场中呼吸、漂移、彼此纠缠。

免构建的沉浸式活体绘画体验场（Vanilla JS + CSS3 + Canvas 2D）。

## 体验

- **活体笔触**：拖拽绘画，笔触即刻转化为有呼吸节律的发光颜料粒子
- **4 种生命模式**：流场 FLOW / 涡旋 SWIRL / 脉动 PULSE / 凝滞 FREEZE（快捷键 1-4）
- **光标力场**：光标移动速度越快，对颜料的推力越强
- **冲击波**：点击画布施加冲击波，全场脉冲（Space）
- **随机播种**：一键生成一幅有机形态的活体画作
- **参数调节**：生命强度 / 笔触粒径 / 拖尾余韵 / 自走漂移开关
- **导出 PNG** · **4 种氛围配色**（Aurora / Ember / Abyss / Orchid）
- 快捷键：`1-4` 切换模式 · `C` 清空 · `Space` 全场脉冲

## 材质

流体网格渐变背景（超大 blur + screen 混合 + 呼吸漂移动画）、微晶玻璃态画框与控制台（backdrop-filter + 发光描边）、全站非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`。

## 文件

- `index.html` — 结构
- `style.css` — 流体背景 / 玻璃态 / 动效
- `main.js` — 颜料粒子物理、噪声流场、交互逻辑
