# Ink Garden · 墨韵花园

沉浸式墨韵花园微交互体验。点击或拖拽画布播下墨的种子，看它们以非线性缓动生长为摇曳的墨草与墨花。

## 交互

- **Click / Drag** — 在画布任意位置栽种墨花（拖拽可连续播种）
- **Shift + Click** — 播下一株更大的盛放墨花
- **光标靠近** — 花草受光标力场轻轻弯折
- **园艺台** — 花型（枝 / 莲 / 草 / 斑）、风力、扩散度、飘散粒子开关
- **收获** — 清空花园，花朵化作粒子飞散

## 特色

- 4 种花型：递归分枝、径向花瓣、草叶、扩散墨斑
- 4 种氛围配色：墨夜 / 月白 / 朱砂 / 虚空
- 风场摆动 + 指针力场弯折的弹簧感物理
- 流体渐变背景 + 微晶玻璃态容器
- 动效曲线统一为 `cubic-bezier(0.16, 1, 0.3, 1)`

## 技术

Vanilla JS + Canvas 2D + CSS3，免构建，直接打开 `index.html` 即可体验。
