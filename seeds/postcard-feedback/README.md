# Postcard Feedback · 明信片回声

沉浸式反馈收集体验。将"写反馈"重新隐喻为"寄一张明信片"——
手写墨迹浮现、邮戳盖印、翻面投递、情绪环读取字里行间的温度。

## 核心交互

1. **手写墨迹 (Handwriting)** — 输入实时同步到 3D 明信片，Caveat 手写体逐行浮现
2. **3D 邮戳盖印 (Stamp)** — 盖戳投递时邮戳以 `stampPress` 弹性动效压印，墨迹迸射
3. **翻面投递 (Flip & Fly)** — 明信片 3D 翻转 + 飞离动画，投递后落入投递箱
4. **情绪环 (Emotion Ring)** — 关键词词库驱动的共鸣值计算，4 个情绪节点环绕共振
5. **磁力拖拽 (Magnetic Pull)** — 光标接近明信片时产生透视倾斜与位移吸附
6. **投递箱 (Mailbox)** — 已投递明信片陈列墙，点击翻面重温

## 交互方式

- **书写**：名字与留言实时同步至明信片正面手写区
- **情绪选择**：点击 4 种情绪芯片，对应轨道节点亮起
- **翻转**：点击翻转按钮或明信片本身切换正反面
- **盖戳投递**：点击发送触发邮戳盖印 → 飞离 → 入库
- **光标移动**：明信片磁力倾斜 + 玻璃态容器透视 + 光晕跟随
- **右下角配色**：4 种氛围配色 (Aurora / Ember / Ocean / Void)

## 审美系统

- **流体渐变背景**：4 颗超大模糊光球 `mix-blend-mode: screen` 呼吸
- **微晶玻璃态容器**：`backdrop-filter: blur(24px)` + 发光描边
- **非线性动效**：统一 `cubic-bezier(0.16, 1, 0.3, 1)` 曲线
- **字体**：Outfit (展示) / Inter (正文) / Caveat (手写) / Share Tech Mono (数据)

## 技术栈

- Vanilla JS + CSS3 + HTML5 (零构建)
- Simplex Noise (内联实现) 驱动粒子流场
- Canvas 2D 粒子系统 + 墨迹迸射
- CSS 变量主题系统
- IntersectionObserver 章节揭示

## 情绪词库

共鸣值由中英双语关键词词库驱动：

- **喜悦 (Joy)** — 开心 / 感谢 / love / thanks …
- **平静 (Calm)** — 宁静 / 疗愈 / peace / relax …
- **灵感 (Spark)** — 创意 / 想象 / idea / inspire …
- **忧伤 (Ache)** — 疲惫 / 孤独 / tired / lonely …

文本长度贡献基础共鸣 (≤40)，命中的关键词额外加权 (≤60)，最高 100。
