# Glyph Proximity — 字形邻近

邻近性感知驱动的交互式字形力场体验。

## 特性
- **邻近性感知** — 鼠标/触控附近的字形被力场驱动，产生吸引、排斥、环绕或冻结响应
- **连接线网络** — 靠近鼠标的字形之间自动生成半透明连接线，形成动态邻近拓扑
- **4 种交互模式** — Attract（吸引）、Repel（排斥）、Orbit（环绕）、Freeze（冻结）
- **4 种字符集** — 拉丁字母 / 希腊字母 / 中文大写数字 / 特殊符号，循环切换
- **4 种氛围配色** — 黑曜石 / 极光 / 余烬 / 星云
- **实时参数调节** — 力场半径、力度、阻尼滑块
- **弹簧归位物理** — 字形脱离力场后以弹簧阻尼回归原位

## 技术实现
- Vanilla JS + Canvas 2D 渲染
- 邻近性感知力场 + 弹簧-阻尼归位物理
- 流体网格渐变背景 + 微晶玻璃态容器
- 非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 响应式布局，支持触屏

## 使用
直接在浏览器中打开 `index.html`，移动鼠标或触摸画布与字形交互。
