# Scramble Reveal - 解密揭示

沉浸式文字乱码揭示交互体验。

## 体验

文字从混沌乱码中逐步解密浮现，配合粒子流场背景与微晶玻璃态容器，营造解密揭示的仪式感。

## 功能

- **5种揭示模式**: CASCADE（级联）、WAVE（波浪）、VORTEX（漩涡）、GLITCH（故障）、QUANTUM（量子）
- **4种氛围配色**: Emerald（翡翠）、Ember（余烬）、Arctic（极光）、Plasma（等离子）
- **参数调节**: 速度、乱码密度实时滑块控制
- **循环模式**: 自动循环乱码→揭示动画
- **粒子流场**: 背景粒子跟随鼠标交互
- **幽灵字符**: 揭示时字符飘浮特效
- **爆发粒子**: 全部揭示完成后的粒子爆发

## 技术栈

- Vanilla JS + CSS3 + HTML5（零构建）
- 字体: Inter, Outfit, Share Tech Mono
- 动效曲线: `cubic-bezier(0.16, 1, 0.3, 1)`
- 流体渐变背景 + 微晶玻璃态容器

## 使用

直接浏览器打开 `index.html` 即可体验。输入文字，选择模式，点击 REVEAL 开始揭示。
