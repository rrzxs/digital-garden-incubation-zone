# Spin Choice - 氛围感随机决策转盘

> When you can't decide, let fate spin for you.

## 功能

- 🎡 **可视化转盘** - Canvas 绘制的彩色扇形转盘
- ✍️ **自定义选项** - 支持 2-8 个选项，实时编辑
- 🖱️ **双重交互** - 点击 SPIN 按钮或拖拽旋转
- ✨ **炫酷结果** - 脉冲光效 + 玻璃态卡片揭晓

## 审美

- 流体网格渐变背景（4层 blob 动画）
- 微晶玻璃态 UI（backdrop-filter blur）
- 非线性动效曲线（cubic-bezier 0.16, 1, 0.3, 1）
- 8 色精选配色方案

## 技术栈

- Vanilla JS + CSS3 + HTML5
- Canvas 2D API
- 纯 CSS 动画
- 零构建依赖
