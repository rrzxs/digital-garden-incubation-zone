# Seasonal Arbor Walk · 四季林间漫步

沉浸式四季林间漫步体验。一棵程序化生成的大树在春樱、夏荫、秋叶与冬雪之间流变。

## 体验

- **季节刻度** — 拖拽底部刻度在一年四季间漫游，弹簧-阻尼物理让季节切换拥有非线性呼吸感
- **AUTO 循环** — 开启后一年约 48 秒缓慢轮转
- **风场** — 光标横向位置化作林间之风，枝叶实时摇曳
- **摇树** — 点击画布抖落当季的花瓣 / 绿叶 / 红叶 / 积雪，粒子迸射
- **季节物候** — 春樱粉、夏荫浓绿 + 萤火虫、秋叶橙红、冬雪覆枝，背景流体渐变随季节呼吸
- **键盘** — `←/→` 漫游季节，`空格` 切换 AUTO
- **4 种氛围配色** — 林语 / 暮林 / 霜境 / 炽秋

## 技术

- 免构建：Vanilla JS + Canvas 2D + CSS3
- 字体：Inter / Outfit / Share Tech Mono
- 动效曲线：`cubic-bezier(0.16, 1, 0.3, 1)`
- 材质：流体渐变背景（超大模糊 + screen 混合）+ 微晶玻璃态容器（backdrop-filter）
