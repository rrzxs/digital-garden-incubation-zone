# Page Flow 页流

沉浸式页面过渡体验场 — 流体渐变背景 + 微晶玻璃态容器 + 非线性动效。

## 体验特色

- **页面流动过渡** — 4 个内容页通过非线性缓动曲线平滑切换，模拟物理流动感
- **粒子流体场** — 120 个带轨迹粒子在全屏 Canvas 上流动，光标附近产生引力扰动
- **贝塞尔流线** — 鼠标与近距粒子间绘制弯曲流线，增强能量场可视化
- **4 种氛围配色** — 深海 / 极光 / 余烬 / 虚空，一键切换全局色彩
- **多模态导航** — 滚轮、触摸滑动、键盘方向键、点击指示器均可切换页面
- **光标辉光** — 跟随鼠标的径向渐变光晕，随主题变色

## 技术栈

- Vanilla JS + CSS3 + HTML5
- 零依赖，免构建
- Google Fonts: Inter, Outfit, Share Tech Mono
- 动效曲线: `cubic-bezier(0.16, 1, 0.3, 1)`

## 操作方式

| 输入 | 动作 |
|------|------|
| 鼠标滚轮 | 上下翻页 |
| 键盘 ↑↓←→ | 切换页面 |
| 触摸滑动 | 上下翻页 |
| 底部指示器 | 点击跳转 |
| 页面内 CTA | 前进到下一页 |
