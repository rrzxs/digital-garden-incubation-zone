# Screenshot Polisher - 截图美化器

一个简洁高效的截图美化工具，让你的截图瞬间变得更加精致专业。

## 功能特性

- **拖拽上传**：支持拖拽图片到上传区域或或点击选择文件
- **背景样式**：5 种精美背景（渐变网格、 极光、日落、深海、纯色）
- **自定义参数**：
  - 内边距：20-120px
  - 圆角：0-48px
  - 阴影:0-100% (动态强度)
  - 缩放:50%-150%
- **一键复制**：直接复制到剪贴板
- **PNG 导出**：导出高质量 PNG 图片
- **实时预览**：所有调整即时生效

## 使用方法

1. 拖拽或点击上传截图
2. 选择喜欢的背景样式
3. 调整内边距、圆角、阴影和缩放参数
4. 点击导出或复制到剪贴板

## 技术栈

- Vanilla JavaScript (无框架)
- Canvas 2D API
- CSS3 (Glassmorphism 设计)
- 非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
