# Constellation Report Weaver · 星座报告织机

沉浸式星座报告织造器。以姓名与生日为经纬，将星线逐笔织成一份只属于你的星图报告。

## 体验

- **织机控制台**：输入姓名与生日（自动检测星座），或直接点选 12 星座符号
- **织造星图**：主星由确定性随机（Mulberry32 种子）生成，最近邻算法连成星座线，配合流动经线逐笔「织」出，鼠标视差跟随
- **专属报告**：六维特质雷达扫描展开、能量指标条非线性递增、星语判词乱码揭示、织造档案（守护星/幸运数/共振率）
- **重织**：同一身份可生成无限种织法变体
- **4 种氛围配色**：星云 / 极光 / 余烬 / 深海

## 技术

- Vanilla JS + CSS3 + HTML5，零构建、零依赖
- Canvas 2D 织造动画 + SVG 雷达 + WAAPI 入场动效
- 全局动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Inter / Outfit / Share Tech Mono
