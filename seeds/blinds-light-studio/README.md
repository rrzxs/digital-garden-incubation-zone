# Blinds Light Studio — 百叶窗光影工作室

沉浸式百叶窗光影微交互体验。一扇由弹簧-阻尼物理驱动的百叶窗，切开流动的天空。

## 交互

- **拖拽舞台垂直方向** — 倾斜窗叶，叶片级联滞后传递，产生波浪形变
- **点击舞台** — 快开 / 快闭，全叶片弹簧归位
- **TILT 滑杆** — 精确设定倾角
- **TIME 滑杆** — 0~24 小时时间流转，天空亮度、色温与光晕随之呼吸
- **SLATS 滑杆** — 6~26 片窗叶密度实时重建
- **SNAP 按钮** — 一键开合
- **BREATHE 按钮** — 呼吸节律模式，窗叶随缓慢律动开合
- **主题按钮** — 4 种氛围配色（aurora / ember / moss / rose）

## 细节

- 窗叶物理：每片独立弹簧-阻尼积分 + 逐片滞后系数 → 倾斜波浪
- 光柱：间隙随倾角实时展宽，投射方向响应光标位置
- 尘埃粒子：在光柱带内增亮，模拟丁达尔效应
- 悬浮气流：光标附近的窗叶被轻微扰动
- HUD 遥测：TILT / APERTURE / LUX / TIME 实时读数

## 技术

Vanilla JS + CSS3 + HTML5 · 免构建 · Canvas 2D 渲染 · `cubic-bezier(0.16, 1, 0.3, 1)`
