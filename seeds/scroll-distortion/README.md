# Scroll Distortion · 滚动畸变

沉浸式滚动畸变体验场。滚动速度驱动五种非线性畸变效果：

1. **空间弯曲** — 玻璃态容器的透视旋转与缩放
2. **形态流变** — Simplex 噪声驱动的 SVG 形体实时变形
3. **色散光棱** — RGB 通道分离的文字棱镜折射
4. **弹性网格** — 弹簧-阻尼物理模型的 9 宫格呼吸
5. **涟漪波场** — 双缓冲水波传播 + 光线折射偏移

## 交互

- **滚动**：速度越快，畸变越剧烈
- **鼠标移动**：容器跟随光标透视旋转 + 光晕追踪
- **键盘方向键**：切换章节
- **右下角配色**：4 种氛围配色 (Aurora / Ember / Ocean / Void)

## 技术栈

- Vanilla JS + CSS3 + HTML5
- Simplex Noise (内联实现)
- Canvas 2D 涟漪波场
- CSS 变量主题系统
- `cubic-bezier(0.16, 1, 0.3, 1)` 动效曲线
