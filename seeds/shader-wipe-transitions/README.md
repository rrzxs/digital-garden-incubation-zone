# Shader Wipe Transitions 着色擦除过渡

沉浸式着色器风格擦除过渡体验场。6 种基于 Simplex 噪声场的像素级擦除模式，实时渲染过渡效果。

## 擦除模式

| 模式 | 说明 |
|------|------|
| 噪声溶解 | Simplex FBM 噪声驱动的不规则溶解 |
| 涟漪扩散 | 从中心向外扩散的涟漪波纹 |
| 径向收缩 | 从边缘向中心收缩的圆形擦除 |
| 对角切割 | 对角线方向的倾斜切割 |
| 网格裂变 | 像素级网格单元格的依次裂变 |
| 螺旋漩涡 | 阿基米德螺旋线驱动的漩涡擦除 |

## 交互

- **键盘**: `← →` 或 `Space` 切换场景
- **参数调节**: 过渡时长、噪声尺度、边缘羽化
- **自动播放**: 默认开启，4.5 秒间隔自动过渡
- **4 种氛围配色**: 深海 / 极光 / 余烬 / 虚空

## 技术实现

- 纯 Canvas 2D + Simplex 噪声实现像素级擦除
- 无构建依赖，Vanilla JS + CSS3 + HTML5
- DPR 适配 + requestAnimationFrame 动画循环
