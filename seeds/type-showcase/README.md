# Type Showcase — 字体剧场

沉浸式字体剧场。邻近力场驱动的排版表演空间，字符在四种表演模式中实时呼吸形变。

## 功能

- **5 种字样展品**：Display（展示标题）、Body（正文段落）、Mono（等宽代码）、Glyph（巨型字符）、Weight（字重光谱 100-900）
- **4 种表演模式**：
  - **Wave** 波浪 — 正弦相位驱动字符上下起伏
  - **Proximity** 邻近 — 鼠标力场排斥字符，字重与缩放实时响应
  - **Orbit** 轨道 — 力场内字符环绕光标旋转
  - **Glitch** 故障 — 随机位移与字符替换，邻近增强扰动
- **乱码揭示动画**：切换字样时字符从随机符号逐字解密
- **实时参数控制**：字号、字重、字距、力场半径、强度
- **Simplex 噪声粒子流场**：背景粒子受流场与光标双重驱动
- **点击涟漪冲击波**：点击触发涟漪环扩散
- **遥测面板**：模式、字符数、力场强度、FPS 实时显示
- **4 种氛围配色**：极光、烬火、森林、虚空
- **自定义光标** + 流体渐变背景 + 微晶玻璃态容器
- **键盘快捷键**：`1-4` 切换模式、`←→` 切换字样、`S` 随机、`R` 重置

## 技术

Vanilla JS + CSS3 + HTML5，零构建依赖。包含内置 Simplex 噪声实现驱动粒子流场。字体使用 Inter / Outfit / Share Tech Mono。动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)` 与弹簧曲线 `cubic-bezier(0.34, 1.56, 0.64, 1)`。
