# Morphism Lab - 形态变异实验室

交互式形态变异体验场。通过噪声扰动、弹簧物理和流体场驱动，探索几何形体在球体、星形、波动、有机体与晶体之间的实时变形。

## 功能

- **三种交互模式**：雕塑（鼠标影响形体）、流体（粒子流场驱动）、碎裂（向心力裂变）
- **五种基础形态**：球体、星形、波动、有机体、晶体，平滑过渡
- **参数调节**：扰动强度、动画速度实时可调
- **四套配色方案**：虚空、深海、余烬、极光
- **拖拽交互**：形体可被拖拽，释放后弹簧阻尼回弹
- **光标追踪**：鼠标轨迹粒子特效

## 技术实现

- Vanilla JS + SVG Path + Canvas 2D
- Catmull-Rom 样条曲线平滑闭合路径
- 值噪声 (Value Noise) 驱动顶点扰动
- 弹簧-阻尼物理模型驱动物体运动
- 流体渐变背景 + 微晶玻璃态容器
- 非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
