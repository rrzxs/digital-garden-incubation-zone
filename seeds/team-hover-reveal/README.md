# Team Hover Reveal · 悬浮揭示

> 沉浸式团队成员悬浮揭示体验。光标进入卡片即刻展开生平、技能光谱与签名引语,3D 倾斜物理 + 粒子流场 + 微晶玻璃态容器,4种氛围配色。

## 体验

- **三态呼吸** — 默认态(肖像 + 姓名)、悬停揭示态(生平 + 技能谱 + 引语 + 社交)、离开归于沉静。卡片在状态之间以非线性缓动过渡。
- **3D 倾斜物理** — 光标在卡片内移动,玻璃表面以 `perspective(1200px)` 实时倾斜,最大 9 度,跟随鼠标的高光光泽层。
- **错峰揭示** — 揭示层内每个模块(头部 / 生平 / 技能 / 引语 / 社交)以 `transition-delay` 顺序浮现,营造层次感。
- **技能光谱** — 每位成员三项核心技能,以延迟触发的进度条形展示,数值 0–100。
- **签名引语** — 每张卡片配一句成员的个人哲学,斜体引号样式 + 主题色左边框。
- **HUD 实时反馈** — 顶部 HUD 显示当前揭示成员姓名 + 闪烁指示点,脚注实时计数已揭示卡片。
- **光标跟随光晕** — 悬停卡片时,全局光晕跟随光标,平滑插值移动。
- **4 种氛围配色** — Aurora 极光 / Ember 余烬 / Abyss 深渊 / Orchid 兰若。

## 审美与交互

- 流体网格渐变背景(5 颗高斯模糊 blob + screen 混合 + SVG 噪点颗粒层)
- 微晶玻璃态容器(`backdrop-filter: blur` + 发光描边)
- 全局非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 粒子流场 + 鼠标引力 + 近邻连线
- 点击涟漪层、卡片错峰入场、键盘可聚焦揭示

## 团队成员

8 位虚构成员,涵盖创意总监 / 主程 / 动效设计师 / 系统架构师 / 研究负责人 / 声学工程师 / 产品策略师 / 交互工程师,每人配有差异化技能谱与签名引语。

## 技术栈

Vanilla JS + CSS3 + HTML5,零构建、零依赖。字体:Inter / Outfit / Share Tech Mono。

## 文件结构

```
team-hover-reveal/
├── index.html   # 结构:序言 + 成员网格 + 脚注
├── style.css    # 流体背景 + 玻璃态 + 非线性悬停揭示 + 4 主题
├── main.js      # 卡片构建 + 3D 倾斜 + 揭示逻辑 + 粒子流场 + 配色

```

## 使用

直接用浏览器打开 `index.html`。悬停任意成员卡片即可揭示详情,移动光标体验 3D 倾斜物理。键盘 Tab 聚焦、触摸点击也可触发揭示。点击右上角色板切换氛围。
