# Editorial Scroll Story | 编年卷轴故事

沉浸式编辑式滚动故事体验。一篇关于「留白」的杂志体卷轴 —— 6 幕叙事章节，由滚动驱动逐字揭示、视差深度、呼吸节奏与流体渐变共同编织。流体渐变背景 + 微晶玻璃态容器 + 非线性动效。

## 核心特性

- **6 幕叙事章节** — 序章 / 起源 / 呼吸 / 深度 / 揭示 / 温度 / 终章，讲述关于「留白」的设计哲学
- **逐字字符揭示** — 标题文字拆分为单字 span，错峰以 `cubic-bezier(0.16, 1, 0.3, 1)` 淡入
- **视差深度层** — 前景快、背景慢的鼠标视差舞台 + 滚动驱动的装饰层位移
- **呼吸节奏可视化** — 节奏律动条与宣言逐行揭示
- **温度交互** — 涟漪回声按钮，点击计数
- **4 种氛围配色** — 极光 / 余烬 / 深渊 / 破晓，主题切换瞬时迁移背景流体球色彩
- **HUD 遥测面板** — 实时章节、滚动百分比与速度
- **终章统计递增** — ease-out-quart 数字滚动动画
- **键盘导航** — 方向键 / PageUp / PageDown / Home / End

## 技术实现

- 纯 Vanilla JS + CSS3 + HTML5，免构建、零依赖
- `IntersectionObserver` 多路观察：章节激活、元素揭示、标题分割、宣言、终章统计
- CSS 自定义属性驱动的主题系统（`data-theme` 切换）
- `@keyframes orbDrift` + `filter: blur(110px)` + `mix-blend-mode: screen` 构建流体渐变背景
- `backdrop-filter: blur(28px) saturate(1.4)` 微晶玻璃态容器
- `requestAnimationFrame` 驱动光标光晕弹性跟随与速度环
- 字体：`Inter` / `Outfit` / `Share Tech Mono`
- 非线性缓动：`cubic-bezier(0.16, 1, 0.3, 1)`

## 交互指南

- 鼠标滚动或键盘方向键在章节间穿梭
- 点击右侧章节导航点快速跳转（悬停显示章节名）
- 右下角切换 4 种氛围配色
- 在「深度」章节移动鼠标体验视差舞台
- 在「温度」章节点击按钮感受回声涟漪
- 移动鼠标观察全屏光晕跟随
