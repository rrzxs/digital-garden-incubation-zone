# Dark Pattern Exposer

An interactive awareness tool that teaches users to identify and understand dark patterns in UI design through simulated deceptive interfaces.

## Features

- **6 Themed Scenes** covering 24 dark patterns: hidden costs, confirmshaming, forced accounts, fake urgency, privacy zuckering, decoy pricing, and more
- **3 Interaction Modes**: Scan (discover), X-Ray (highlight all), Educate (guide unfound patterns)
- **4 Atmosphere Palettes**: Crimson, Abyss, Venom, Void
- **Particle flow field** background with mouse interaction
- **Glassmorphism containers** with fluid gradient backgrounds
- **Non-linear transitions** using `cubic-bezier(0.16, 1, 0.3, 1)`

## Tech Stack

- Vanilla HTML5 + CSS3 + JavaScript
- Zero build step, zero dependencies
- Fonts: Inter, Outfit, Share Tech Mono

## Usage

Open `index.html` in any modern browser. Navigate between scenes using arrow buttons or keyboard arrows. Click on suspicious UI elements to expose hidden dark patterns and learn about deceptive design tactics.
