# Pixel Owl Math — 像素猫头鹰数学馆

沉浸式像素猫头鹰数学训练馆。一只会眨眼、振翅、歪头、脸红的像素猫头鹰导师陪你进行心算训练。

## 特性

- **像素猫头鹰导师**：瞳孔实时追踪光标、随机眨眼、答对时跳跃振翅脸红、答错时歪头抖动、出题时思考倾斜
- **乱码揭示题目**：每道算式以乱码字符逐位解密呈现
- **连击系统**：COMBO × 连击、段位进化（雏鸟 → 夜翼 → 星眼 → 羽翼风暴 → 夜之智者），连击越高 XP 倍率越猛
- **羽翼风暴**：连击 ≥10 触发风暴模式，粒子迸射与光环闪烁
- **5 种运算模式 × 4 档难度**：加 / 减 / 乘 / 除 / 混合，难度 I–IV
- **像素键盘**：微晶玻璃态数字键盘，支持键盘 / 回车输入
- **夜巡档案**：答题数、正确率、最佳连击、羽毛 XP 与环形等级进度
- **流体渐变背景 + 微晶玻璃态容器 + 非线性动效**（cubic-bezier(0.16, 1, 0.3, 1)）
- **4 种氛围配色**：极光 / 赛博 / 暮砂 / 薄荷
- 环境粒子流场（Simplex 噪声）、爆发粒子与飘落羽毛

## 技术栈

Vanilla JS + CSS3 + HTML5，零构建、零依赖，即插即用。

## 使用

直接打开 `index.html`，输入答案按回车或 ✓，开始夜算之旅。
