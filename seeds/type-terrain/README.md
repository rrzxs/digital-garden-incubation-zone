# Type Terrain · 字形地形

沉浸式字形地形交互体验。输入文字即刻隆起为 3D 地形，Simplex 噪声风化、光标力场雕刻、脉冲冲击波与粒子流场，4种氛围配色。

## 功能

- **铸字成山**: 输入任意文字（中英文皆可），实时采样字形为高度场，隆起为可环绕的 3D 地形
- **Simplex 噪声风化**: 字形边缘被噪声实时侵蚀，山体随时间缓慢呼吸演化
- **双交互模式**: 环绕（拖拽旋转地形）/ 雕刻（光标力场实时扰动地形）
- **三种渲染模式**: 线框（峰值高光描边）/ 点阵 / 密度横截面
- **脉冲冲击波**: 点击或 `SPACE` 触发冲击波涟漪推挤地形
- **参数调节**: 起伏振幅、风化强度、网格精度实时滑块
- **粒子流场**: 噪声流场粒子响应光标力场
- **4种氛围配色**: 深渊、极光、熔岩、苍蓝

## 技术栈

- Vanilla JS + CSS3 + HTML5（免构建）
- Canvas 2D 软件投影渲染（yaw/pitch 旋转 + 透视深度）
- 离屏 Canvas 字形采样 + 3×3 高斯柔化
- 内置 Simplex Noise 实现
- CSS 自定义属性主题切换

## 使用方式

直接在浏览器中打开 `index.html` 即可体验。
