# Merge City — 融城

沉浸式建筑融合城市建设体验场。

## 概述

在 6×6 微晶玻璃网格上放置建筑，相同等级的相邻建筑自动级联融合升级——从帐篷筑起木屋，从木屋筑起砖房，一路发展为办公楼、摩天楼乃至大都市。配合粒子迸射、冲击波环与弹簧物理动效。

## 核心玩法

- **放置建筑**：点击空格放置「下一个」建筑
- **级联融合**：相同等级的相邻建筑自动融合升级，可能引发连锁融合
- **推平模式**：清除不想要的建筑腾出空间
- **撤销**：Ctrl/Cmd+Z 回退最近操作
- **建筑图鉴**：左侧面板追踪已解锁的 12 种建筑

## 建筑升级路线

帐篷 → 木屋 → 砖房 → 公寓 → 商店 → 办公楼 → 酒店 → 医院 → 塔楼 → 摩天楼 → 地标 → 大都市

## 快捷键

| 按键 | 功能 |
|------|------|
| `R` | 新城重开 |
| `B` | 推平模式开关 |
| `Ctrl/Cmd+Z` | 撤销 |

## 配色

极光 / 余烬 / 苔藓 / 暮色 四种氛围配色。

## 技术

- Vanilla JS + CSS3 + HTML5（免构建）
- Canvas 2D 粒子系统（迸射、冲击波环、尘埃）
- 流体网格渐变背景（`filter: blur` + `mix-blend-mode: screen`）
- 微晶玻璃态容器（`backdrop-filter: blur`）
- 非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- SVG 建筑图标系统
