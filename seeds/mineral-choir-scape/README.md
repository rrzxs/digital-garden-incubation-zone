# Mineral Choir Scape · 矿物唱诗班

沉浸式矿物唱诗班声景。13 枚程序化晶簇沿洞窟地面弧线排布，每枚晶簇绑定一个音级——悬停低吟、点击长音、拖拽扫弦、长按蓄能全场合唱绽放。Web Audio 合成合唱声部（三重失谐振荡器 + 低通包络 + 生成式洞穴卷积混响），4 种音阶 × 4 种氛围配色，流体渐变背景 + 微晶玻璃态控制台 + 非线性动效。

## 交互

| 手势 | 效果 |
|---|---|
| 悬停晶簇 | 低吟短音（hum）+ 微弱共振 |
| 点击晶簇 | 长音合唱 + 粒子迸射 + 涟漪环 |
| 按住拖拽 | 扫过晶簇产生和声琶音 |
| 长按 (>600ms) 松开 | 蓄能合唱——全场级联绽放 |

## 控制台

- **SCALE** — 大五声 / 多利亚 / 利底亚 / 平调子四种音阶
- **CAVE** — 洞穴卷积混响干湿比
- **AUTOCHOIR** — 生成式自动唱诗调度（随机根音三和弦）
- **AMBIENT** — 紫晶洞 / 翠谷 / 蔷薇水晶 / 极冰四种氛围配色

## 技术

- Vanilla JS + CSS3 + Canvas 2D，零构建、零依赖
- 弹簧-阻尼物理（`k=90, damp=7.5`）驱动晶簇共振缩放
- Web Audio：ConvolverNode 使用程序化衰减噪声脉冲响应模拟洞穴混响
- 动效统一采用 `cubic-bezier(0.16, 1, 0.3, 1)` 非线性曲线
- 字体：Inter / Outfit / Share Tech Mono
