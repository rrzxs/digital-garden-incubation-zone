# Moon Phase Orbit 月相轨道

沉浸式天体律动 Web App。基于真实天文算法的月相计算，配合流体渐变背景、微晶玻璃态容器与非线性动效。

## 功能

- **实时月相计算** — 基于 2000-01-06 新月历元，朔望月 29.53 天周期
- **轨道可视化** — 月球沿椭圆轨道环绕中心天体，多层装饰轨道环
- **月相阴影** — clip-path 实时渲染月相明暗面（朔→望→朔）
- **星空背景** — Canvas 动态星空，粒子闪烁与漂移
- **拖拽交互** — 拖拽月球沿轨道旋转，实时改变月相
- **时间线** — 8 个标准月相节点，点击跳转
- **日期选择** — 选择任意日期查看当日月相
- **速度控制** — 0× / 1× / 5× / 20× / 100× 时间加速
- **键盘** — ← → 调节月相，Space 暂停/播放，R 重置
- **4 种氛围配色** — 月华（深海银月）/ 月蚀（血月深红）/ 星海（深空紫蓝）/ 琥珀（暖金秋夜）

## 技术栈

- Vanilla JS + CSS3 + HTML5
- Canvas 2D（星空 + 轨道轨迹）
- Google Fonts: Inter / Outfit / Share Tech Mono
- `cubic-bezier(0.16, 1, 0.3, 1)` 全局缓动
- 零构建、零依赖
