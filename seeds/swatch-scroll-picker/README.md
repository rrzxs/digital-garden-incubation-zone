# Swatch Scroll Picker 色卡卷轴拣选器

沉浸式色卡卷轴拣选体验。拖拽、滚轮或方向键在色卡卷轴中游走，弹簧-惯性物理驱动非线性中心聚焦（远离中心的色卡以幂次曲线缩小、降透明、模糊并倾斜），滚动速度实时转化为色卡歪斜畸变，选中的色彩即刻驱动全局主题与流体渐变背景。

## 特性

- **非线性中心聚焦**：色卡按与中心的距离产生 `pow(t, 1.7)` 幂次缩放 / 透明度 / 升降 / 景深模糊
- **弹簧-惯性物理**：释放拖拽后先惯性滑行（摩擦衰减），再进入带过冲的弹簧吸附对齐
- **速度歪斜畸变**：滚动速度实时驱动色卡 `skewX` 非线性形变，HUD 显示实时速度
- **选中色驱动主题**：色相带环绕插值平滑过渡，流体渐变背景光斑同步流变
- **4 组色卡集**：Aurora / Ember / Botanic / Nocturne，各含 12 张精选色卡
- **一键复制**：点击色卡或预览面板复制 HEX，伴随涟漪冲击波与 Toast 反馈
- **微晶玻璃态容器**：`backdrop-filter: blur` + 发光描边 + 呼吸辉光

## 技术

- Vanilla JS + CSS3 + HTML5，免构建
- 字体：Inter / Outfit / Share Tech Mono
- 动效曲线：`cubic-bezier(0.16, 1, 0.3, 1)`
