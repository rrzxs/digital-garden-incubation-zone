# Typewriter - 复古打字机体验

一个模拟复古打字机风格的 Web 应用，带来怀旧而沉浸的文字输入体验。

## 功能特性

- **逐字打印效果** - 带有随机延迟（50-120ms）模拟真实打字节奏
- **按键音效反馈** - 可选的打字音效，使用 Web Audio API 合成
- **换行动作** - 打字机风格的换行，带有叮声音效和纸张卷动效果
- **墨迹残留效果** - 纸张上模拟的墨迹污渍
- **打字头动画** - 随光标移动的机械打字头
- **复古视觉风格** - 暖色调纸张质感与微妙阴影

## 使用方法

1. 点击纸张区域开始输入
2. 直接使用键盘输入文字
3. 按 Enter 键或点击"换行"按钮换行
4. 点击音效按钮开启/关闭打字音效
5. 点击清空按钮重置内容

## 技术实现

- 纯 Vanilla JS + CSS3 + HTML5，无构建依赖
- 使用 Web Audio API 合成打字音效
- CSS 动画实现流畅的视觉效果
- 支持键盘直接输入和文本区域输入双模式

## 字体

使用 Google Fonts 的 Special Elite 字体，搭配 Courier New 作为后备字体。

## 浏览器兼容

支持所有现代浏览器，包括移动端适配。
