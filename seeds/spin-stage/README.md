# Spin Stage 旋转舞台

沉浸式 3D 旋转舞台微交互体验场。八位「表演者」玻璃卡片在透视环轨上巡演——拖拽赋予舞台角动量（惯性 + 摩擦物理），点击卡片以弹簧-阻尼曲线将其推至聚光灯下，空白处点击产生冲击波涟漪并令轨道呼吸扩张。

## 交互

- **拖拽舞台**：赋予角动量，松手后惯性旋转并自动吸附至最近整位
- **点击卡片**：弹簧物理对焦，卡片抬升、发光揭示
- **Nudge ⟳**：随机角动量轻推
- **Auto ▷**：自动巡演模式
- **Pulse ✦**：全场脉冲，冲击波 + 轨道扩张
- **氛围切换**：Nebula / Aurora / Ember / Abyss 四种配色

## 技术

- Vanilla JS + CSS3 + HTML5，免构建
- 惯性物理（摩擦衰减）+ 弹簧-阻尼对焦
- Canvas 粒子流场（双频正弦伪噪声）
- 流体渐变背景 + 微晶玻璃态（`backdrop-filter`）
- 非线性动效曲线 `cubic-bezier(0.16, 1, 0.3, 1)`
- 字体：Inter / Outfit / Share Tech Mono
